> **重要程度：高**｜**手练：需要**
> 重点：属性查找、共享可变值与实例覆盖。

但是，如果`Student`类本身需要绑定一个属性呢？可以直接在class中定义属性，这种属性是类属性，归`Student`类所有：

```python
class Student(object):
    name = 'Student'
```

### 小结

实例属性属于各个实例所有，互不干扰；

类属性属于类所有，所有实例共享一个属性；

不要对实例属性和类属性使用相同的名字，否则将产生难以发现的错误。
## 属性查找与共享

读取实例属性时，通常先查实例，再查类及其父类；描述符等机制会影响查找顺序。对实例赋值通常创建或覆盖实例属性，不会自动修改类属性。若类属性是列表等可变对象，通过实例修改这个列表会影响共享该对象的其他实例。

手练：创建两个实例，先读取同一个类属性，再给一个实例赋同名值；另用类属性列表观察追加元素的共享效果。实例独有的可变数据应在初始化时分别创建。
