# 访问限制与封装

> **重要程度：中**｜**手练：建议**
> 重点：单下划线约定、名称改写与封装边界。

`_name` 表示内部使用的约定，外部仍可以访问。以双下划线开头、且不以双下划线结尾的属性会发生名称改写：例如 `Student` 类中的 `__name` 通常改写为 `_Student__name`，主要用于避免子类意外覆盖，并不是安全访问控制。

需要限制写入或校验时，可通过方法或 [[使用@property|property]] 提供明确接口；不要把需要保密的数据寄希望于属性命名。

手练：创建带 `_name` 和 `__name` 的类，观察属性访问与名称改写；给分数属性增加 0 到 100 的校验。
