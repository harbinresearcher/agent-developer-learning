# 获取对象信息

> **重要程度：中**｜**手练：建议**
> 重点：isinstance、hasattr、getattr 的适用场景。

- `type(obj)` 返回对象的具体类型；`isinstance(obj, Base)` 还会考虑继承，通常更适合类型检查。
- `dir(obj)` 返回可供查看的属性名，便于交互式探索，但不保证列出所有动态属性。
- `getattr(obj, name, default)` 按名称读取属性；`hasattr(obj, name)` 检查属性访问是否抛出 `AttributeError`。属性访问可能触发 property 或其他逻辑。
- `callable(obj)` 判断对象是否可调用；能调用不等于调用一定成功。

工作中优先使用明确接口和类型提示，不要为了读取已知属性而滥用反射。需要兼容多种对象时，可用协议或鸭子类型，必要时校验输入。

手练：用继承类比较 `type` 与 `isinstance`，再用 `getattr` 的默认值处理可选属性。
