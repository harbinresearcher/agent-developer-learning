> **重要程度：低**｜**手练：按需**
> 重点：属性限制、内存取舍与继承边界。


如果我们想要限制实例的属性怎么办？比如，只允许对Student实例添加`name`和`age`属性。

为了达到限制的目的，Python允许在定义`class`的时候，定义一个特殊的`__slots__`变量，来限制该`class`实例能添加的属性：

```python
class Student(object):
    __slots__ = ('name', 'age') # 用tuple定义允许绑定的属性名称
```


基类的 slot 会被子类继承；子类如果不声明自己的 `__slots__`，通常会获得 `__dict__`，因而还能添加其他属性。只有在需要限制属性或大量实例的内存测量显示有收益时才考虑使用；某些功能需要显式加入 `__weakref__`。
