# 元类

> **重要程度：低**｜**手练：按需**
> 重点：理解类也是对象、类由元类创建；看懂框架代码即可，普通业务开发不必优先手写元类。

## 类是怎样创建的

Python 的类本身也是对象。通常定义类时，默认元类 `type` 负责创建这个类对象；之后调用类对象，才创建实例。`type(obj)` 常用于查看对象的类型；`type(name, bases, namespace)` 也可以动态创建类。

自定义元类可以在类创建阶段检查或调整类定义。顺序是：执行类体得到命名空间 → 元类创建类 → 之后调用类创建实例。类创建和实例创建是不同阶段。

## 工作中怎么选

元类适合少数需要统一约束类创建的框架级场景，但会增加理解和调试成本。只需注册子类、初始化子类或复用行为时，可先考虑类装饰器、`__init_subclass__` 或组合；数据模型通常应优先使用成熟框架提供的接口。
