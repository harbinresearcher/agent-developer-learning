# 多重继承与 MRO

> **重要程度：中**｜**手练：建议**
> 重点：MRO、super 和协作式继承。

一个类可以继承多个基类。Python 按方法解析顺序（MRO）查找属性；用 `类名.__mro__` 或 `类名.mro()` 查看实际顺序。多个基类有同名方法时，顺序会影响调用结果。

`super()` 按当前实例的 MRO 寻找下一个实现，并非简单等于“调用某个固定父类”。协作式多重继承要求相关方法都按约定继续调用 `super()`，并让参数契约兼容。

Mixin 通常只提供一组明确能力，不独立承担完整对象职责。若只需复用一个服务，组合往往更容易理解。标准库 `socketserver` 的 mixin 示例有特定基类顺序，应按该库文档使用，不能随意调换。

手练：构造菱形继承，查看 MRO；让各层方法调用 `super()`，记录调用顺序，再移除一层的 `super()` 观察变化。

参考：[Python 多重继承](https://docs.python.org/3/tutorial/classes.html#multiple-inheritance)；[socketserver](https://docs.python.org/3/library/socketserver.html)。
