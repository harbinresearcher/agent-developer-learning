# 枚举类 Enum

> **重要程度：中**｜**手练：建议**
> 重点：Enum 成员、值比较和业务状态。

## 用途

用枚举给一组有限的业务状态起名字，例如订单状态，避免在代码里散落无说明的数字或字符串。定义时可用类继承 `Enum`，每个成员有 `.name` 和 `.value`。

## 访问与比较

假设 `Status` 定义了 `OK = 200`：`Status.OK` 通过名字访问，`Status['OK']` 按名字查找，`Status(200)` 按值查找；无对应值时通常抛出 `ValueError`。普通 `Enum` 成员与裸值不相等；`IntEnum` 可与整数比较，需注意类型边界。

重复的值默认成为别名：遍历枚举时通常不显示别名，`__members__` 包含别名。需要禁止重复值时，可用 `@unique`。

## 工作中注意

数据库和 API 需要约定保存 `.value` 还是 `.name`，变更已持久化的值要考虑兼容性。处理外部输入时验证未知状态，避免默认当成合法状态。

手练：定义订单状态，按名称和值读取；验证非法值、重复值和 `@unique` 的行为。
