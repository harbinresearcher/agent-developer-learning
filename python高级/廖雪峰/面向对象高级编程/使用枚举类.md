## 为什么用

表示一组相关常量，别用裸的 `int` 或 `str`。Enum 把它们收进一个封闭集合，**成员不可变、非法值构造即报错**。核心认知：`Weekday.Mon` 不是 `1`，是 `Weekday` 的实例，`.value` 才是底层数字。

## 定义：两种方式

**函数式**，value 自动从 1 编号：

python

from enum import Enum
Month = Enum('Month', ('Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun',
                       'Jul', 'Aug', 'Sep', 'Oct', 'Nov', 'Dec'))

**类继承式**，自己控 value：

python

class Weekday(Enum):
    Sun = 0
    Mon = 1
    Tue = 2

## 访问：四种

python

Weekday.Mon          # 属性访问
Weekday['Mon']       # 按名字取
Weekday(1)           # 按 value 反查
Weekday.Mon.value    # 取原始值

反查传非法值直接报错：`Weekday(7)` → `ValueError`。这是 Enum 的守门价值。

## 比较和遍历

比较认身份，不认值：`Weekday.Mon == 1` 是 `False`，`Weekday.Mon == Weekday(1)` 是 `True`。

python

for m in Weekday:                                     # 按定义顺序遍历成员
    print(m)
for name, member in Weekday.__members__.items():      # 同时要名字
    print(name, '=>', member)

## 两个补充点

**重复 value 默认不报错**，后定义的那个变成别名：`Color.BLUE is Color.RED` 为 `True`，且别名不出现在 `for` 遍历里、但出现在 `__members__` 里。加 `@unique` 在定义时拦住：

python

from enum import Enum, unique
@unique
class Color(Enum):
    RED = 1
    GREEN = 2
    BLUE = 1      # ValueError

**要当整数用换 `IntEnum`**，成员可直接比较和运算：`Status.OK == 200` 为 `True`。但默认优先用 `Enum`，别图省事。
