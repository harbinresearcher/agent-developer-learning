
特殊方法 = 双下划线方法 = **协议钩子**。你不主动调，Python 在特定语法场景下替你调。实现哪个，你的类就拥有哪种"内置类型行为"。核心思想是**鸭子类型**：不靠继承，靠实现协议。

---

## 速查表（先背这张）

|你写的代码|Python 自动调|一句话作用|
|---|---|---|
|`print(obj)` / `str(obj)`|`__str__`|给人看的字符串|
|交互环境裸敲 `obj` / `repr(obj)`|`__repr__`|给开发者调试看的字符串|
|`for x in obj`|`__iter__` → `__next__`|让对象可遍历|
|`obj[key]`|`__getitem__`|支持下标/切片|
|`obj[key] = v`|`__setitem__`|支持下标赋值|
|`del obj[key]`|`__delitem__`|支持下标删除|
|`obj.不存在的属性`|`__getattr__`|属性找不到时兜底|
|`obj()`|`__call__`|让实例像函数一样被调用|
|`len(obj)`|`__len__`|支持 len()|
|`callable(obj)`|看有没有 `__call__`|判断是否可调用|

## 逐个说，只讲"你要记住的"

### `__str__` vs `__repr__`

- **分工**：`__str__` 给用户看，`__repr__` 给开发者看。
    
- **触发**：`print`/`str()` 走 `__str__`；裸敲变量、`repr()` 走 `__repr__`。
    
- **坑**：只写 `__str__` 不写 `__repr__`，交互环境里裸敲变量还是丑的。
    
- **偷懒写法**：`__repr__ = __str__`，一行搞定两个。
    

### `__iter__` + `__next__`

- **分工**：`__iter__` 返回迭代器对象（通常 `return self`）；`__next__` 返回下一个值。
    
- **退出机制**：`__next__` 里 `raise StopIteration()`，`for` 循环才停。**不抛这个异常，循环永不结束**。
    
- **关系**：`for` 循环先调 `__iter__` 拿迭代器，再反复调它的 `__next__`。
    

### `__getitem__`

- **两种入参**：`obj[5]` 传 `int`；`obj[5:10]` 传 `slice` 对象。**必须 `isinstance` 判断类型分路处理**。
    
- **坑**：切片要自己处理 `start/stop/step` 和负数下标，不处理就是半成品。
    
- **配套**：`__setitem__` 管赋值，`__delitem__` 管删除。
    

### `__getattr__`

- **触发时机**：**只有正常查找失败后**才调，正常属性不会触发。
    
- **坑（最重要）**：必须对不认识的属性 `raise AttributeError`，否则任何错拼属性都返回 `None`，bug 被吞掉。
    
- **威力**：可以写完全动态的链式调用，SDK 不用为每个 URL 写方法。
    

### `__call__`

- **效果**：实例加括号就能调，`obj()` 等价于 `obj.__call__()`。
    
- **参数**：跟普通方法一样带 `self`，调用时不用传。
    
- **判断**：`callable(obj)` 看有没有 `__call__`。
    

---

## 易混点集中排雷

1. **`__str__` 和 `__repr__` 不是一回事**。`print` 不走 `__repr__`，裸敲不走 `__str__`。
    
2. **`__iter__` 和 `__getitem__` 都能让 `for` 跑起来，但机制不同**。只实现 `__getitem__` 时，`for` 会退化成从 0 开始不断取下标直到 `IndexError`；实现 `__iter__` 才是正规迭代器协议。两个都实现时，`__iter__` 优先。
    
3. **`__getattr__` 和 `__getattribute__` 别搞混**。前者是"找不到才兜底"，后者是"每次访问都拦截"，日常用前者，后者容易写出死循环。
    
4. **`__call__` 不改变对象的类型**，它还是实例，只是"可调用"了。
    

---

## 记忆锚点

- **打印两兄弟**：`str` 给人，`repr` 给己。
    
- **迭代两兄弟**：`iter` 给迭代器，`next` 给下一个，`StopIteration` 喊停。
    
- **下标一个哥**：`getitem` 接 `int` 也接 `slice`，分路处理。
    
- **兜底一个哥**：`getattr` 只兜找不到的，兜不住就 `raise`。
    
- **调用一个哥**：`call` 让实例变函数。
