# 求职复习：把知识用到项目里

> **重要程度：高**｜**手练：需要**
> 重点：完成一个可运行、可测试、可排查问题的小项目，并能解释设计选择。

## 优先掌握

1. **Python 基础**：函数参数、闭包和装饰器、迭代器与生成器、异常、文件和 JSON。
2. **项目维护**：虚拟环境、依赖版本、类型提示、日志、测试、Git 基本操作。
3. **服务端基础**：HTTP 方法和状态码、参数校验、SQL、事务、索引和连接管理。
4. **并发与 IO**：区分线程、进程、异步任务；知道阻塞、超时、取消和并发上限。
5. **安全边界**：参数化 SQL，不反序列化不可信 pickle，密钥不写入源码和日志，密码使用专用哈希库。

## 一个综合练习

做一个小型数据服务：接收数据、校验字段、保存到数据库，并提供查询接口。用虚拟环境管理依赖；写正常、边界和异常测试；对外部请求设置超时；在日志中保留排查所需的上下文。根据实际需要选择同步或异步，不为使用新技术而增加复杂度。

完成后检查：能否在新环境按说明启动；测试能否重复运行；出错时能否找到原因；能否解释事务、索引、并发选择及其限制。
