# Python 笔记复习索引

> **重要程度：高**｜**手练：需要**
> 重点：按顺序复习高优先级主题，用小任务验证，遇到问题再回查对应笔记。

## 推荐顺序

1. 函数参数、迭代器、生成器、装饰器：能读懂并编写常见 Python 代码。
2. 文件、JSON、异常、日志、测试、虚拟环境：能完成并维护一个小项目。
3. 面向对象、数据库、HTTP：能读懂服务端代码并处理数据。
4. 线程、进程、asyncio：能说明适用场景、处理异常并控制并发。
5. 常用模块按需回查；元类、底层网络和分布式进程先理解用途即可。

重要程度是面向 Python 开发与 AI 应用岗位的复习优先级，不代表所有岗位要求一致。每篇开头的手练重点是复习起点，涉及第三方库时以项目锁定的版本为准。
