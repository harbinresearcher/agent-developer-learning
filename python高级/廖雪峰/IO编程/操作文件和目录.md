# 操作文件和目录 · 笔记

## 先分清：os 和 os.path 是两个命名空间

原文反复强调这一点：操作文件和目录的函数**一部分在 `os` 模块，一部分在 `os.path` 模块**。你写代码时如果发现 `os.join` 不存在，不是记错了，是它住在 `os.path.join` 里。先把这个分类装脑子里，后面就不容易混。

---

## 系统信息：确认你在什么平台上

```python
import os

os.name          # 'posix'（Linux/Unix/macOS）或 'nt'（Windows）
os.uname()       # 详细的系统信息，Windows 上不提供
```

`os.uname()` 只在 Unix-like 系统上有，**Windows 上调它会报 AttributeError**。所以如果你写跨平台代码，别默认 `os.uname()` 一定可用。

环境变量存在 `os.environ` 里，取的时候用 `.get()` 给默认值，避免 KeyError：

```python
os.environ.get('PATH')           # 取 PATH，不存在返回 None
os.environ.get('x', 'default')   # 不存在时返回 'default'，更安全
```

## 路径操作：**永远不要手拼字符串**，用 os.path

这是这页最值钱的规矩。路径分隔符在 Linux/macOS 上是 `/`，Windows 上是 `\`。你手拼 `'/Users/michael' + '/' + 'testdir'`，到 Windows 上就废了。

**拼接用 `os.path.join()`**：

```python
os.path.join('/Users/michael', 'testdir')
# Linux/macOS 返回：/Users/michael/testdir
# Windows 返回：   /Users/michael\testdir
```

`os.path.join` 会根据当前操作系统自动选对分隔符，**这是它存在的唯一理由，也是你必须用它的唯一理由**。别嫌麻烦，手拼字符串是跨平台 bug 的头号来源。

**拆分用 `os.path.split()`**，把路径切成“父目录”和“最后一级（文件或目录名）”：

```python
os.path.split('/Users/michael/testdir/file.txt')
# ('/Users/michael/testdir', 'file.txt')
```

**取扩展名用 `os.path.splitext()`**，它返回“去掉扩展名的部分”和“扩展名”的元组：

```python
os.path.splitext('/path/to/file.txt')
# ('/path/to/file', '.txt')
```

这里有一个必须钉死的认知：**`os.path.join`、`split`、`splitext` 都只对字符串做操作，不要求路径真实存在**。你拿一个根本不存在的路径去 `split`，它照样给你拆得好好的。它们是纯字符串工具，不是文件检查工具。

## 目录的增删查

```python
os.path.abspath('.')                 # 当前目录的绝对路径
os.mkdir('/Users/michael/testdir')   # 创建目录，要求父目录已存在
os.rmdir('/Users/michael/testdir')   # 删除目录，要求目录是空的
```

`os.mkdir` **不能一次性创建多级目录**。你要建 `a/b/c`，得先有 `a/b`。想一步到位建多级，用 `os.makedirs('a/b/c')`，它会自动把中间缺的目录都补上。

**列目录内容用 `os.listdir('.')`**，返回当前目录下所有文件和子目录的名字列表（不含路径前缀）：

```python
os.listdir('.')    # ['a.py', 'b.txt', 'subdir', ...]
```

## 文件操作：重命名、删除，以及“复制为什么不在 os 里”

```python
os.rename('test.txt', 'test.py')   # 重命名
os.remove('test.py')               # 删除文件
```

复制文件呢？**`os` 模块里没有复制函数**。原文解释得很清楚：复制文件不是操作系统提供的系统调用，所以 `os` 里没有对应的接口。理论上你用读写文件也能完成复制，但那是“打开源文件 → 读一块 → 写一块 → 循环”，写起来啰嗦。

**复制交给 `shutil`**，它是 `os` 的补充模块：

```python
import shutil
shutil.copyfile('source.txt', 'dest.txt')   # 复制文件内容到目标路径
```

`shutil` 里还有 `copy()`（复制并保留权限）、`copy2()`（连元数据一起保留）、`copytree()`（递归复制整个目录）、`rmtree()`（递归删除整个目录）。日常复制文件，`copyfile` 或 `copy` 够用。

## 一行代码过滤文件：列表推导 + os.listdir + os.path 判断

原文最后展示的这个技巧很实用，本质上是用列表推导把“列目录 + 筛选”一步写完。

**列出当前目录下所有子目录**：

```python
[x for x in os.listdir('.') if os.path.isdir(x)]
```

**列出当前目录下所有 `.py` 文件**：

```python
[x for x in os.listdir('.') if os.path.isfile(x) and os.path.splitext(x)[1] == '.py']
```

`os.path.isdir(x)` 判断 `x` 是不是目录，`os.path.isfile(x)` 判断是不是文件，`os.path.splitext(x)[1]` 取扩展名（`[1]` 是元组的第二项，即 `'.py'`）。

这两行代码拆开看没有任何新东西，就是你已经知道的函数组合起来。**记住这个组合模板**，以后“按类型筛选文件”的需求直接套。

## 几个容易踩的点

**1. `os.mkdir` 不建父目录。** 建多级目录用 `os.makedirs`，否则父目录不存在直接 `FileNotFoundError`。

**2. `os.rmdir` 只删空目录。** 目录里有东西就报错。要连内容一起删，用 `shutil.rmtree`（**谨慎，不可恢复**）。

**3. 路径拼接永远用 `os.path.join`，永远。** 手拼 `/` 或 `\` 在跨平台代码里迟早炸。

**4. `os.listdir` 返回的是名字，不是完整路径。** 你要用这些名字做后续操作，记得跟原目录 `os.path.join` 拼回去。

**5. `os.path.split` / `splitext` 不检查文件是否存在。** 它们是字符串工具，路径写错了也照样拆，别指望它们帮你发现路径不存在——那是 `os.path.exists()` 的活。
