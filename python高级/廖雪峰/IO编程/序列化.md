# 序列化 · 笔记

## 先聊动机：内存里的变量，程序一关就没了

你在程序里定义一个字典 `d = dict(name='Bob', age=20, score=88)`，改来改去，程序一结束，**操作系统把内存全部回收，下次运行又变回初始值**。你想把某个时刻的变量状态存下来，或者传给另一台机器，就需要一个动作：**把内存里的对象变成可以存储或传输的格式**。这个动作叫序列化，反过来从存储的格式读回内存，叫反序列化。

Python 提供两种路径：**`pickle` 专供 Python 自己用，`json` 用来跟其他语言互通**。

---

## pickle：Python 专属的“原样打包”

`pickle` 可以把许多 Python 对象序列化成一个 `bytes`，然后你把这个 `bytes` 写文件、走网络都行。两个核心函数：**`dumps`/`loads` 处理内存中的 bytes，`dump`/`load` 直接对接文件对象**。

**序列化到内存**：

```python
import pickle

d = dict(name='Bob', age=20, score=88)   # 一个普通字典
data = pickle.dumps(d)                    # 把 d 序列化成 bytes，返回的是一堆二进制乱码
print(data)                               # b'\x80\x03}q\x00(X...'，人看不懂，机器认
```

**直接写文件**：

```python
with open('dump.txt', 'wb') as f:         # 'wb' 二进制写，pickle 产出的是 bytes
    pickle.dump(d, f)                     # 把 d 序列化后直接写入文件对象
```

**反序列化**：

```python
with open('dump.txt', 'rb') as f:         # 'rb' 二进制读
    d2 = pickle.load(f)                   # 从文件对象读出并还原成 Python 对象
print(d2)                                 # {'age': 20, 'score': 88, 'name': 'Bob'}
```

**关键认知**：反序列化回来的 `d2` 和原来的 `d` **内容相同，但是两个完全不相干的对象**，各自独立，改一个不影响另一个。

**安全边界**：不要反序列化不可信或可能被篡改的 pickle；加载时可能执行任意代码。pickle 是 Python 专用格式；版本兼容取决于协议及对象定义，长期保存需测试迁移。参考：[Python pickle](https://docs.python.org/3/library/pickle.html)。

## JSON：跨语言的标准格式

JSON 序列化出来的是一个**字符串**，所有语言都认识，而且比 XML 更轻、更快、Web 页面能直接读。

JSON 和 Python 的类型有**固定的一一对应关系**：

| JSON 类型 | Python 类型 |
|---|---|
| `{}` | `dict` |
| `[]` | `list` |
| `"string"` | `str` |
| `1234.56` | `int` 或 `float` |
| `true` / `false` | `True` / `False` |
| `null` | `None` |

用起来跟 pickle 的四个函数一一对应，只是模块换成 `json`、产出从 `bytes` 变成 `str`：

```python
import json

d = dict(name='Bob', age=20, score=88)
s = json.dumps(d)                         # 序列化成 JSON 字符串
print(s)                                  # '{"age": 20, "score": 88, "name": "Bob"}'

d2 = json.loads(s)                        # 从 JSON 字符串还原成 dict
print(d2)                                 # {'age': 20, 'score': 88, 'name': 'Bob'}
```

`dump()` 和 `load()` 则直接对接文件对象，用法和 pickle 的 `dump`/`load` 完全一致。读写 JSON 文本文件时显式使用 UTF-8；字符串与文件字节之间仍需正确编码和解码。

## 重头戏：为什么 `json.dumps(实例)` 会直接报错

前面序列化的都是 `dict`、`list` 这种内置类型。但实际写代码，你更可能想序列化一个 **class 的实例**：

```python
import json

class Student(object):
    def __init__(self, name, age, score):
        self.name = name
        self.age = age
        self.score = score

s = Student('Bob', 20, 88)
print(json.dumps(s))        # TypeError: Student object is not JSON serializable
```

报错的原因很直接：**`dumps()` 默认只认识 `dict`、`list`、`str` 这些内置类型，它不知道一个 `Student` 实例该怎么变成一个 JSON 的 `{}`**。但 `dumps()` 留了一个扩展口子：**`default` 参数**。

### 用 `default` 告诉它怎么转

你写一个函数，把 `Student` 实例转成 `dict`，然后传给 `default`：

```python
def student2dict(std):                   # 接收一个对象，返回一个 dict
    return {
        'name': std.name,                # 把实例属性一个个取出来
        'age': std.age,
        'score': std.score
    }

print(json.dumps(s, default=student2dict))   # 现在能序列化了
```

流程是：`dumps` 遇到不认识的 `Student` 实例，**先把实例交给 `default` 函数**，函数返回一个 `dict`，`dumps` 再把这个 `dict` 正常转成 JSON。

### 偷懒通用写法：`lambda obj: obj.__dict__`

如果每个类都写一个转换函数太啰嗦。**大多数 class 的实例都有一个 `__dict__` 属性，它本身就是把实例变量装成 `dict` 的结果**，所以可以一步到位：

```python
print(json.dumps(s, default=lambda obj: obj.__dict__))
```

这个写法可能暴露对象内部字段，也不能处理所有对象或属性值。实际项目优先显式选择对外字段，验证数据结构；部分 `__slots__` 对象没有 `__dict__`。

### 反方向：`object_hook` 把 `dict` 还原成实例

`loads()` 默认把 JSON 转成 `dict`，但你拿到一个 `dict` 之后，往往想要的是 `Student` 实例。`loads()` 提供 **`object_hook` 参数**，让你插手“`dict` 怎么变成对象”这一步：

```python
def dict2student(d):                     # 接收 dumps 转出来的 dict
    return Student(d['name'], d['age'], d['score'])   # 用 dict 里的字段构造 Student 实例

json_str = '{"age": 20, "score": 88, "name": "Bob"}'
obj = json.loads(json_str, object_hook=dict2student)   # 反序列化结果直接是 Student 实例
print(obj)                                # <__main__.Student object at ...>
```

**`default` 管序列化方向（对象 → dict），`object_hook` 管反序列化方向（dict → 对象）**，两个参数配成一对。

## 一个中文坑：`ensure_ascii`

`json.dumps()` 默认 `ensure_ascii=True`，**中文会被转义成 `\uXXXX`**：

```python
obj = dict(name='小明', age=20)
print(json.dumps(obj, ensure_ascii=True))    # {"name": "\u5c0f\u660e", "age": 20}
print(json.dumps(obj, ensure_ascii=False))   # {"name": "小明", "age": 20}
```

**想让中文原样输出，加 `ensure_ascii=False`**。这个参数跟序列化本身无关，只影响“输出里中文怎么显示”，但实际项目里几乎每次都要处理。

## 什么时候用哪个

- **可信 Python 数据**：需要保留 Python 对象结构时可考虑 `pickle`，并检查协议及对象版本兼容；
- **要跨语言、走网络、存 Web 数据**：`json`，标准格式，谁都能读。

`json.dumps()` / `loads()` 的设计值得留意：**必填参数只有一个，满足 90% 的普通场景；`default` 和 `object_hook` 这两个可选参数，又把 class 实例这种复杂情况覆盖了**。接口简单，但不缺扩展性。
