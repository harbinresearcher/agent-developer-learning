> **重要程度：高**｜**手练：需要**
> 重点：起止步长、边界、浅拷贝与负索引。

`L[0:3]`表示，从索引`0`开始取，直到索引`3`为止，但不包括索引`3`。即索引`0`，`1`，`2`，正好是3个元素
 如果第一个索引是`0`，还可以省略

tuple 和 list 是不同类型的序列；tuple 不可变，list 可变。因此，tuple也可以用切片操作，只是操作的结果仍是tuple：

```plain
>>> (0, 1, 2, 3, 4, 5)[:3]
(0, 1, 2)
```


字符串是不可变序列，不是 list；按索引取到的元素是长度为 1 的字符串。因此，字符串也可以用切片操作，只是操作结果仍是字符串：

```plain
>>> 'ABCDEFG'[:3]
'ABC'
>>> 'ABCDEFG'[::2]
'ACEG'
```


## 边界与手练

切片写作 `序列[start:stop:step]`，结束位置不包含在结果中；负索引从末尾计数，负步长改变遍历方向。切片索引越界通常会被截到有效范围，但直接索引越界会抛异常。`list[:]` 是浅拷贝，嵌套的可变对象仍共享。

手练：分别取前 3 项、最后 2 项和倒序序列；对嵌套列表切片后修改内部列表，观察浅拷贝的影响。
