> **重要程度：中**｜**手练：建议**
> 重点：lambda 与普通函数、排序 key。

当我们在传入函数时，有些时候，不需要显式地定义函数，直接传入匿名函数更方便。
```plain
>>> list(map(lambda x: x * x, [1, 2, 3, 4, 5, 6, 7, 8, 9]))
[1, 4, 9, 16, 25, 36, 49, 64, 81]
```

关键字`lambda`表示匿名函数，冒号前面的`x`表示函数参数。匿名函数有个限制，就是只能有一个表达式，不用写`return`，返回值就是该表达式的结果。

此外，匿名函数也是一个函数对象，也可以把匿名函数赋值给一个变量，再利用变量来调用该函数：

```plain
>>> f = lambda x: x * x
>>> f
<function <lambda> at 0x101c6ef28>
>>> f(5)
25
```
同样，也可以把匿名函数作为返回值返回，比如：

```python
def build(x, y):
    return lambda: x * x + y * y
```
## 工作中怎么选

`lambda` 适合简短且含义明显的表达式，如 `sorted(records, key=lambda item: item['score'])`。逻辑复杂、需要文档或复用时，用有名字的 `def`。循环里创建函数时要留意闭包的延迟绑定，见 [[返回函数]]。

手练：按字典的分数字段排序，再把复杂排序规则改写为有名字的函数。
