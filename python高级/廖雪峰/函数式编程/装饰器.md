> **重要程度：高**｜**手练：需要**
> 重点：闭包、参数转发、functools.wraps。

函数对象有一个`__name__`属性（注意：是前后各两个下划线），可以拿到函数的名字：

```plain
>>> now.__name__
'now'
>>> f.__name__
'now'
```
现在，假设我们要增强`now()`函数的功能，比如，在函数调用前后自动打印日志，但又不希望修改`now()`函数的定义，这种在代码运行期间动态增加功能的方式，称之为“装饰器”（Decorator）。

把`@log`放到`now()`函数的定义处，相当于执行了语句：

```python
now = log(now)
```


## 工作中怎么用

装饰器接收函数并返回可调用对象。调用被装饰的函数时，包装函数可以在调用前后计时、记录日志或检查权限；应正确转发 `*args` 和 `**kwargs`，并返回原函数结果。原函数抛出异常时，要明确记录、清理或继续抛出，不能默认吞掉异常。

包装函数使用 `functools.wraps(原函数)` 可以保留名称、文档等元信息。带参数的装饰器多一层：先接收配置，再接收被装饰函数。多个装饰器从下往上应用，调用时按包装关系进入。

## 手练与自测

写一个计时装饰器，包装接收位置参数和关键字参数的函数。检查返回值、异常传播及 `__name__` 是否正确；再说明两个装饰器叠加时的执行顺序。
