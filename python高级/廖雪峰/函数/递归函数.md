# 递归函数

> **重要程度：中**｜**手练：需要**
> 重点：终止条件、递归状态、调用栈与复杂度。

递归函数把问题分解为规模更小的同类问题。每次调用要向终止条件靠近，并在终止条件返回结果，否则会无限递归。调用尚未返回时会保留调用栈帧。

普通 CPython 不做尾调用优化；把递归调用写在 `return` 中也不能消除递归深度限制。深度不可控时，可改用循环或显式栈；不要随意调高递归限制，否则可能耗尽栈空间。

时间和空间复杂度由具体递归决定：单链递归与重复计算的树形递归不同。对于重复子问题，可考虑缓存，但要先确认内存开销。

手练：写阶乘或树遍历，先明确空输入和终止条件，再用小输入画出调用与返回顺序。尝试改为迭代版本，比较结果。
