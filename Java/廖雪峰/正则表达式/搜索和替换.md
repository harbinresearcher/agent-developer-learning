# 搜索和替换

> **重要程度：中**｜**手练：建议**
> **重点**：find、replace 与转义。

## 核心概念

Matcher 的 find 可逐个查找匹配；replaceAll 和 replaceFirst 按模式替换文本。

## 工作中注意

替换字符串里的特殊字符可能有额外含义；需要按字面替换用户内容时，查阅 quoteReplacement 等 API。

## 手练

把测试文本中的多个编号替换为固定标记，检查第一个替换和全部替换的差异。

来源：[教程：搜索和替换](https://liaoxuefeng.com/books/java/reg-exp/search-replace/index.html)。
