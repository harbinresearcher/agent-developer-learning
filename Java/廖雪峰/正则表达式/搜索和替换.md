# 搜索和替换

> **重要程度：高**｜**手练：需要**
> **重点**：find、分组替换、转义用户内容。

## 解决什么问题

需要从文本中查找或替换符合规则的片段时，可使用 Matcher。`find()` 逐次寻找下一个匹配；`replaceAll` 替换所有匹配，`replaceFirst` 只替换第一个匹配。它们并不直接修改原 String。

## 完整例子

保存为 `RegexReplaceDemo.java`，编译运行；日志写到标准错误。

```java
import java.util.regex.Matcher;
import java.util.regex.Pattern;
import java.util.logging.Logger;
public class RegexReplaceDemo {
    private static final Logger logger = Logger.getLogger(RegexReplaceDemo.class.getName());
    public static void main(String[] args) {
        /*
         * ========================================================================
         * 步骤1：替换匹配片段
         * ========================================================================
         * 数据源：程序内的固定模式与文本
         * 操作：
         * 1) 构造正则表达式及匹配器
         * 2) 匹配、读取或替换并输出结果
         */
        logger.info("开始处理文本");
        // 1.1 查找并替换两个数字片段
        Pattern pattern = Pattern.compile("[0-9]+");
        String input = "A12 B34";
        String result = pattern.matcher(input).replaceAll("#");
        // 1.2 将带美元符号的替换值视为普通文本
        String literal = pattern.matcher("id=12").replaceAll(Matcher.quoteReplacement("$5"));
        System.out.println("result=" + result);
        System.out.println("literal=" + literal);
        logger.info("文本处理完成");
    }
}
```

标准输出：

```text
result=A# B#
literal=id=$5
```

## 执行过程

`[0-9]+` 找到输入中的 12 和 34，`replaceAll("#")` 返回新字符串 `A# B#`。第二次替换中，`$` 在替换字符串里可能代表捕获组引用；`Matcher.quoteReplacement("$5")` 把它转换为按字面值替换所需的形式，因此得到 `id=$5`。

## 模式和替换是两种语法

如果用户提供的搜索内容必须按普通文本处理，用 `Pattern.quote` 构造字面匹配模式；如果用户提供的替换内容必须按普通文本处理，用 `Matcher.quoteReplacement`。二者用途不同，不能互换。需要引用捕获组时，替换字符串可以按 API 的组引用语法处理，但必须验证组存在。

`Matcher` 保存匹配状态，成功查找后才能读取 group、start、end。`replaceAll` 会改变匹配器状态；重用时按 API 重置或创建新 Matcher。正则替换不等于 HTML 转义、SQL 参数化或密码脱敏策略，按具体边界使用专门工具。

## 手练与答案

把 `replaceAll` 换成 `replaceFirst`：第一行得到 `A# B34`。如果要把用户输入 `$5` 原样替换进去，应保留 `quoteReplacement`，不要把美元符号误解释为组引用。
