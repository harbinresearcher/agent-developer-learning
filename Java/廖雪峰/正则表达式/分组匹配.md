# 分组匹配

> **重要程度：高**｜**手练：需要**
> **重点**：捕获组编号、成功检查、格式和语义。

## 解决什么问题

不仅要知道文本是否符合格式，还可能需要提取其中的部分。捕获组用括号标记子表达式，匹配成功后可通过编号或名称读取对应文本。

## 完整例子

保存为 `RegexGroupDemo.java`，编译运行；日志写到标准错误。

```java
import java.util.regex.Matcher;
import java.util.regex.Pattern;
import java.util.logging.Logger;
public class RegexGroupDemo {
    private static final Logger logger = Logger.getLogger(RegexGroupDemo.class.getName());
    public static void main(String[] args) {
        /*
         * ========================================================================
         * 步骤1：提取日期文本的三个部分
         * ========================================================================
         * 数据源：程序内的固定模式与文本
         * 操作：
         * 1) 构造正则表达式及匹配器
         * 2) 匹配、读取或替换并输出结果
         */
        logger.info("开始处理文本");
        // 1.1 定义年、月、日三个捕获组
        Pattern pattern = Pattern.compile("([0-9]{4})-([0-9]{2})-([0-9]{2})");
        Matcher matcher = pattern.matcher("2024-03-09");
        // 1.2 完整匹配成功后读取各组
        if (matcher.matches()) {
            System.out.println("year=" + matcher.group(1));
            System.out.println("month=" + matcher.group(2));
            System.out.println("day=" + matcher.group(3));
        }
        logger.info("文本处理完成");
    }
}
```

标准输出：

```text
year=2024
month=03
day=09
```

## 执行过程

正则中三个括号分别捕获四位年份、两位月份和两位日期。`matches()` 先确认默认整个输入区域符合格式，再用 `group(1)`、`group(2)`、`group(3)` 依次取得 `2024`、`03`、`09`。`group(0)` 是整个匹配文本，不是第一个括号。

## 常见边界

在匹配成功前调用 `group` 会抛 `IllegalStateException`；访问不存在的组编号也会失败。可选捕获组未参与匹配时可能为 null，不能盲目调用其方法。非捕获分组 `(?:...)` 用于组织规则，不分配捕获组编号；命名组可按 Java Pattern 的语法声明和读取。

格式符合不代表日期真实存在：本模式也能匹配 `2024-13-99`。实际日期校验应再使用适当的 `LocalDate` 和严格解析规则，而不是把数字位数检查当成业务验证。

## 手练与答案

对 `2024-13-99`，正则能匹配，三个组仍能提取，但它不是有效日期。输入 `2024-3-9` 不符合两位月、日格式，因此 matches 返回 false。
