# 匹配规则

> **重要程度：高**｜**手练：需要**
> **重点**：字符类、量词、完整输入校验。

## 解决什么问题

需要判断一个输入是否符合约定时，正则可表达字符范围和重复次数。下面演示一个简单标识符规则：首字符为 ASCII 字母，总长度为 3～8，后续可包含字母、数字或下划线。

## 完整例子

保存为 `RegexRuleDemo.java`，编译运行；日志写到标准错误。

```java
import java.util.regex.Matcher;
import java.util.regex.Pattern;
import java.util.logging.Logger;
public class RegexRuleDemo {
    private static final Logger logger = Logger.getLogger(RegexRuleDemo.class.getName());
    public static void main(String[] args) {
        /*
         * ========================================================================
         * 步骤1：验证简单标识符
         * ========================================================================
         * 数据源：程序内的固定模式与文本
         * 操作：
         * 1) 构造正则表达式及匹配器
         * 2) 匹配、读取或替换并输出结果
         */
        logger.info("开始处理文本");
        // 1.1 定义首字符和其余字符规则
        Pattern rule = Pattern.compile("[A-Za-z][A-Za-z0-9_]{2,7}");
        // 1.2 对正常和边界输入执行完整匹配
        System.out.println("abc=" + rule.matcher("abc").matches());
        System.out.println("9abc=" + rule.matcher("9abc").matches());
        System.out.println("ab=" + rule.matcher("ab").matches());
        logger.info("文本处理完成");
    }
}
```

标准输出：

```text
abc=true
9abc=false
ab=false
```

## 执行过程

`[A-Za-z]` 匹配一个 ASCII 英文字母；`[A-Za-z0-9_]` 表示一个允许的后续字符；`{2,7}` 表示后续字符重复 2～7 次，所以总长度是 3～8。`matches()` 检查默认整个输入区域。abc 合格，9abc 首字符不合格，ab 长度不足。

## 基础符号

`[abc]` 表示其中一个字符，`[^abc]` 表示不在集合中的一个字符；`.` 默认匹配除特定行终止符外的任意字符；`?`、`*`、`+` 分别表示零或一次、零或多次、一次或多次。正则符号与 Java 字符串转义有两层规则，例如正则要表示反斜杠开头的数字类别时，Java 源码通常写成 `"\\d"`。

## 工作中怎么用

规则要对应业务定义：本例只允许 ASCII 字母，并不适合所有国际化用户名。限制长度应明确按字节、UTF-16 单元、码点还是用户感知字符计算；正则只是其中一种工具。不要对 null 输入直接调用 matcher 而不处理。

## 手练与答案

`"a_1"` 通过；`"a1"` 不通过（只有 2 个字符）；`"a1234567"` 通过（8 个字符）；再追加一个字符则超出上限。
