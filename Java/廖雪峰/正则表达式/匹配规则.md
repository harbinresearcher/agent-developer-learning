# 匹配规则

> **重要程度：中**｜**手练：建议**
> **重点**：字符类、数量词和锚点。

## 核心概念

字符类描述可匹配的字符，数量词描述重复次数，锚点描述位置。`matches()` 要求整体匹配，`find()` 查找匹配片段。

## 工作中注意

Java 源码字符串和正则表达式各自处理转义，反斜杠通常需要按 Java 字符串规则再转义。

## 手练

校验完整编号，再从句子中查找编号；比较 matches 和 find 的结果。

来源：[教程：匹配规则](https://liaoxuefeng.com/books/java/reg-exp/match-rules/index.html)。

## 关联知识与实践

Java 用 `Pattern` 编译表达式，用 `Matcher` 匹配。`matches()` 要求整个输入匹配，`find()` 查找下一个匹配片段；两者不能混用。括号形成分组；默认量词通常贪婪，后接 `?` 可改变匹配方式。

Java 字符串和正则表达式各有转义规则。例如表示正则数字类时，源码字符串中反斜杠需要按 Java 字符串规则转义。处理不可信输入时避免容易引发灾难性回溯的表达式，并限制输入长度。
