# 匹配规则

> **重要程度：中**｜**手练：建议**
> **重点**：字符类、数量词和锚点。

## 核心概念

字符类描述可匹配的字符，数量词描述重复次数，锚点描述位置。`matches()` 要求整体匹配，`find()` 查找匹配片段。

## 工作中注意

Java 源码字符串和正则表达式各自处理转义，反斜杠通常需要按 Java 字符串规则再转义。

## 手练

校验完整编号，再从句子中查找编号；比较 matches 和 find 的结果。
