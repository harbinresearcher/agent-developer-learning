# 处理注解

> **重要程度：中**｜**手练：建议**
> **重点**：反射读取、保留策略和框架处理。

## 核心概念

运行时可通过反射检查类或方法上的注解并读取元素；编译期注解处理器则在编译流程工作，二者发生时机不同。

## 工作中注意

读取不到注解时，检查保留策略、实际读取的元素及框架代理位置。处理过程需要明确错误行为，不应静默跳过关键校验。

## 手练

给方法添加自定义运行时注解并读取其值；移除运行时保留策略后比较结果。
