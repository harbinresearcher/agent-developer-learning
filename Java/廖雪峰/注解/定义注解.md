# 定义注解

> **重要程度：中**｜**手练：建议**
> **重点**：@Target、@Retention、成员默认值。

## 注解如何定义

`@interface` 定义注解类型。成员以类似无参数方法的语法声明，可以有默认值。元注解描述该注解能写在哪里、保留到什么阶段等规则。

## 完整例子

保存为 `DefineAnnotationDemo.java`，编译运行；日志写到标准错误。

```java
import java.lang.annotation.ElementType;
import java.lang.annotation.Retention;
import java.lang.annotation.RetentionPolicy;
import java.lang.annotation.Target;
import java.util.logging.Logger;
public class DefineAnnotationDemo {
    private static final Logger logger = Logger.getLogger(DefineAnnotationDemo.class.getName());
    public static void main(String[] args) {
        /*
         * ========================================================================
         * 步骤1：读取类型上的注解
         * ========================================================================
         * 数据源：标注了 Label 的类
         * 操作：
         * 1) 获取运行时注解
         * 2) 读取显式值与默认值
         */
        logger.info("开始读取注解");
        // 1.1 读取运行时注解
        Label label = Service.class.getAnnotation(Label.class);
        // 1.2 输出注解成员
        System.out.println("value=" + label.value());
        System.out.println("level=" + label.level());
        logger.info("注解读取完成");
    }
    @Retention(RetentionPolicy.RUNTIME)
    @Target(ElementType.TYPE)
    @interface Label {
        String value();
        int level() default 1;
    }
    @Label("订单服务")
    static class Service { }
}
```

标准输出：

```text
value=订单服务
level=1
```

## 执行过程

`@Target(ElementType.TYPE)` 允许 Label 标注类型声明；`@Retention(RetentionPolicy.RUNTIME)` 保留运行时所需信息，以便反射读取。`value()` 没有默认值，因此使用时必须提供；当唯一显式赋值成员名为 `value`，`@Label("订单服务")` 是简写。`level()` 有默认值 1，使用时省略即可。

`getAnnotation(Label.class)` 读取 Service 上的注解，本例确定它存在，所以随后访问其成员。一般工具处理不确定的类时要先检查结果是否为 null。

## 保留策略和约束

`SOURCE` 主要用于源码阶段；`CLASS` 记录在 class 文件但运行时不要求保留；`RUNTIME` 保留到运行时以供反射。没有声明 `@Retention` 时默认是 CLASS。`@Target` 的可选位置包括 TYPE、METHOD、FIELD、PARAMETER 等；误用到不允许的位置会编译失败。

成员类型和默认值受 Java 注解语法限制，不能任意使用普通对象或在运行时动态计算。注解成员不是普通方法体；注解也不会因为声明了成员就自动校验业务。

## 工作中怎么用

为约定设计明确的名称、默认值、适用位置和读取阶段；让处理器明确如何处理缺少注解与无效配置。不要通过注解存储密钥等敏感数据。

## 手练与答案

把 `level()` 改为 `default 2`：输出 level=2。移除 `RUNTIME` 保留策略后默认是 CLASS，运行时反射通常读不到 Label；示例随后直接访问成员会因 null 抛 `NullPointerException`，应先做缺失检查。
