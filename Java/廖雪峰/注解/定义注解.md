# 定义注解

> **重要程度：中**｜**手练：建议**
> **重点**：@interface、Target、Retention 和默认值。

## 核心概念

自定义注解用 `@interface` 声明元素；`@Target` 控制可标注位置，`@Retention` 控制信息保留到源码、class 或运行时。

## 工作中注意

要通过运行时反射读取，通常选择 `RetentionPolicy.RUNTIME`；注解元素类型和默认值有语言层面的限制。

## 手练

定义一个只能用于方法、保留到运行时的注解，加入一个带默认值的元素。
