# 使用注解

> **重要程度：高**｜**手练：建议**
> **重点**：注解的元数据作用和常见注解。

## 核心概念

注解给程序元素附加元数据。`@Override` 让编译器检查重写关系，`@Deprecated` 表达弃用信息；框架注解的语义由框架在对应阶段解释。

## 工作中注意

写上注解不等于自动实现逻辑：必须有编译器、处理器、容器或框架读取并处理它。不同框架对位置和生命周期的要求不同。

## 手练

在重写方法上添加 `@Override`，故意写错方法名观察编译错误；阅读一个框架注解对应文档。
