# 网络编程基础

> **重要程度：高**｜**手练：需要**
> **重点**：IP 地址、端口、TCP 与 UDP。

## 先认识地址、端口和协议

IP 地址标识网络中的地址，端口用于区分主机上的通信端点；地址加端口还需要结合 TCP 或 UDP 等传输协议理解。域名通过 DNS 等机制解析成地址，但解析结果可能变化，也可能包含多个地址。

## 完整例子

保存为 `NetworkBasicsDemo.java`，编译运行；日志写到标准错误。例子只构造本地地址对象，不连接外部服务。

```java
import java.net.InetAddress;
import java.net.InetSocketAddress;
import java.util.logging.Logger;
public class NetworkBasicsDemo {
    private static final Logger logger = Logger.getLogger(NetworkBasicsDemo.class.getName());
    public static void main(String[] args) throws Exception {
        /*
         * ========================================================================
         * 步骤1：检查本地地址和端口
         * ========================================================================
         * 数据源：IPv4 回环地址和演示端口
         * 操作：
         * 1) 构造地址与端点
         * 2) 检查地址类型和端口
         */
        logger.info("开始检查网络端点");
        // 1.1 使用固定本地回环地址
        InetAddress address = InetAddress.getByName("127.0.0.1");
        InetSocketAddress endpoint = new InetSocketAddress(address, 8080);
        // 1.2 查看地址属性和端口
        System.out.println("loopback=" + address.isLoopbackAddress());
        System.out.println("address=" + address.getHostAddress());
        System.out.println("port=" + endpoint.getPort());
        logger.info("网络端点检查完成");
    }
}
```

标准输出：

```text
loopback=true
address=127.0.0.1
port=8080
```

## 执行过程

`127.0.0.1` 是 IPv4 回环地址，表示本机回环网络；`InetSocketAddress` 将它与端口 8080 组合。这里只是创建端点表示，`getPort()` 返回 8080 并不代表该端口有服务在监听，更不代表防火墙允许访问。

## TCP、UDP 和应用协议

TCP 提供连接上的有序字节流，不保留应用层消息边界；一次发送未必对应一次读取。UDP 传输独立数据报，不保证送达、顺序或去重。HTTP、SMTP 等是更高层的应用协议；选择 TCP 并不自动让应用具有正确的重试、认证或业务一致性。

网络调用可能遇到 DNS 失败、连接失败、超时、对端中断和部分成功。连接超时与读超时是不同配置；TLS 用于保护传输时仍需正确验证证书和主机名。

## 工作中怎么用

先明确协议、目标地址、端口、数据格式、超时、资源关闭和错误处理。业务系统通常使用成熟客户端而非重新实现底层协议；重试写请求前确认幂等规则。回环测试只能证明本机路径，不能证明跨机器网络、TLS 或生产服务可用。

## 手练与答案

把端口改成 8081：输出 port=8081，但仍没有创建或连接服务。`127.0.0.1` 指当前运行程序的机器或容器网络命名空间，不能把它当作远程服务器的通用地址。
