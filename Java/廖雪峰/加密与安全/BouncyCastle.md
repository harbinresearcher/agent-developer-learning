# BouncyCastle

> **重要程度：低**｜**手练：按需**
> **重点**：安全提供者与依赖版本。

## 核心概念

Bouncy Castle 是 Java 密码学相关库和提供者，提供额外算法和接口；是否需要取决于项目及目标运行环境已有能力。

## 工作中注意

从可信来源引入、按项目策略维护版本；不能因为算法可用就认为适合当前安全需求。

## 手练

查看测试项目中安全提供者列表，说明何时需要额外提供者。

来源：[教程：BouncyCastle](https://liaoxuefeng.com/books/java/security/bouncy-castle/index.html)。
