# 非对称加密算法

> **重要程度：中**｜**手练：按需**
> **重点**：公钥私钥与适用范围。

## 核心概念

非对称密码体系使用公钥和私钥；公钥可分发，私钥必须保护。具体算法和操作用途不同，不应把签名、加密和密钥交换混为一谈。

## 工作中注意

实际协议常用非对称技术建立信任或协商密钥，再用对称加密处理数据；不要自行设计填充与组合方式。

## 手练

解释公钥和私钥分别由谁持有，以及私钥泄露后需要采取什么措施。

来源：[教程：非对称加密算法](https://liaoxuefeng.com/books/java/security/rsa/index.html)。

## 关联知识与实践

对称加密双方使用共享密钥；非对称加密有公钥和私钥。数字签名用于验证持有私钥的一方签署的内容，证书用于建立身份与公钥之间的信任关系。实际项目使用成熟库与明确的安全协议，不自创算法或把密钥提交到仓库。

来源：[教程：加密与安全](https://liaoxuefeng.com/books/java/security/index.html)；[OWASP 密码存储](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)。
