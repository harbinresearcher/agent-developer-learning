# 编码算法

> **重要程度：中**｜**手练：建议**
> **重点**：Base64、编码和加密的区别。

## 核心概念

Base64 把二进制表示为文本，便于在文本协议中传输；任何人都可以按规则解码，它不提供保密性。

## 工作中注意

标准 Base64 与 URL 安全变体字符集不同，填充和解码规则应按协议约定；不要把 Base64 当作密码保护。

## 手练

编码一段测试文本再解码；解释为什么不能用 Base64 保护令牌。
