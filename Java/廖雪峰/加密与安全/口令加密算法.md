# 口令加密算法

> **重要程度：高**｜**手练：建议**
> **重点**：密码哈希、独立盐和成本参数。

## 核心概念

用户密码应使用专门的密码哈希算法，例如 Argon2id，使用独立随机盐和适当成本参数；登录时调用同一库的验证接口。

## 工作中注意

不要保存明文，不要直接用 MD5、SHA-256 或单次 HMAC 保存密码。参数和库版本按当前安全指南及服务负载核定。

## 手练

在隔离项目中使用成熟库生成并验证密码哈希；验证错误密码失败，且不打印真实密码。

来源：[教程：口令加密算法](https://liaoxuefeng.com/books/java/security/pbe/index.html)；[OWASP 密码存储](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)。

## 关联知识与实践

用户密码不要明文存储，也不要只做一次 MD5、SHA-256 或 HMAC。优先使用成熟库提供的 Argon2id 等密码哈希算法，并使用独立随机盐和适当成本参数。盐通常不需要保密；密钥或 pepper 需要单独保护。

用可信的测试数据计算 SHA-256；对比同一消息的摘要与 HMAC。解释为什么它们都不能替代专用密码哈希算法。

来源：[教程：加密与安全](https://liaoxuefeng.com/books/java/security/index.html)；[OWASP 密码存储](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)。
