# 口令加密算法

> **重要程度：高**｜**手练：建议**
> **重点**：密码哈希、独立盐和成本参数。

## 核心概念

用户密码应使用专门的密码哈希算法，例如 Argon2id，使用独立随机盐和适当成本参数；登录时调用同一库的验证接口。

## 工作中注意

不要保存明文，不要直接用 MD5、SHA-256 或单次 HMAC 保存密码。参数和库版本按当前安全指南及服务负载核定。

## 手练

在隔离项目中使用成熟库生成并验证密码哈希；验证错误密码失败，且不打印真实密码。
