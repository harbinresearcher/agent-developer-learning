# 哈希算法

> **重要程度：高**｜**手练：需要**
> **重点**：摘要、完整性和密码哈希区别。

## 核心概念

SHA-256 等摘要把输入映射成固定长度结果；相同输入得到相同摘要，但不同输入理论上可能碰撞。

## 工作中注意

普通摘要不能在攻击者可同时替换内容和摘要时证明来源；一次快速 SHA-256 不适合直接保存密码。

## 手练

对测试文件计算 SHA-256，修改一个字节后重算；说明摘要被替换时校验的局限。
