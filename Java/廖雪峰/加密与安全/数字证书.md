# 数字证书

> **重要程度：中**｜**手练：按需**
> **重点**：证书、公钥、信任链与有效期。

## 核心概念

数字证书将公钥与身份信息绑定，并由颁发机构签名；TLS 客户端依据配置的信任锚、域名及有效期等规则验证证书。

## 工作中注意

不能为了让 HTTPS 请求成功而关闭证书和主机名验证；证书过期、名称不匹配或信任链错误应定位原因。

## 手练

检查一个测试服务证书的域名和有效期；解释为什么仅有证书并不代表一定可信。
