# IO 与文件

> **重要程度：高**｜**手练：需要**
> **重点**：字节流与字符流、编码、`try-with-resources`、`Path` 与 `Files`。

## 先分类型

`InputStream` / `OutputStream` 处理字节；`Reader` / `Writer` 处理字符。字节转文本要约定编码，例如 UTF-8；图片、压缩包等二进制内容不要随意按文本解码。缓冲流减少频繁的小块读写；实际性能需测量。

使用 `try-with-resources` 确保文件和流关闭。`Path` 表达路径，`Files` 提供读取、写入、遍历等操作；大文件优先流式处理，不要无条件一次读入内存。相对路径相对于进程工作目录，不能假设总是源码目录。

## 文件与安全

读取 classpath 资源与读取普通文件是两种路径：打包进 JAR 后，资源不一定是可直接操作的系统文件。处理 ZIP 等归档时，解压路径必须限制在目标目录内，防止目录穿越；避免解压不受限制的大量数据。

Java 原生对象反序列化不适合直接处理不可信数据。系统边界优先使用可验证的数据格式，明确数据结构和大小限制。

## 手练

读取 UTF-8 文本并统计行数；复制一个二进制文件，比较复制前后的摘要；测试文件不存在和提前中断时资源是否关闭。
