# 流程控制与数组

> **重要程度：高**｜**手练：需要**
> **重点**：条件分支、循环边界、`break` 与 `continue`；数组遍历和排序。

## 判断与循环

`if / else` 根据布尔条件选择分支。传统 `switch` 要注意 `case` 后是否需要 `break`，否则可能继续执行后续分支；现代 `switch` 表达式可使用箭头形式，但要检查项目 JDK 版本。

`while` 先判断再执行，`do ... while` 至少执行一次；`for` 适合已知遍历范围。`break` 退出当前循环或 `switch`；`continue` 跳过当前循环的剩余部分，进入下一轮。多层循环中，它们默认只作用于最近一层。

## 数组

普通 `for` 可以拿到下标，增强 `for` 适合只读取元素。注意循环条件使用 `< array.length`，不要访问 `array[array.length]`。`Arrays.sort(array)` 原地排序；对原始数组排序会改变原数据。`Arrays.toString(array)` 便于查看一维数组内容。

`main(String[] args)` 接收命令行参数；参数都是字符串，转数字要处理格式错误。不要在未经检查时直接读取 `args[0]`。

## 手练

遍历一组成绩，输出最高分和平均分；分别用 `for` 与增强 `for` 写一遍。再构造空数组，说明最高分是否存在；排序前复制数组，检查原数组是否改变。
