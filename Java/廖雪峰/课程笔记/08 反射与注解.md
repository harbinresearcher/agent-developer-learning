# 反射与注解

> **重要程度：中**｜**手练：建议**
> **重点**：`Class`、字段和方法反射；注解的保留策略；理解框架如何读取元数据。

## 反射

反射允许程序在运行时查看类、字段、方法和构造器。获取 `Class` 可从类字面量、实例的 `getClass()` 或类名加载；`getMethod` 查找公开方法，`getDeclaredMethod` 查找本类声明的方法，二者范围不同。

运行时通过反射调用需要处理访问限制、异常和类型转换。模块系统可能限制对内部成员的访问。业务代码优先使用明确接口；框架或通用工具需要动态处理未知类型时再考虑反射。

动态代理常用于为接口方法附加行为，如日志、权限或事务。JDK 动态代理以接口为基础；调用目标方法时仍要处理异常和返回值。

## 注解

注解是附加元数据，不会因为写在代码上就自动实现业务逻辑。`@Target` 限制使用位置，`@Retention` 决定保留范围；需要运行时反射读取时通常使用 `RUNTIME`。具体行为由编译器、注解处理器或框架解释。

## 手练

给自定义注解设置运行时保留策略，标到一个方法上，再用反射读取；解释不使用 `RUNTIME` 时会怎样。
