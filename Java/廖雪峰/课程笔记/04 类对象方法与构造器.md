# 类、对象、方法与构造器

> **重要程度：高**｜**手练：需要**
> **重点**：类与实例、字段封装、方法调用、重载、构造器和参数传递。

## 类和对象

类描述字段和方法；`new` 根据类创建对象。对象的实例字段分别属于各对象；`static` 字段属于类，多个实例共享。把一个引用变量赋给另一个变量时，不会复制对象，两者可以指向同一个对象。

封装不是给每个字段机械地生成 getter/setter。应由类维护自己的约束，例如不允许年龄为负数；外部通过合适的方法使用对象。

## 方法

方法的签名包含方法名和参数类型列表。相同方法名、不同参数列表可以重载；只改返回类型不能构成重载。调用时参数按值传递：基本类型传入值的副本，引用类型传入引用值的副本。方法内修改引用所指对象可能影响调用者，但重新给参数赋一个新引用不会改变调用者的变量。

## 构造器

构造器在创建实例时初始化对象；构造器没有返回类型。默认无参构造器只在没有声明任何构造器时自动生成。`this(...)` 用于调用同类的其他构造器，必须放在构造器第一条语句。

完整可运行示例和练习：[[面向对象编程/面向对象基础/构造方法|构造方法]]。

## 手练

创建两个学生对象，修改其中一个字段，检查另一个是否受影响；再把同一个可变对象传进方法，分别尝试修改对象内容和重新赋值参数，比较结果。
