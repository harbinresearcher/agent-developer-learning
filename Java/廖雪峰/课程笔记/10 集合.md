# 集合

> **重要程度：高**｜**手练：需要**
> **重点**：List、Map、Set、队列、迭代器；`equals` 与 `hashCode` 契约。

## 先按需求选

`List` 保留元素顺序、允许通过下标访问；`ArrayList` 适合常见随机访问。`Map` 保存键值对；`HashMap` 不承诺遍历顺序，`LinkedHashMap` 可保留可预测的顺序，`TreeMap` 按比较规则排序。`Set` 表达不重复元素。`Queue`、`Deque` 适合队列、双端队列和栈操作；新代码通常优先考虑 `Deque` 而不是旧 `Stack`。

## 相等与哈希

两个对象按 `equals` 相等时，它们的 `hashCode` 必须相同；哈希相同不代表对象一定相等。把可变对象作为哈希键时，若参与相等判断的字段在放入后发生变化，可能导致无法按预期查找。不要直接用 `==` 判断两个字符串的内容相等。

遍历集合时，不能随意通过集合自身结构修改方法删除元素；需要删除时按集合和迭代器契约处理，或先收集再修改。快速失败迭代器是排错辅助，不能作为并发正确性保障。

## 手练

统计一段文本的词频；比较 `HashMap` 与 `TreeMap` 的输出顺序。自定义键对象并同时实现 `equals`、`hashCode`，验证两个内容相同的键如何查找。
