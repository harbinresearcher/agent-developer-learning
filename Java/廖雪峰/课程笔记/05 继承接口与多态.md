# 继承、接口与多态

> **重要程度：高**｜**手练：需要**
> **重点**：重写与重载、向上转型、动态分派、抽象类与接口、组合。

## 继承与重写

子类用 `extends` 继承一个直接父类。实例方法重写时，运行时根据实际对象类型选择实现；编译时仍按引用声明类型检查可访问的方法。`@Override` 让编译器帮助检查是否真的重写。

重载是同类中方法名相同、参数列表不同；重写是子类提供继承方法的新实现。静态方法属于类，不能按实例方法的方式动态重写。

构造器不会被继承。子类构造时先完成父类部分的初始化，再初始化子类字段并执行构造器剩余代码。需要显式调用父类构造器时使用 `super(...)`，调用必须位于适用语言版本规定的位置，入门按第一条语句记忆。

## 抽象类与接口

抽象类不能直接实例化，可以定义状态和已实现的方法；接口用于描述能力和契约，一个类可以实现多个接口。选型先看业务关系：有“是什么”的稳定继承关系再用继承；需要组合多个独立能力时，通常优先考虑组合。

## 手练

创建一个接口和两个实现，让同一个调用方法接收接口类型；观察运行时执行的是哪个实现。分别写一个重载和一个重写，说明编译期与运行期如何选择。
