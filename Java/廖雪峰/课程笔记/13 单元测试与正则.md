# 单元测试与正则表达式

> **重要程度：高**｜**手练：需要**
> **重点**：JUnit 断言、异常和参数化测试；正则全匹配、分组与转义。

## 单元测试

测试描述可观察行为：准备输入、调用目标、断言结果。正常值、边界值和失败路径都应考虑。JUnit 提供断言、异常测试、测试前后准备与清理，以及参数化测试；具体注解和版本按项目依赖确定。

单元测试应尽量独立、可重复，不依赖真实网络或时间；需要验证数据库、框架配置和多个组件协作时，再编写相应集成测试。测试通过只证明已覆盖的检查通过。

## 正则表达式

Java 用 `Pattern` 编译表达式，用 `Matcher` 匹配。`matches()` 要求整个输入匹配，`find()` 查找下一个匹配片段；两者不能混用。括号形成分组；默认量词通常贪婪，后接 `?` 可改变匹配方式。

Java 字符串和正则表达式各有转义规则。例如表示正则数字类时，源码字符串中反斜杠需要按 Java 字符串规则转义。处理不可信输入时避免容易引发灾难性回溯的表达式，并限制输入长度。

## 手练

给年龄校验写正常、边界和异常测试；写一个正则校验完整编号，再用 `find()` 从句子中提取编号，比较结果。
