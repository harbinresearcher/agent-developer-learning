# 日期与时间

> **重要程度：高**｜**手练：需要**
> **重点**：`Instant`、`LocalDateTime`、`ZonedDateTime`、时区转换与格式化。

## 选择正确类型

`Instant` 表示时间线上的时刻；`LocalDate` 只有日期；`LocalDateTime` 有日期和钟表时间但没有时区，不能单独确定全球唯一时刻；`ZonedDateTime` 包含时区规则。`Date` 和 `Calendar` 是旧 API，维护旧项目可能遇到，新代码通常优先使用 `java.time`。

系统间传递时间点时应明确偏移或使用 UTC，并约定精度。用户日程如果依赖地区规则，还要保存 `Asia/Shanghai` 这样的地区时区；固定偏移不能完整描述夏令时变化。时间戳的秒和毫秒不要混淆。

`DateTimeFormatter` 负责格式化和解析，格式符号区分大小写；日历年份一般用 `yyyy` 或按需求使用 `uuuu`，不要误用周基年 `YYYY`。

## 手练

把一个 UTC 时间点转换到两个地区时区，比较时间点是否相同；解析无时区字符串时，说明还缺什么信息。构造跨年日期，比较 `yyyy` 与 `YYYY` 的含义。
