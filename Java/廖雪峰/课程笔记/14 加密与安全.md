# 加密与安全

> **重要程度：高**｜**手练：建议**
> **重点**：区分编码、哈希、认证码和加密；了解密码存储与密钥管理。

Base64 是编码，不提供保密性。SHA-256 等摘要用于完整性校验；若攻击者能同时替换内容和摘要，普通摘要不能证明来源。HMAC 用共享密钥校验消息完整性和真实性；它不加密内容，也不能防止重放，协议可能需要时间戳或随机数。

对称加密双方使用共享密钥；非对称加密有公钥和私钥。数字签名用于验证持有私钥的一方签署的内容，证书用于建立身份与公钥之间的信任关系。实际项目使用成熟库与明确的安全协议，不自创算法或把密钥提交到仓库。

用户密码不要明文存储，也不要只做一次 MD5、SHA-256 或 HMAC。优先使用成熟库提供的 Argon2id 等密码哈希算法，并使用独立随机盐和适当成本参数。盐通常不需要保密；密钥或 pepper 需要单独保护。

## 手练

用可信的测试数据计算 SHA-256；对比同一消息的摘要与 HMAC。解释为什么它们都不能替代专用密码哈希算法。
