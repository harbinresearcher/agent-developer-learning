# JDBC 与事务

> **重要程度：高**｜**手练：需要**
> **重点**：参数化 SQL、连接和结果集关闭、事务提交回滚、连接池。

## 查询链路

JDBC 提供连接数据库的标准接口，具体数据库需要对应驱动。常见流程是：从数据源取得连接 → 创建 `PreparedStatement` → 设置参数 → 执行 → 读取 `ResultSet` → 关闭资源。用参数占位符传入值，不拼接不可信输入；表名、列名等通常不能直接作为值参数，需要白名单控制。

## 事务

单个业务操作涉及多次修改时，要明确事务边界。关闭自动提交后，成功时提交，失败时回滚，并在连接归还连接池前恢复或由框架管理连接状态。事务提供一致性保障，但不能替代唯一约束、并发控制和幂等设计。

批处理可以降低多次往返的开销，结果和失败处理依赖驱动。连接池复用连接，不等于无限连接；要设置容量、超时并及时归还，避免连接耗尽。

## 手练

在测试数据库里插入和查询数据，再模拟第二步失败，验证两步修改一起回滚。用恶意输入测试参数化查询，确认它被当作值处理。
