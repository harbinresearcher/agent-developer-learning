# 包、访问范围与核心类

> **重要程度：高**｜**手练：需要**
> **重点**：包和访问修饰符、类路径、字符串、包装类型、枚举、BigDecimal。

## 组织代码

`package` 声明所属包，`import` 引入类型名；完整类名包含包名。`public` 对外可见，`private` 限制在类内部，未写修饰符是包访问权限，`protected` 还涉及子类访问规则。`static` 成员与具体实例无关；静态方法不能直接使用 `this`。

JAR 是打包后的归档文件，类路径决定运行时在哪里寻找类。项目通常由 Maven 等构建工具管理依赖，不要把机器上的绝对路径写死到源码中。模块系统有独立的可读性和导出规则，初学先掌握包与依赖。

## 常用类型

- `String` 不可变；循环拼接较多字符串时可考虑 `StringBuilder`。有分隔符的拼接可用 `StringJoiner`。
- `Integer` 等包装类型可以与基本类型自动装箱、拆箱；对 `null` 拆箱会抛 `NullPointerException`。
- `enum` 适合表达有限状态；对外存储使用稳定的约定值，谨慎依赖序号 `ordinal()`。
- `BigInteger` 处理超出固定整型范围的整数；`BigDecimal` 处理需要十进制精度的数，金额通常从字符串构造，并明确舍入模式。
- `record` 可简化不可变数据载体定义，正式可用自 Java 16；是否使用取决于项目 JDK。

## 手练

把两个类放进不同包，验证访问修饰符；比较字符串内容和对象引用；用 `BigDecimal` 计算金额并规定两位小数。
