# 泛型

> **重要程度：高**｜**手练：需要**
> **重点**：泛型类和方法、类型擦除、`? extends` 与 `? super`。

## 为什么需要泛型

泛型让容器和方法在编译时表达元素类型，例如 `List<String>`；它减少显式强制转换，并让类型不匹配尽早暴露。泛型类型参数不能直接使用 `int` 等基本类型，需要包装类型如 `Integer`。

Java 泛型主要通过类型擦除实现。运行时通常不能仅凭对象区分 `List<String>` 和 `List<Integer>`；不要把泛型当作运行时完整类型检查。数组与泛型的规则不同，混用时要特别小心。

## 通配符

`List<Integer>` 不是 `List<Number>` 的子类型。读取一组数值时，`List<? extends Number>` 可以接收 `Integer` 或其他 `Number` 子类型的列表；除了 `null` 外，不能安全地向其中添加普通元素。

向集合写入 `Integer` 时，`List<? super Integer>` 可以接受 `Integer` 或它的父类型列表；读取时一般只能安全地按 `Object` 使用。常用记忆：生产者用 `extends`，消费者用 `super`；具体仍以数据流向判断。

## 手练

写一个读取数字列表的求和方法和一个向列表添加整数的方法，分别选择合适的通配符；试着用不匹配的类型编译，读懂报错。
