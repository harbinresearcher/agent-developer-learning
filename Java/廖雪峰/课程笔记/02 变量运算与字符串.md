# 变量、运算与字符串

> **重要程度：高**｜**手练：需要**
> **重点**：基本类型和引用类型；整数除法与溢出；字符串比较；数组默认值。

## 变量与类型

变量先声明、赋值后使用。Java 有 `byte`、`short`、`int`、`long`、`float`、`double`、`char`、`boolean` 八种基本类型。引用类型变量保存引用，可以指向对象或为 `null`。

局部变量使用前必须明确赋值；实例字段和数组元素会获得默认值，如 `int` 为 `0`、`boolean` 为 `false`、引用为 `null`。`final` 限制变量再次赋值；引用设为 `final` 不代表对象本身不可变。

## 数字与布尔

- `5 / 2` 的结果是整数 `2`；参与浮点运算时才有小数结果。整数可能溢出；整数除以零会抛 `ArithmeticException`。
- 二进制浮点数不能精确表示所有十进制小数。金额计算通常使用 `BigDecimal`，并明确精度和舍入规则。
- `&&`、`||` 会短路：左侧已能决定结果时，右侧不再计算；`!` 取反。
- `long` 字面量可写 `100L`，`float` 常写 `1.0f`；窄化类型转换可能丢失信息。

## 字符串与数组

`String` 不可变。比较文本内容用 `equals` 或 `Objects.equals(a, b)`；`==` 对引用比较是否指向同一对象。`char` 是 UTF-16 代码单元，不能保证单个 `char` 就是一个完整 Unicode 字符。

数组长度固定，下标从 `0` 到 `length - 1`；越界抛异常。引用类型数组存的是引用；二维数组可理解为数组的数组，行长度可以不同。
