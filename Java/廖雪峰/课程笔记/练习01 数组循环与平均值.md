# 手练：数组、循环与平均值

> **重要程度：高**｜**手练：需要**
> **重点**：数组下标、循环边界、整数与浮点运算。

将下面代码保存为 `ScoreDemo.java`。运行命令：`javac -encoding UTF-8 ScoreDemo.java`，随后运行 `java ScoreDemo`。

```java
import java.util.logging.Logger;

public class ScoreDemo {
    private static final Logger logger = Logger.getLogger(ScoreDemo.class.getName());

    public static void main(String[] args) {
        /*
         * ========================================================================
         * 步骤1：统计成绩
         * ========================================================================
         * 目标：计算最高分和平均分。
         * 数据源：本地成绩数组。
         * 操作：
         * 1) 逐项计算总分和最高分。
         * 2) 将总分转换为浮点数后求平均值。
         */
        logger.info("开始统计成绩");
        // 1.1 准备非空数组和初始值
        int[] scores = {80, 90, 100};
        int total = 0;
        int highest = scores[0];
        // 1.2 遍历数组并更新统计值
        for (int i = 0; i < scores.length; i++) {
            total += scores[i];
            if (scores[i] > highest) {
                highest = scores[i];
            }
        }
        // 1.3 输出结果
        double average = (double) total / scores.length;
        System.out.println("最高分: " + highest);
        System.out.println("平均分: " + average);
        logger.info("成绩统计完成");
    }
}
```

`i < scores.length` 避免越界。先把总分转成 `double`，除法才会保留小数。本例明确使用非空数组；如果成绩来自外部输入，读取 `scores[0]` 前要检查数组是否为空。
