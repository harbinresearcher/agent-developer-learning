# 输入和输出

> **重要程度：高**｜**手练：需要**
> **重点**：按行读取、格式化输出、输入边界。

## 输入和输出是什么

标准输入通常连接终端，也可以来自管道；标准输出通常显示结果，标准错误常用来输出日志或错误。`System.out.println` 输出内容并换行；`System.out.printf` 按格式输出，不会自动换行，`%n` 表示平台换行符。

## 完整例子

保存为 `ConsoleDemo.java`，编译后运行，输入一行姓名并按回车。验证时输入 `小明`；标准输出如下，日志写到标准错误。

```java
import java.util.logging.Logger;
import java.util.Scanner;

public class ConsoleDemo {
    private static final Logger logger = Logger.getLogger(ConsoleDemo.class.getName());

    public static void main(String[] args) {
        /*
         * ========================================================================
         * 步骤1：读取一整行输入
         * ========================================================================
         * 数据源：标准输入
         * 操作：
         * 1) 读取或准备示例数据
         * 2) 处理数据并输出结果
         */
        logger.info("开始处理示例");
        // 1.1 从标准输入读取一整行
        Scanner scanner = new Scanner(System.in);
        String name = scanner.nextLine();
        // 1.2 格式化输出结果
        System.out.printf("你好，%s%n", name);
        logger.info("示例处理完成");
    }
}
```

标准输出：

```text
你好，小明
```

## 执行过程

`new Scanner(System.in)` 创建读取标准输入的扫描器。`nextLine()` 读取一整行并去掉行末换行符，因此带空格的姓名也能完整读到。`printf` 中 `%s` 对应后面的字符串参数，`%n` 输出换行。代码没有关闭扫描器：关闭它也会关闭底层 `System.in`；应用如果后续还要使用标准输入，需要统一管理其生命周期。

`nextInt()` 按整数读取，不会消费后面的行结束符。如果紧接着调用 `nextLine()`，它可能只读到该行剩余内容，看起来像空行。初学时可以统一按行读取，再用 `Integer.parseInt` 转换，并处理空行和无效数字。输入结束时 `nextLine()` 可能抛出异常；实际工具要考虑 EOF，例如先用 `hasNextLine()` 判断。

## 常用输出与工作用法

`print` 不自动换行；`println` 自动换行；`printf("%.2f", value)` 按两位小数格式化显示。格式化是展示，不会改变变量本身的值；小数和日期的展示还受区域设置影响。服务端程序通常用日志框架记录诊断信息，避免把密码或令牌写入日志。

## 手练与答案

1. 输入 `Ada Lovelace`：输出 `你好，Ada Lovelace`，空格会保留。
2. 把 `nextLine()` 改成 `next()` 后输入同样内容：只读取第一个以空白分隔的词，输出 `你好，Ada`。
