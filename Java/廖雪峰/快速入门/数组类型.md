# 数组类型

> **重要程度：高**｜**手练：需要**
> **重点**：创建数组、理解长度与下标、查看默认值、区分数组和普通变量。

## 数组解决什么问题

要保存 3 个学生的成绩，可以分别声明 3 个变量；更方便的做法是使用一个 `int[]`。数组把相同类型的多个元素按顺序组织起来，每个元素用下标访问。

数组本身是对象；变量保存对数组对象的引用。数组创建后长度固定。如果需要经常增加或删除元素，可以继续学习 [[使用List]]。

## 完整例子

保存为 `ArrayDemo.java`，执行 `javac -encoding UTF-8 ArrayDemo.java`，再执行 `java ArrayDemo`。
```java
import java.util.Arrays;
import java.util.logging.Logger;

public class ArrayDemo {
    private static final Logger logger = Logger.getLogger(ArrayDemo.class.getName());

    public static void main(String[] args) {
        /*
         * ========================================================================
         * 步骤1：创建并修改整数数组
         * ========================================================================
         * 目标：观察数组长度、默认值和索引。
         * 数据源：长度为 3 的整数数组。
         * 操作：
         * 1) 创建数组并查看默认值。
         * 2) 修改第一个元素并输出。
         */
        logger.info("开始处理数组");
        // 1.1 创建数组并查看长度与初始内容
        int[] scores = new int[3];
        System.out.println("长度: " + scores.length);
        System.out.println("初始: " + Arrays.toString(scores));
        // 1.2 修改第一个元素并查看结果
        scores[0] = 80;
        System.out.println("修改后: " + Arrays.toString(scores));
        logger.info("数组处理完成");
    }
}
```

标准输出依次为 `长度: 3`、`初始: [0, 0, 0]`、`修改后: [80, 0, 0]`。

### 按步骤看

1. `new int[3]` 创建含 3 个整数元素的数组。整数数组的元素初始值为 0。
2. `scores.length` 是数组长度，结果是 3；下标从 0 开始，因此合法下标为 0、1、2。
3. `scores[0] = 80` 只修改第一个元素。
4. `Arrays.toString(scores)` 把一维数组内容转为便于查看的字符串。

也可直接用初始化列表，例如 `int[] scores = {80, 90, 100};`。数组类型、元素类型和长度仍由声明与初始化内容确定。

## 易错点

- `scores[3]` 会越界，抛 `ArrayIndexOutOfBoundsException`；最后一项是 `scores[scores.length - 1]`。
- 数组元素有默认值：整数为 0，boolean 为 false，引用为 null；**局部变量本身**没有可直接读取的默认值。
- 将数组引用赋给另一个变量不会复制数组；两个变量指向同一数组时，通过一个变量修改元素，另一个变量也能看到。

## 手练与自测

1. 将第二个元素改为 90，预测输出。
2. 长度为 3 的数组，为什么不能访问下标 3？
3. 两个变量指向同一数组时，修改一个变量访问到的元素，会不会影响另一个变量看到的内容？

**答案要点**：① `[80, 90, 0]`。② 合法下标为 0 至 2。③ 会，因为它们指向同一数组对象。
