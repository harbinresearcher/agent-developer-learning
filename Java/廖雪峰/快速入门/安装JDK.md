# 安装JDK

> **重要程度：高**｜**手练：需要**
> **重点**：发行版、版本和验证。

## 核心概念

JDK 包含编译与运行 Java 程序所需工具。项目应选择受支持且与依赖兼容的版本及发行版。

## 工作中注意

本次检查时运行时为 Java 11，javac 为 17；这是当时的环境快照，实际使用前请重新查看。选择发行版时检查授权与更新政策。

## 手练

运行 java -version 和 javac -version，确认路径一致或说明为什么不同。
