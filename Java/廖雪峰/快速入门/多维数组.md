# 多维数组

> **重要程度：高**｜**手练：需要**
> **重点**：数组的数组、每行长度、空行。

## 二维数组是什么

Java 的二维数组可以理解为“元素类型也是数组的一维数组”：外层元素引用每一行，行本身又是数组。不同的行可以有不同长度，也可能是 `null`，所以不能默认它一定是规则矩形。

## 完整例子

保存为 `MultiArrayDemo.java`，编译并运行；日志写到标准错误。

```java
import java.util.logging.Logger;

public class MultiArrayDemo {
    private static final Logger logger = Logger.getLogger(MultiArrayDemo.class.getName());

    public static void main(String[] args) {
        /*
         * ========================================================================
         * 步骤1：遍历不等长的二维数组
         * ========================================================================
         * 数据源：程序内的二维数组
         * 操作：
         * 1) 读取或准备示例数据
         * 2) 处理数据并输出结果
         */
        logger.info("开始处理示例");
        // 1.1 准备每行长度不相同的数组
        int[][] rows = {{1, 2}, {3}};
        int sum = 0;
        // 1.2 分别按每一行的长度遍历
        for (int i = 0; i < rows.length; i++) {
            for (int j = 0; j < rows[i].length; j++) {
                sum += rows[i][j];
            }
        }
        // 1.3 输出行数、第二行长度和总和
        System.out.println("rows=" + rows.length + ", second=" + rows[1].length + ", sum=" + sum);
        logger.info("示例处理完成");
    }
}
```

标准输出：

```text
rows=2, second=1, sum=6
```

## 执行过程

`rows.length` 是 2，即外层有两行。`rows[0]` 是 `{1, 2}`，长度为 2；`rows[1]` 是 `{3}`，长度为 1。外层循环选行，内层循环用当前行的 `rows[i].length` 控制列数，依次加 1、2、3，得到 6。

`rows[i][j]` 先取第 `i` 行，再取该行下标 `j` 的元素。若内层固定用 `rows[0].length`，第二行访问 `rows[1][1]` 时会越界。示例中行都非空；如果行允许为 `null`，在访问 `.length` 前必须先判断。

## 创建与实际使用

`new int[2][3]` 创建两行，每行三个 `int`，元素初始为 0；`new int[2][]` 只创建外层，两行引用初始为 `null`，需要分别创建才能访问元素。`Arrays.toString` 打印二维数组时展示的是行数组引用，查看嵌套内容可用 `Arrays.deepToString`。

二维数组适合矩阵、网格等结构；实际开发中若每行有不同含义，考虑定义有名字的类，避免靠数字下标猜字段。

## 手练与答案

把第二行改为 `{3, 4, 5}`，输出 `rows=2, second=3, sum=15`。如果把第二行改成 `null`，内层访问 `rows[i].length` 会抛出 `NullPointerException`，需要先决定跳过还是拒绝空行。
