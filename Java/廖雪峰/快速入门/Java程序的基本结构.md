# Java 程序的基本结构

> **重要程度：高**｜**手练：需要**
> **重点**：区分类、字段、方法和语句；认识入口方法与注释。

## 从外到内看

Java 源文件中可以声明类。类中可以有字段和方法；方法体包含执行语句。程序的组织关系可以先记成：**源文件 → 类 → 方法 → 语句**。

打开 [[第一个Java程序]] 的完整代码：`Hello` 是类名，`main` 是方法名；方法体里的 `System.out.println(...)` 是一条输出语句。示例中 `logger` 是类的静态字段，供入口方法记录日志。

## 入口方法各部分是什么意思

示例入口是 `public static void main(String[] args)`：

- `public`：公开访问；`static`：属于类，可由启动器调用，不需要先创建 Hello 对象。
- `void`：方法不返回值；`main`：该入口的方法名。
- `String[] args`：接收命令行参数的字符串数组；参数可以为空数组。
- `{ ... }`：包住方法体，语句按实际控制流程执行。

这是初学阶段常用的入口写法；较新 JDK 还有其他入口特性，是否可用要看项目版本。

## 注释与格式

`//` 表示单行注释，`/* ... */` 表示多行注释；`/** ... */` 常用于生成 API 文档。注释帮助人理解代码，不应替代清晰命名，也不要写入密码或令牌。

Java 对空格和缩进不完全敏感，但一致缩进能看出代码块层次。很多语句以 `;` 结束，不是每一行都加分号：类、方法和 if 等代码块的花括号本身不是一条必须加分号的普通语句。

## 手练与自测

打开 [[第一个Java程序]]，指出类名、入口方法、静态字段、输出语句和注释；把类名改为别的公开类名后，解释为什么文件名也要同步调整。
