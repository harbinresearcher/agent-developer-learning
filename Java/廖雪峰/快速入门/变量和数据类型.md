# 变量和数据类型

> **重要程度：高**｜**手练：需要**
> **重点**：区分基本类型与引用类型；理解局部变量和字段的初始化；认识 `final` 和 `var`。

## 变量是什么

变量有名称、类型和当前值。声明 `int age = 18;` 表示创建一个名为 `age` 的整数变量并赋值。之后 `age = 20;` 是给已有变量重新赋值，不需要再次写 `int`。

## 基本类型和引用类型

Java 有八种基本类型：整数 `byte`、`short`、`int`、`long`；浮点数 `float`、`double`；字符 `char`；布尔值 `boolean`。它们保存对应的基本值。

`String`、数组和自定义类等属于引用类型。引用变量保存的是对对象的引用；两个引用可以指向同一个对象。引用可以为 `null`，对 null 调用实例方法会出错。

## 默认值：先看变量在哪里

不能说“所有没有初始化的变量默认是 0”。**实例字段、静态字段和数组元素**有默认值：整数为 0，浮点数为 0.0，boolean 为 false，引用为 null。`char` 的默认值为 Unicode 码元 `\u0000`。

**局部变量**必须在使用前被编译器确认已经赋值，不能直接读取一个尚未赋值的局部变量。这条区别很常见，也容易在面试和实际排错中出现。

## final 与 var

`final` 变量只能赋值一次。若它是对象引用，不能改为指向别的对象，但对象内部是否可变要看对象本身。

Java 10 起，符合条件的局部变量声明可以用 `var` 让编译器根据初始化表达式推断类型。类型一旦推断确定，变量不会因此变成动态类型；不能只写 `var x;` 而不提供可推断的初始化表达式。

## 手练与自测

1. 声明并重新赋值一个 `int`；尝试在同一作用域重复声明同名局部变量。
2. 比较未赋值的实例字段和局部变量：哪一种可以直接读取？
3. final 引用指向可变列表时，列表内容能否改变？

**答案要点**：① 可重新赋值，不可在同一作用域重复声明。② 字段有对应类型默认值；局部变量须先确定赋值。③ 引用不能重新赋值，但对象可能仍可修改。
