# 字符和字符串

> **重要程度：高**｜**手练：需要**
> **重点**：区分 char 和 String；用 equals 比较内容；理解 UTF-16 长度与编码。

## 先分清两个类型

`char` 是一个 UTF-16 代码单元，字面量常用单引号，例如 `'A'`。`String` 表示字符串对象，字面量常用双引号，例如 `"Java"`。一个完整 Unicode 字符并不一定只占一个 char。

## 完整例子

保存为 `StringDemo.java`，执行 `javac -encoding UTF-8 StringDemo.java`，再执行 `java StringDemo`。
```java
import java.util.logging.Logger;

public class StringDemo {
    private static final Logger logger = Logger.getLogger(StringDemo.class.getName());

    public static void main(String[] args) {
        /*
         * ========================================================================
         * 步骤1：比较字符串并观察字符长度
         * ========================================================================
         * 目标：区分引用身份、内容和 Unicode 码点。
         * 数据源：两个文本相同的字符串及一个表情。
         * 操作：
         * 1) 比较对象引用和字符串内容。
         * 2) 比较 UTF-16 长度与码点数量。
         */
        logger.info("开始比较字符串");
        // 1.1 创建两个内容相同的不同对象
        String first = new String("Java");
        String second = new String("Java");
        System.out.println("同一对象: " + (first == second));
        System.out.println("内容相等: " + first.equals(second));
        // 1.2 比较文本长度与 Unicode 码点数量
        String symbol = "😀";
        System.out.println("UTF-16 单元数: " + symbol.length());
        System.out.println("码点数量: " + symbol.codePointCount(0, symbol.length()));
        logger.info("字符串比较完成");
    }
}
```

标准输出依次为 `同一对象: false`、`内容相等: true`、`UTF-16 单元数: 2`、`码点数量: 1`。

### 为什么结果不同

1. 两次 `new String("Java")` 创建两个不同对象，`==` 比较引用身份，结果为 false。
2. `equals` 比较 String 的内容，两者都是 `Java`，结果为 true。实际业务一般不需要像示例这样专门用 `new String`。
3. 示例里的表情是一个 Unicode 码点，但需要两个 UTF-16 代码单元；`length()` 得到 2，`codePointCount(...)` 得到 1。

码点数也不总等于用户看到的字符数：一些可见字符由多个码点组合而成。要按用户感知的字符切分时，需使用适合的文本处理规则。

## 不可变与编码

String 不可变。方法如 `replace` 返回新的结果字符串；若不接收返回值，原变量仍引用原内容。

字符是文本概念，字节是存储或传输单位。文本与字节互转时要约定编码，例如 UTF-8；编码和解码使用不同规则可能得到错误文本。

## 空值比较

`first.equals(second)` 在 first 为 null 时会抛 `NullPointerException`。需要允许两侧为 null 时，可考虑 `Objects.equals(first, second)`，并按业务区分“缺失”和“空字符串”。

## 手练与自测

1. 修改第二个字符串内容，预测 `equals` 结果。
2. 为什么不能用 `==` 作为一般的字符串内容比较？
3. `length()` 为什么不总等于人眼看到的字符数量？

**答案要点**：① 内容不同时为 false。② 它比较引用身份。③ `length()` 统计 UTF-16 代码单元，而一个码点或可见字符可能占多个单元。
