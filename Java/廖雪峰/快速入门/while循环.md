# while循环

> **重要程度：高**｜**手练：需要**
> **重点**：先判断、推进状态与退出条件。

## 先理解：满足条件时重复

`while (条件) { 循环体 }` 每轮先检查条件；为真才执行循环体，之后回到条件处再判断。若第一次就是假，循环体一次也不执行。条件表达式必须是 `boolean`。

## 完整例子：累加 1 到 3

保存为 `WhileDemo.java`，编译并运行；日志写到标准错误。

```java
import java.util.logging.Logger;

public class WhileDemo {
    private static final Logger logger = Logger.getLogger(WhileDemo.class.getName());

    public static void main(String[] args) {
        /*
         * ========================================================================
         * 步骤1：按条件累计
         * ========================================================================
         * 数据源：程序内准备的示例数据
         * 操作：
         * 1) 初始化输入
         * 2) 按控制流程处理并输出结果
         */
        logger.info("开始处理示例");
        // 1.1 初始化计数器与累计值
        int n = 1;
        int sum = 0;
        // 1.2 条件为真时处理当前值，并推进计数器
        while (n <= 3) {
            sum += n;
            n++;
        }
        // 1.3 输出循环结束后的状态
        System.out.println("sum=" + sum + ", n=" + n);
        logger.info("示例处理完成");
    }
}
```

标准输出：

```text
sum=6, n=4
```

## 按顺序读代码

初始 `n=1`、`sum=0`。第一轮加 1 后 `n` 变 2；第二轮加 2 后 `n` 变 3；第三轮加 3 后 `n` 变 4。再次判断 `4 <= 3` 为假，退出循环，所以结果是 `sum=6, n=4`。`sum += n` 等价于 `sum = sum + n`，`n++` 把 n 增加 1。

循环要想正常结束，循环体通常需要改变影响条件的状态。把 `n++` 删掉后，条件一直为真，会成为无限循环。处理来自外部的数据时，也要考虑读不到结束标记、请求超时等情况。

## 工作中怎么用

`while` 常用于直到满足停止条件才结束的任务，例如读取流直到返回结束标记。明确三个东西：初始状态、退出条件、每轮如何推进。访问资源时还需要按资源接口正确关闭，详见 IO 章节。

## 手练与答案

1. 初始 `n=4`，其他不变：循环体执行 0 次，输出 `sum=0, n=4`。
2. 保持初始值，把条件改为 `n < 3`：只加 1 和 2，输出 `sum=3, n=3`。
