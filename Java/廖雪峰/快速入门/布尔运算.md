# 布尔运算

> **重要程度：高**｜**手练：需要**
> **重点**：关系比较、`&&` / `||` 的短路、`!` 和三元表达式。

## 条件结果只有 true 或 false

`>`、`>=`、`<`、`<=` 比较大小；`==`、`!=` 判断是否相等或不等。比较引用时，`==` 判断引用是否指向同一对象，字符串内容比较通常使用 `equals` 或空安全的 `Objects.equals`。

## 短路是怎么发生的

- `A && B`：先计算 A；A 为 false 时整体必为 false，B 不执行。
- `A || B`：先计算 A；A 为 true 时整体必为 true，B 不执行。
- `!A`：对布尔结果取反。

例如先判断字符串引用不是 null，再用 `&&` 调用其方法：前一个判断为 false 时，后面的调用不会执行。顺序反过来，则可能先触发空指针。`&` 和 `|` 也可用于布尔值，但不会采用 `&&` / `||` 的同样短路行为；整数上的位运算另有含义。

## 三元表达式

`条件 ? 值A : 值B` 先判断条件，再只计算选中的分支。它适合简单的值选择；条件或分支复杂时，用 `if / else` 通常更易读。两个分支类型不必完全相同，但表达式类型需要满足 Java 的类型推断与转换规则。

## 手练与自测

1. 假设 `text` 是 null，先检查 `text != null` 再用 `&&` 判断长度，为什么不会访问 null？
2. 对 `A || B`，A 为 true 时 B 会执行吗？
3. `==` 比较两个 String 引用与 `equals` 比较内容有什么区别？

**答案要点**：① 前项为 false，后项短路。② 不执行。③ 前者比较引用身份，后者通常比较字符串内容。
