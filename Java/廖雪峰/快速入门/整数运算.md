# 整数运算

> **重要程度：高**｜**手练：需要**
> **重点**：整数除法、溢出、数值提升、`++` 前后位置及常用位运算。

## 先看结果

保存为 `ArithmeticDemo.java`，运行 `javac -encoding UTF-8 ArithmeticDemo.java`，再运行 `java ArithmeticDemo`。

```java
import java.util.logging.Logger;

public class ArithmeticDemo {
    private static final Logger logger = Logger.getLogger(ArithmeticDemo.class.getName());

    public static void main(String[] args) {
        /*
         * ========================================================================
         * 步骤1：比较整数和浮点数除法
         * ========================================================================
         * 目标：观察操作数类型如何影响结果。
         * 数据源：数值 5 和 2。
         * 操作：
         * 1) 用两个整数计算。
         * 2) 用浮点数与整数计算。
         */
        logger.info("开始比较除法结果");
        // 1.1 计算整数除法
        System.out.println("整数除法: " + (5 / 2));
        // 1.2 计算浮点数除法
        System.out.println("浮点除法: " + (5.0 / 2));
        logger.info("除法比较完成");

        /*
         * ========================================================================
         * 步骤2：观察整数溢出和浮点误差
         * ========================================================================
         * 目标：识别固定宽度与二进制小数的边界。
         * 数据源：int 最大值及两个测试小数。
         * 操作：
         * 1) 对 int 最大值加一。
         * 2) 输出两个浮点数的和。
         */
        logger.info("开始观察数值边界");
        // 2.1 计算 int 溢出结果
        int max = Integer.MAX_VALUE;
        System.out.println("溢出结果: " + (max + 1));
        // 2.2 计算二进制浮点数的和
        System.out.println("浮点数相加: " + (0.1 + 0.2));
        logger.info("数值边界观察完成");
    }
}
```

标准输出依次包括：整数除法 `2`、浮点除法 `2.5`、溢出结果 `-2147483648`、浮点数相加 `0.30000000000000004`。

## 为什么 `5 / 2` 是 2

两个操作数都是整数，执行整数除法，结果的小数部分被截去；`5.0 / 2` 包含浮点数，结果为 `2.5`。整数除以 0 会抛 `ArithmeticException`。求余使用 `%`，要结合负数结果规则测试。

## 为什么最大值加一变成负数

`int` 是 32 位有符号整数。普通整数运算溢出不会自动报错；`Integer.MAX_VALUE + 1` 会得到 `Integer.MIN_VALUE`。需要检测溢出时可以考虑 `Math.addExact` 等方法，并处理异常；数据范围更大时考虑 `long` 或 `BigInteger`。

将更宽的值强制转换为更窄的整数类型可能丢失信息。运算过程中还要关注数值提升，不能只看最终接收变量的类型。

## 自增与位运算

`++n` 先递增再得到表达式的值；`n++` 先得到旧值，再递增。业务代码应避免把自增与复杂表达式混用。`&`、`|`、`^`、`~` 是位运算；`<<`、`>>`、`>>>` 是移位运算，分别需要结合有符号数规则理解。

## 手练与自测

1. 把 5 和 2 改成 7 和 2，预测两种除法结果。
2. 为什么不能假定整数溢出会自动抛异常？
3. 分别计算 `n = 3` 时的 `++n` 和 `n++` 表达式值。

**答案要点**：① 3 与 3.5。② 普通定宽整数溢出会按 Java 规则产生结果。③ 前者为 4，后者表达式先为 3、之后 n 为 4。
