# 命令行参数

> **重要程度：高**｜**手练：需要**
> **重点**：参数位置、长度校验与类型转换。

## 参数从哪里来

`main(String[] args)` 的 `args` 接收启动程序时写在类名后面的参数。它是字符串数组；程序没有收到参数时长度为 0，而不是 `null`。参数位置从 0 开始，必须先检查长度再访问。

## 完整例子

保存为 `ArgsDemo.java`。编译后运行 `java ArgsDemo Ada 18`；下面是标准输出，日志写到标准错误。

```java
import java.util.logging.Logger;

public class ArgsDemo {
    private static final Logger logger = Logger.getLogger(ArgsDemo.class.getName());

    public static void main(String[] args) {
        /*
         * ========================================================================
         * 步骤1：校验并读取命令行参数
         * ========================================================================
         * 数据源：启动 Java 程序时输入的参数
         * 操作：
         * 1) 读取或准备示例数据
         * 2) 处理数据并输出结果
         */
        logger.info("开始处理示例");
        // 1.1 校验参数个数
        if (args.length != 2) {
            System.out.println("用法: java ArgsDemo 姓名 年龄");
        } else {
            // 1.2 展示两个原始字符串参数
            System.out.println("name=" + args[0]);
            System.out.println("ageText=" + args[1]);
        }
        logger.info("示例处理完成");
    }
}
```

标准输出：

```text
name=Ada
ageText=18
```

## 执行过程

命令行中的 `Ada` 进入 `args[0]`，`18` 进入 `args[1]`。这里的 `18` 仍是字符串，不会自动变成数字。因为长度恰好是 2，程序读取并输出两个元素。没有参数或参数数量不对时，输出用法，不访问不存在的下标。

需要计算年龄时，可用 `Integer.parseInt(args[1])`；输入非整数或超出 `int` 范围会抛出 `NumberFormatException`。实际程序应提供清楚的错误信息，并按业务检查年龄范围，而不是假定输入总是正确。

## 使用边界

`java` 的 JVM 选项写在类名前，类名后的内容才交给程序。带空格的单个参数通常需要按所用 shell 的规则加引号，例如 `java ArgsDemo "Ada Lovelace" 18`。命令行参数可能暴露在进程列表或 shell 历史中，不应放密码、令牌等秘密。

## 手练与答案

1. 执行 `java ArgsDemo`：输出用法提示，不抛下标异常。
2. 执行 `java ArgsDemo Bob 20`：输出 `name=Bob` 和 `ageText=20`，其中 20 仍是字符串。
