# 数组排序

> **重要程度：高**｜**手练：需要**
> **重点**：原地排序、复制、比较规则。

## 排序解决什么问题

排序让一组数据按指定顺序排列，例如把成绩从低到高展示。Java 的 `Arrays.sort` 会**直接修改传入数组**，它不返回一个排好序的新数组；需要保留原数据时，先复制再排序。

## 完整例子

保存为 `ArraySortDemo.java`，编译并运行；日志写到标准错误。

```java
import java.util.logging.Logger;
import java.util.Arrays;

public class ArraySortDemo {
    private static final Logger logger = Logger.getLogger(ArraySortDemo.class.getName());

    public static void main(String[] args) {
        /*
         * ========================================================================
         * 步骤1：排序并保留原始数组
         * ========================================================================
         * 数据源：程序内的整数数组
         * 操作：
         * 1) 读取或准备示例数据
         * 2) 处理数据并输出结果
         */
        logger.info("开始处理示例");
        // 1.1 复制输入，避免改变原数组
        int[] original = {5, 2, 9, 2};
        int[] sorted = Arrays.copyOf(original, original.length);
        // 1.2 原地升序排序复制品
        Arrays.sort(sorted);
        // 1.3 展示两个数组
        System.out.println("original=" + Arrays.toString(original));
        System.out.println("sorted=" + Arrays.toString(sorted));
        logger.info("示例处理完成");
    }
}
```

标准输出：

```text
original=[5, 2, 9, 2]
sorted=[2, 2, 5, 9]
```

## 执行过程

`original` 引用原数组，`Arrays.copyOf` 创建另一个长度相同的数组并复制元素，因此 `sorted` 和 `original` 指向不同数组。`Arrays.sort(sorted)` 原地升序排列复制品。`Arrays.toString` 把元素格式化成便于阅读的字符串；直接打印数组引用不会得到这样的元素列表。

基本类型数组的复制会复制各个值。若是对象数组，`copyOf` 只复制对象引用：两个数组的元素仍可能指向同一对象；修改对象内部状态仍可能从另一数组看到。

## 比较与注意事项

基本类型数组的 `Arrays.sort` 默认升序。对象数组需要元素满足自然顺序，或提供 `Comparator` 明确比较规则；比较规则应处理业务允许出现的空值，并保持一致。数组已经排好序时，才考虑使用 `Arrays.binarySearch`；结果为负数时不能直接当作找到的下标。

学习时可以手写冒泡排序理解比较和交换，但真实项目通常优先调用标准库，除非需求或性能数据说明有特殊必要。

## 手练与答案

1. 如果把 `sorted = original` 代替复制，两变量指向同一数组；排序后两次打印都是 `[2, 2, 5, 9]`。
2. 将输入改成 `{}`，排序后依然是空数组，不会因为没有元素而越界。
