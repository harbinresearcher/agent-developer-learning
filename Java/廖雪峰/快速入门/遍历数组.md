# 遍历数组

> **重要程度：高**｜**手练：需要**
> **重点**：遍历方式、空数组、平均值与类型转换。

## 数组遍历解决什么问题

数组把相同类型的数据按顺序存放。遍历是依次取出每个元素：例如统计三个成绩的总分和平均分。数组一旦创建，长度固定，合法下标从 0 到 `length - 1`。

## 完整例子

保存为 `ArrayLoopDemo.java`，编译并运行；日志写到标准错误。

```java
import java.util.logging.Logger;

public class ArrayLoopDemo {
    private static final Logger logger = Logger.getLogger(ArrayLoopDemo.class.getName());

    public static void main(String[] args) {
        /*
         * ========================================================================
         * 步骤1：遍历数组并求平均值
         * ========================================================================
         * 数据源：程序内的整数数组
         * 操作：
         * 1) 读取或准备示例数据
         * 2) 处理数据并输出结果
         */
        logger.info("开始处理示例");
        // 1.1 准备成绩并统计总和
        int[] scores = {80, 90, 70};
        int sum = 0;
        for (int score : scores) {
            sum += score;
        }
        // 1.2 先检查长度，再计算浮点平均值
        if (scores.length == 0) {
            System.out.println("没有成绩");
        } else {
            double average = (double) sum / scores.length;
            System.out.println("sum=" + sum + ", average=" + average);
        }
        logger.info("示例处理完成");
    }
}
```

标准输出：

```text
sum=240, average=80.0
```

## 执行过程

增强 for 每轮从 `scores` 取一个元素赋给 `score`：先取 80、再取 90、最后取 70。`sum` 依次变成 80、170、240。数组长度是 3，因此 `(double) sum / scores.length` 得到 80.0。

强制转换发生在除法前，左操作数变成 `double`，除法才保留小数。如果写成 `(double) (sum / scores.length)`，整数除法已先丢弃小数，后面的转换无法恢复。比如总分 5、人数 2，前者得 2.5，后者得 2.0。

空数组的长度为 0；示例先检查它，否则这里的浮点除法可能产生 `NaN`，并不能表达有意义的平均分。`scores` 为 `null` 时访问 `.length` 仍会抛出 `NullPointerException`；外部传入的数组需要按接口约定检查。

## 选择遍历方式

仅处理元素时用增强 for。需要下标、反向访问或修改数组元素时用普通 for，例如 `for (int i = 0; i < scores.length; i++)`。增强 for 的基本类型循环变量是元素值的副本，修改它不会改数组。元素是对象引用时，可以通过引用修改对象内部状态，但给循环变量重新赋引用也不会替换数组中的元素。

## 手练与答案

将数组改为 `{1, 2}`，输出为 `sum=3, average=1.5`；改为空数组 `{}`，输出“没有成绩”。如果普通 for 写成 `i <= scores.length`，访问到 `scores[length]` 时会越界。

## 综合练习：手练：数组、循环与平均值


将下面代码保存为 `ScoreDemo.java`。运行命令：`javac -encoding UTF-8 ScoreDemo.java`，随后运行 `java ScoreDemo`。

```java
import java.util.logging.Logger;

public class ScoreDemo {
    private static final Logger logger = Logger.getLogger(ScoreDemo.class.getName());

    public static void main(String[] args) {
        /*
         * ========================================================================
         * 步骤1：统计成绩
         * ========================================================================
         * 目标：计算最高分和平均分。
         * 数据源：本地成绩数组。
         * 操作：
         * 1) 逐项计算总分和最高分。
         * 2) 将总分转换为浮点数后求平均值。
         */
        logger.info("开始统计成绩");
        // 1.1 准备非空数组和初始值
        int[] scores = {80, 90, 100};
        int total = 0;
        int highest = scores[0];
        // 1.2 遍历数组并更新统计值
        for (int i = 0; i < scores.length; i++) {
            total += scores[i];
            if (scores[i] > highest) {
                highest = scores[i];
            }
        }
        // 1.3 输出结果
        double average = (double) total / scores.length;
        System.out.println("最高分: " + highest);
        System.out.println("平均分: " + average);
        logger.info("成绩统计完成");
    }
}
```

`i < scores.length` 避免越界。先把总分转成 `double`，除法才会保留小数。本例明确使用非空数组；如果成绩来自外部输入，读取 `scores[0]` 前要检查数组是否为空。

手练：将成绩改成 `81, 90, 100`，先手算平均值再运行；然后给空数组设计处理方式。
