# 搭建开发环境

> **重要程度：高**｜**手练：需要**
> **重点**：JDK、编译器、运行时和 IDE。

## 核心概念

开发环境包含 JDK、命令行及可选 IDE。先确认项目使用的 Java 版本，再确认工具实际调用的编译器与运行时。

## 工作中注意

不同终端和 IDE 可能指向不同 JDK；更改系统环境变量前先查看现状，项目选择不必等于系统默认。

## 手练

在终端分别查看 java 与 javac 版本，再编译并运行一个测试程序。
