# 基本概念

> **重要程度：高**｜**手练：需要**
> **重点**：时间点、时区与本地时间。

## 核心概念

同一个时间点在不同地区可以显示为不同的钟表时间；时间点、时区和本地日期时间不能混为一谈。时间戳常按 UTC 基准表示经过的秒或毫秒。

## 工作中注意

毫秒与秒相差一千倍；仅有本地日期和时刻不足以确定跨地区唯一时间点。

## 手练

把同一 UTC 时间点显示为两个时区的时间，比较它们是否表示同一时刻。

来源：[教程：基本概念](https://liaoxuefeng.com/books/java/datetime/concept/index.html)。

## 关联知识与实践

`Instant` 表示时间线上的时刻；`LocalDate` 只有日期；`LocalDateTime` 有日期和钟表时间但没有时区，不能单独确定全球唯一时刻；`ZonedDateTime` 包含时区规则。`Date` 和 `Calendar` 是旧 API，维护旧项目可能遇到，新代码通常优先使用 `java.time`。

来源：[教程：日期与时间](https://liaoxuefeng.com/books/java/datetime/index.html)；[Java Date-Time API](https://dev.java/learn/date-time/)。
