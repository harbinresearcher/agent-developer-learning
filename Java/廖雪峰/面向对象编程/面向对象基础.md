# 面向对象基础

> **重要程度：高**｜**手练：需要**
> **重点**：类与对象、封装、引用与状态。

## 从现实问题开始

账户既有数据（余额），也有操作（存款、查询）。类 `Account` 定义账户的数据和可执行操作；用 `new` 创建的每个账户是这个类的一个对象，也叫实例。实例字段属于各自对象，两个账户可以有不同余额。

## 完整例子

保存为 `ObjectDemo.java`，编译运行。为聚焦对象关系，金额使用整数；真实业务还需明确货币单位、溢出和持久化。日志写到标准错误。

```java
import java.util.logging.Logger;

public class ObjectDemo {
    private static final Logger logger = Logger.getLogger(ObjectDemo.class.getName());
    public static void main(String[] args) {
        /*
         * ========================================================================
         * 步骤1：创建并使用账户
         * ========================================================================
         * 数据源：账户初始余额与存入金额
         * 操作：
         * 1) 创建两个独立账户并修改其中一个
         * 2) 用另一个引用访问同一账户
         */
        logger.info("开始处理账户");
        // 1.1 创建两个不同对象
        Account first = new Account(100);
        Account second = new Account(50);
        // 1.2 通过引用调用对象的方法
        Account alias = first;
        alias.deposit(20);
        System.out.println("first=" + first.balance());
        System.out.println("second=" + second.balance());
        System.out.println("same=" + (first == alias));
        logger.info("账户处理完成");
    }
}

class Account {
    private int balance;
    Account(int initialBalance) {
        if (initialBalance < 0) throw new IllegalArgumentException("余额不能为负");
        this.balance = initialBalance;
    }
    void deposit(int amount) {
        if (amount <= 0) throw new IllegalArgumentException("金额必须为正");
        balance = Math.addExact(balance, amount);
    }
    int balance() { return balance; }
}
```

标准输出：

```text
first=120
second=50
same=true
```

## 对着结果理解对象

1. `new Account(100)` 创建第一个对象，构造器将它的 `balance` 初始化为 100；第二次 `new` 创建独立对象，余额为 50。
2. `Account alias = first` 复制的是引用，不会创建第三个账户。`alias` 与 `first` 指向同一对象。
3. `alias.deposit(20)` 修改那个对象的字段，因此通过 `first.balance()` 读到 120；另一个账户仍是 50。
4. 引用之间的 `==` 判断是否指向同一对象，所以此处为 `true`。对象内容是否相等取决于该类型如何定义 `equals`，见 [[编写equals方法]]。

## 封装与语法

`private int balance` 让外部代码不能直接访问字段；外部要通过方法修改，`deposit` 可以拒绝负数并用 `Math.addExact` 检查整数溢出。`this.balance = initialBalance` 中，`this` 指当前对象，左侧是它的字段，右侧是传入参数。构造器和方法的详细规则分别见 [[构造方法]]、[[方法]]。

类是类型定义；对象是一次创建出来的实例；引用变量保存对对象的引用。`null` 表示引用未指向对象，对 `null` 调用实例方法会抛 `NullPointerException`。Java 的参数传递是值传递：传对象时复制的是引用值；方法可以经引用修改同一对象，但重新给参数赋引用不会改调用者的变量。

## 工作中怎么用

把数据和维护数据有效性的操作放在同一类中，让调用者通过明确的方法操作；不要仅把对象当作一堆随意可改的公共字段。真实账户更新还涉及并发控制、事务和数据库持久化，单靠示例中的普通字段不够。

## 手练与答案

把 `alias` 改为指向 `second`：存款后 first 为 100、second 为 70，`first == alias` 为 false。尝试存入 -1 会抛 `IllegalArgumentException`，余额不会被修改。
