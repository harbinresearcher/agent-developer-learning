# 继承

> **重要程度：高**｜**手练：需要**
> **重点**：`extends`、父子类成员、构造顺序、`super` 与类型转换。

## 继承解决什么

当 `Student` 确实是一种 `Person` 时，可以让 `Student extends Person`。子类继承可访问的父类行为，也能增加自己的行为。Java 类只有一个直接父类；一个类可以实现多个接口。

`private` 成员属于父类内部实现，子类不能像直接访问自己的可见成员那样访问它；可以通过父类暴露的合适方法交互。继承不等于复制源码，也不应为了少写几行代码而强行建立不符合业务的关系。

## 构造对象的顺序

创建子类对象时，父类部分需要先初始化，然后子类字段初始化并执行子类构造器剩余部分。`super(...)` 用来选择父类构造器；在本笔记采用的 Java 11～21 语法中，显式调用放在子类构造器第一条语句。Java 25 起灵活构造器成为正式特性，允许在符合限制时先写部分语句，详见 [[构造方法]]。若不写，编译器会尝试插入无参的 `super()`；父类没有可访问的无参构造器时会编译失败。

## 类型转换

把子类对象赋给父类类型变量叫向上转型，例如 `Person p = new Student()`；不需要强制转换。向下转换需要对象实际类型兼容，否则可能抛 `ClassCastException`；需要时先使用 `instanceof` 检查。引用声明为父类类型时，编译器按该类型检查能调用哪些成员。

## 手练

定义 `Person` 和 `Student`，给父类只保留带参数的构造器，观察子类不写 `super(...)` 时的编译错误；再显式传参。把学生对象赋给父类变量，检查哪些方法能直接调用。

来源：[教程：继承](https://liaoxuefeng.com/books/java/oop/basic/inherit/index.html)。

## 可运行例子

保存为 `InheritanceDemo.java`，执行 `javac -encoding UTF-8 InheritanceDemo.java`，再执行 `java InheritanceDemo`。

```java
import java.util.logging.Logger;

public class InheritanceDemo {
    private static final Logger logger = Logger.getLogger(InheritanceDemo.class.getName());

    public static void main(String[] args) {
        /*
         * ========================================================================
         * 步骤1：创建学生并读取父类信息
         * ========================================================================
         * 目标：观察子类如何调用父类构造器。
         * 数据源：学生姓名和年级。
         * 操作：
         * 1) 创建 Student 对象。
         * 2) 调用继承的公开方法和子类自己的方法。
         */
        logger.info("开始创建学生");
        // 1.1 创建学生对象
        Student student = new Student("小明", 2);
        // 1.2 读取父类和子类的信息
        System.out.println(student.getName());
        System.out.println(student.getGrade());
        logger.info("学生信息读取完成");
    }
}

class Person {
    private final String name;

    Person(String name) {
        this.name = name;
    }

    String getName() {
        return name;
    }
}

class Student extends Person {
    private final int grade;

    Student(String name, int grade) {
        super(name);
        this.grade = grade;
    }

    int getGrade() {
        return grade;
    }
}
```

标准输出：

```text
小明
2
```

执行 `new Student("小明", 2)` 时，先为新对象准备空间，然后 `super(name)` 调用父类有参构造器；父类保存姓名后，子类构造器保存年级。`name` 是父类私有字段，子类不能直接读取它，但可以调用继承来的可访问方法 `getName()`。

如果把 `super(name)` 删除，编译器会尝试调用 `super()`；示例中的 `Person` 只定义了有参构造器，没有可用的无参构造器，所以编译失败。父类构造器不会被子类继承。

## 手练答案

`Person person = new Student("小明", 2)` 可以向上转型，`person.getName()` 可以调用；`person.getGrade()` 不能直接编译，因为变量声明类型 `Person` 没有 `getGrade`。如果对象实际是 `Student`，可在检查类型后向下转型；如果实际是其他 `Person`，强转会抛 `ClassCastException`。

判断是否该用继承时，先确认子类确实符合父类的行为约定；若只是为了复用实现，不存在稳定的“是一种”关系，可考虑让一个类持有另一个类的对象，即组合。
