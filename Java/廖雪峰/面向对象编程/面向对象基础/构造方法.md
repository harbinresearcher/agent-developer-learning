# 构造方法

> **重要程度：高**｜**手练：需要**
> **重点**：创建对象时初始化字段；无参构造器的生成条件；构造器重载；`this(...)` 复用初始化逻辑。

## 它解决什么问题

`new Person("小明", 18)` 创建对象时会调用匹配的构造器，让对象从一开始就具备合法状态。构造器名与类名相同，没有返回类型，连 `void` 也不写。

## 可以运行的例子

将下面内容保存为 `Main.java`。它使用 JDK 自带的日志工具，无需安装依赖。

```java
import java.util.logging.Logger;

public class Main {
    private static final Logger logger = Logger.getLogger(Main.class.getName());

    public static void main(String[] args) {
        /*
         * ========================================================================
         * 步骤1：创建对象并检查结果
         * ========================================================================
         * 目标：观察构造器重载和字段初始化。
         * 数据源：两个不同的构造参数。
         * 操作：
         * 1) 分别调用有参和无参构造器。
         * 2) 输出对象字段。
         */
        logger.info("开始创建对象");
        // 1.1 调用有参构造器
        Person first = new Person("小明", 18);
        // 1.2 调用无参构造器并检查结果
        Person second = new Person();
        System.out.println(first.describe());
        System.out.println(second.describe());
        logger.info("对象创建和检查完成");
    }
}

class Person {
    private static final Logger logger = Logger.getLogger(Person.class.getName());
    private final String name;
    private final int age;

    public Person() {
        this("未命名", 0);
    }

    public Person(String name, int age) {
        /*
         * ========================================================================
         * 步骤1：校验并初始化字段
         * ========================================================================
         * 目标：创建状态合法的 Person。
         * 数据源：调用者传入的姓名和年龄。
         * 操作：
         * 1) 校验姓名和年龄。
         * 2) 将参数保存到实例字段。
         */
        logger.info("开始初始化 Person");
        // 1.1 拒绝无效参数
        if (name == null || name.isBlank() || age < 0) {
            throw new IllegalArgumentException("姓名不能为空，年龄不能为负数");
        }
        // 1.2 保存合法参数
        this.name = name;
        this.age = age;
        logger.info("Person 初始化完成");
    }

    public String describe() {
        return name + ": " + age;
    }
}
```

在 `Main.java` 所在目录运行 `javac -encoding UTF-8 Main.java`，再运行 `java Main`。标准输出为：

```text
小明: 18
未命名: 0
```

日志写到标准错误，时间和格式会因环境而异。

## 按执行顺序理解

1. `new Person("小明", 18)` 匹配有两个参数的构造器；先检查姓名和年龄，再给新对象的两个字段赋值。
2. `new Person()` 匹配无参构造器。它用 `this("未命名", 0)` 调用同类的有参构造器，复用同一套校验与赋值逻辑。
3. 两次 `new` 创建两个不同对象；`describe()` 分别读取各自字段，因此输出两行不同的信息。
4. 姓名为空白或年龄为负数时，构造器抛异常，调用方得不到正常构造完成的对象。

## 需要记住的规则

- 类没有声明任何构造器时，编译器通常会生成一个无参默认构造器。**只要自己声明了构造器，就不会再自动生成无参构造器**；需要的话要显式定义。
- 同一个类可以声明参数列表不同的多个构造器，称为重载；只改变参数名不能构成重载。
- `this(...)` 调用同一个类的另一个构造器。本例按 Java 11 语法，将它放在构造器第一条语句，用无参构造器复用有参构造器。
- `this.name` 指实例字段，右侧 `name` 指参数。引用类型字段的默认值为 `null`，`int` 字段为 `0`；局部变量没有可直接读取的默认值。
- 有继承时，父类初始化也会参与对象创建；关于调用顺序，再结合继承笔记学习。

## Java 版本区别

Java 11～21 的普通语法中，显式的 `this(...)` 或 `super(...)` 必须放在构造器第一条语句。Java 22～24 曾预览灵活构造器语法；Java 25 起正式允许在显式构造器调用前写部分语句，但早期构造阶段有访问当前实例等限制。项目采用哪个写法，以项目配置的 Java 版本为准。详见 [Oracle：灵活构造器](https://docs.oracle.com/en/java/javase/25/language/flexible-constructor-bodies.html)。

## 实际开发

在构造器里检查必要参数，避免对象创建后处于无效状态。框架可能要求特定构造方式，应以所用框架和项目约定为准；不要为了满足习惯而无条件添加无参构造器。

## 自测

1. 为 `Person` 只写有参构造器后，`new Person()` 还能编译吗？为什么？
2. `this(...)` 和 `this.name` 分别做什么？
3. 传入负数年龄时，程序会得到一个正常的 `Person` 对象吗？

**答案**：① 不能。显式声明了有参构造器后，编译器不会再自动生成无参构造器。② `this(...)` 委托给同类的另一个构造器；`this.name` 访问当前对象的字段。③ 不会；校验抛出 `IllegalArgumentException`，构造未正常完成。
