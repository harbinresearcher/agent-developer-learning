# 方法重载

> **重要程度：高**｜**手练：需要**
> **重点**：参数列表如何区分重载；调用时选择哪个方法；重载与重写的区别。

## 从一个需求开始

假设要计算两个整数的和，也要计算三个整数的和。可以让两个方法都叫 `sum`，一个接收两个 `int`，另一个接收三个 `int`。名字表达同一种操作，参数列表区分不同调用方式，这叫方法重载。

## 哪些变化算重载

同一类中，方法名相同，但参数的**数量、类型或顺序**不同，可以构成重载。例如 `sum(int, int)` 和 `sum(int, int, int)` 可以同时存在；`show(int, String)` 和 `show(String, int)` 的参数顺序不同，也可以共存。

只改参数名不能构成重载，`sum(int a)` 与 `sum(int b)` 是同一个签名。只改返回类型也不行，不能同时定义只有返回类型不同的两个方法。

调用时编译器根据可见候选方法、实参类型和适用的转换规则选择；有些调用可能发生歧义而无法编译。不要把“最终调用哪个重载”当作根据对象运行时类型动态选择。

## 和重写区别

**重载**：同名方法有不同参数列表，重点是编译时选择哪个签名。

**重写**：子类为继承来的实例方法提供实现，运行时的实际对象类型影响方法分派。见 [[多态]]。

## 工作中

同一组重载应表达相近含义，避免同名却有完全不同的副作用。参数很多且含义容易混淆时，可以考虑有明确字段的对象；是否需要抽象取决于实际需求。

## 手练

1. 定义两个和三个参数的 `sum`，分别调用并核对结果。
2. 尝试只改变参数名或返回类型，观察编译错误。
3. 写一个重写例子，解释它与重载选择发生的阶段有什么区别。

来源：[教程：方法重载](https://liaoxuefeng.com/books/java/oop/basic/overload/index.html)。

## 可运行例子

保存为 `OverloadDemo.java`。分别执行 `javac -encoding UTF-8 OverloadDemo.java` 和 `java OverloadDemo`。

```java
import java.util.logging.Logger;

public class OverloadDemo {
    private static final Logger logger = Logger.getLogger(OverloadDemo.class.getName());

    public static void main(String[] args) {
        /*
         * ========================================================================
         * 步骤1：调用不同参数列表的方法
         * ========================================================================
         * 目标：观察编译器如何选择重载。
         * 数据源：两组整数。
         * 操作：
         * 1) 分别调用两个参数和三个参数的方法。
         * 2) 输出结果并核对。
         */
        logger.info("开始演示方法重载");
        // 1.1 用不同数量的参数调用同名方法
        int first = sum(2, 3);
        int second = sum(2, 3, 4);
        // 1.2 输出各自结果
        System.out.println(first);
        System.out.println(second);
        logger.info("方法重载演示完成");
    }

    static int sum(int a, int b) {
        return a + b;
    }

    static int sum(int a, int b, int c) {
        return a + b + c;
    }
}
```

输出依次是 `5` 和 `9`。第一个调用匹配两个参数的方法；第二个调用匹配三个参数的方法。日志可能显示在不同的输出流中。
