# 接口

> **重要程度：高**｜**手练：需要**
> **重点**：接口契约、`implements`、多态调用、default 方法与抽象类的区别。

## 用接口表达能力

接口描述调用方可以依赖的能力。例如 `Payment` 声明支付方法，银行卡和钱包实现分别用 `implements` 提供行为。调用方接收 `Payment` 类型，不必把每个具体类都写进条件分支。完整可运行例子见 [[练习02 接口与多态]]。

一个类可以实现多个接口，也可以在继承一个父类的同时实现接口。接口中的普通方法默认是 `public abstract`；现代 Java 还支持 `default` 方法、静态方法和私有辅助方法，适用规则随方法种类不同。

接口字段隐式为 `public static final`，不是每个实例独有的可变字段。实现类提供方法时不能缩小接口方法要求的访问权限。

## 和抽象类怎么选

接口强调能力和契约，适合多个不相关类提供共同操作；抽象类可共享实例状态、构造逻辑和通用实现。两者可以组合使用，也可以先用更简单的具体类，等需求稳定后再抽象。
