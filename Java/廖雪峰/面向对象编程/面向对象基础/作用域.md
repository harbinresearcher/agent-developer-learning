# 作用域与访问权限

> **重要程度：高**｜**手练：需要**
> **重点**：局部变量作用范围、同名遮蔽、访问修饰符及跨包边界。

## 先区分两个问题

**作用域**回答“在这段代码中能否用这个名字”；**访问权限**回答“另一个类是否允许访问该类或成员”。名字在作用域内，也不代表一定能通过编译：局部变量还必须在使用前被确定赋值。

## 完整例子

保存为 `ScopeDemo.java`，编译并运行；日志写到标准错误。

```java
import java.util.logging.Logger;

public class ScopeDemo {
    private static final Logger logger = Logger.getLogger(ScopeDemo.class.getName());
    public static void main(String[] args) {
        /*
         * ========================================================================
         * 步骤1：观察字段与局部变量
         * ========================================================================
         * 数据源：对象字段和方法参数
         * 操作：
         * 1) 创建对象并传入同名参数
         * 2) 分别读取参数和对象字段
         */
        logger.info("开始观察作用域");
        // 1.1 创建对象并调用方法
        User user = new User("原名");
        user.show("参数名");
        // 1.2 读取方法调用后的字段
        System.out.println("字段仍是=" + user.name());
        logger.info("作用域观察完成");
    }
}
class User {
    private final String name;
    User(String name) { this.name = name; }
    void show(String name) {
        System.out.println("参数=" + name);
        System.out.println("字段=" + this.name);
        if (name.length() > 0) {
            int count = name.length();
            System.out.println("参数长度=" + count);
        }
    }
    String name() { return name; }
}
```

标准输出：

```text
参数=参数名
字段=原名
参数长度=3
字段仍是=原名
```

## 执行过程

`User` 的实例字段 `name` 初始化为“原名”。`show(String name)` 的参数也叫 `name`，在该方法里，直接写 `name` 指参数，它遮蔽了同名字段；`this.name` 明确访问当前对象的字段。这里仅打印两者，没有修改字段，所以方法返回后它仍是“原名”。

`count` 在 `if` 的代码块内声明，只能在其作用域内使用；将 `System.out.println(count)` 放到这个 `if` 块后面会编译失败。`for` 头部声明的计数器也受该循环作用域限制。方法参数、局部变量和字段的有效范围不同，生命周期也不能简单等同于作用域。

## 四种常见访问权限

- `private`：通常只在声明该成员的类内部访问；同一顶层类内的嵌套类之间存在语言规定的访问关系，别简单等同于“只能在一个方法里”。
- 不写修饰符：包访问权限，同包可访问，其他包通常不可访问；这不是 `protected`。
- `protected`：同包可访问；跨包时还允许符合限定条件的子类访问，不能理解为子类能通过任意父类对象访问受保护成员。
- `public`：可从其他包访问，但还要满足所在类型本身可访问；使用模块系统时还受模块可读性和包导出影响。

顶层类只能声明为 `public` 或包访问权限；成员和嵌套类型还有其他选项。局部变量不能声明为 `public` 等访问修饰符。静态方法没有当前对象，所以不能直接使用 `this`。

## 工作中怎么用

字段默认优先 `private`，对外只公开必要能力。返回可变集合或对象时，即使字段是 `private`，直接返回内部引用也可能让调用者修改内部状态；是否返回副本要看接口约定和成本。

## 手练与答案

1. 把 `this.name` 改成 `name`：两个输出都使用参数“参数名”，对象字段仍是“原名”。
2. 把 `count` 的打印语句移出 `if`：编译失败，找不到该局部变量。
3. 把字段改成公开是否意味着对象状态安全？不意味着；外部修改可能绕过业务校验。
