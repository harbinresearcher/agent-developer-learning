# 作用域与访问权限

> **重要程度：高**｜**手练：需要**
> **重点**：局部变量作用域、字段访问修饰符、同包与子类边界。

## 变量作用域

局部变量只在声明所在的作用域内可见；例如循环体内部声明的变量不能在循环体外直接使用。局部变量使用前必须确定已经赋值。字段的生命周期与所属对象或类相关，不等于局部变量的作用域。

同名参数或局部变量可能遮蔽实例字段；在实例方法内可用 `this.name` 明确指向字段。静态方法没有 `this`。

## 访问修饰符

`private` 主要限制在声明它的类内部；未写修饰符通常是包访问权限；`public` 可以从其他包访问，但还受所在类和模块导出规则约束。`protected` 除同包访问外，还涉及子类访问规则，跨包访问时不能简单理解成“任何子类都可通过任意对象访问”。

工作中优先给成员最小必要可见性，公开接口表达业务能力，不随意暴露可变内部状态。

## 手练

创建不同包中的父类与子类，分别测试 `private`、默认权限、`protected` 和 `public`。解释参数与字段同名时 `this` 的作用。
