# 方法

> **重要程度：高**｜**手练：需要**
> **重点**：声明与调用、返回值、封装、this、参数按值传递、可变参数。

## 先理解：让对象提供可调用的行为

方法把一段有名字的操作组织起来。调用方传入参数，方法可以修改对象状态、返回结果或两者兼有。把字段设为 `private`，再通过方法控制读写，能集中检查规则，例如拒绝负数余额。

## 完整例子

保存为 `MethodDemo.java`，编译并运行；日志写到标准错误。

```java
import java.util.logging.Logger;

public class MethodDemo {
    private static final Logger logger = Logger.getLogger(MethodDemo.class.getName());
    public static void main(String[] args) {
        /*
         * ========================================================================
         * 步骤1：调用方法并观察参数
         * ========================================================================
         * 数据源：账户对象、基本类型参数和数组
         * 操作：
         * 1) 调用对象方法并检查字段
         * 2) 比较基本类型和引用参数的传递效果
         */
        logger.info("开始演示方法调用");
        // 1.1 调用对象方法
        Wallet wallet = new Wallet();
        wallet.setBalance(10);
        System.out.println("balance=" + wallet.getBalance());
        // 1.2 比较参数变化是否影响调用者
        int amount = 5;
        int[] numbers = {5};
        change(amount, numbers);
        System.out.println("amount=" + amount + ", numbers[0]=" + numbers[0]);
        System.out.println("sum=" + sum(1, 2, 3));
        logger.info("方法调用演示完成");
    }
    static void change(int amount, int[] numbers) {
        amount = 99;
        numbers[0] = 99;
    }
    static int sum(int... values) {
        int total = 0;
        for (int value : values) total += value;
        return total;
    }
}
class Wallet {
    private int balance;
    void setBalance(int balance) {
        if (balance < 0) throw new IllegalArgumentException("余额不能为负数");
        this.balance = balance;
    }
    int getBalance() { return balance; }
}
```

标准输出：

```text
balance=10
amount=5, numbers[0]=99
sum=6
```

## 方法如何声明和调用

`void setBalance(int balance)` 中，`void` 表示没有返回值，`setBalance` 是方法名，括号内是一个 `int` 参数。`wallet.setBalance(10)` 在 `wallet` 指向的对象上调用它。方法中 `this.balance` 是当前对象字段，右侧 `balance` 是参数：赋值前检查负数，合格后才更新字段。`getBalance()` 返回 `int`，调用者可以读取结果。

`return 值` 把结果返回给调用者并结束当前方法；声明为 `void` 的方法可以用单独的 `return;` 提前结束。方法名、参数类型和参数个数需要与调用匹配；多个同名不同参数的方法属于重载，见 [[方法重载]]。实例方法需要对象；`static` 方法属于类，可用类名调用，详见 [[静态字段和静态方法]]。

## 参数到底传了什么

Java **总是按值传递**。基本类型参数拿到数值的副本，所以 `change` 内把参数 `amount` 改为 99，不会改变调用方的 `amount`，它仍是 5。

数组也是对象。传入 `numbers` 时复制的是引用值：方法参数和调用方的引用最初指向同一个数组，因此 `numbers[0] = 99` 修改的是双方看到的数组元素。若在方法中改为 `numbers = new int[]{99}`，只是让方法自己的参数指向新数组，不会改变调用方的引用。对象参数同理。

## 可变参数

`int... values` 在方法体里作为 `int[]` 使用，调用时可以传 0 个或多个 `int`，也可以传一个已有的 `int[]`。例子里 `sum(1, 2, 3)` 将三个元素依次累加为 6；不传元素时循环 0 次，结果为 0。一个方法最多有一个可变参数，且它必须位于参数列表末尾。传入 `null` 数组时这里遍历会抛 `NullPointerException`；实际接口需要明确是否允许 `null`。

## 工作中怎么用

方法命名应说明行为，参数和返回值应体现含义。修改状态的方法要明确校验和失败方式；不要为了省代码直接暴露可变内部数据。金额示例仅用于讲语法，实际金融业务还需要正确的货币单位、并发控制和持久化。

## 手练与答案

1. 调用 `sum()`：结果为 0；调用 `sum(4, 5)`：结果为 9。
2. 将 `change` 内的数组修改改为 `numbers = new int[]{99}`：调用方原数组的第一个元素仍为 5。
3. 调用 `setBalance(-1)`：抛出异常，赋值语句未执行，原余额保持不变。
