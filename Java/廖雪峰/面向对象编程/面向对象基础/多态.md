# 多态

> **重要程度：高**｜**手练：需要**
> **重点**：父类引用、子类重写、运行时方法分派、`@Override`。

## 先看一个调用

设 `Dog` 和 `Cat` 都是 `Animal` 的子类，并分别重写 `speak()`。调用方可以使用 `Animal animal = new Dog()`，再调用 `animal.speak()`。引用类型是 `Animal`，对象实际类型是 `Dog`，实例方法调用会选择 `Dog` 的实现。

把对象换成 `new Cat()`，调用方仍可通过 `Animal` 接口调用相同方法，但行为由 `Cat` 实现。这让调用方依赖稳定的抽象，而不是逐个判断每一种具体类型。

## 两个阶段

编译时检查引用声明类型里是否存在这个方法，以及参数类型是否匹配；运行时对可重写的实例方法按对象实际类型分派。字段与静态方法不采用相同的实例方法动态分派规则。

给重写方法加 `@Override`，可让编译器检查方法是否确实重写了可重写方法。重载与重写不同：重载关心不同参数列表；重写关心父子类中的对应实例方法。

## 手练

建立 `Animal`、`Dog`、`Cat`，让两种动物返回不同叫声；用同一个方法接收 `Animal` 并调用 `speak()`。再尝试通过 `Animal` 类型引用调用只有 `Dog` 才声明的方法，观察编译结果。
