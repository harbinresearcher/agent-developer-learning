# Java 模块

> **重要程度：中**｜**手练：需要**
> **重点**：模块与包、requires、exports、模块路径和反射边界。

## 模块解决什么问题

Java 9 引入模块系统。模块可以包含多个包，并在 `module-info.java` 中声明依赖和对外导出的包。`requires` 表示当前模块读取另一个模块；`exports` 允许其他可读取该模块的代码访问指定包中的公开类型。模块和包不是同一个概念。

## 完整例子

使用 JDK 11 或更高版本。新建空目录，按下列路径创建四个文件。

`src/demo.lib/module-info.java`：

```java
module demo.lib {
    exports demo.lib;
}
```

`src/demo.lib/demo/lib/Greeting.java`：

```java
package demo.lib;
public class Greeting {
    public static String message() { return "你好，模块"; }
}
```

`src/demo.app/module-info.java`：

```java
module demo.app {
    requires demo.lib;
    requires java.logging;
}
```

`src/demo.app/demo/app/Main.java`：

```java
package demo.app;
import java.util.logging.Logger;
import demo.lib.Greeting;
public class Main {
    private static final Logger logger = Logger.getLogger(Main.class.getName());
    public static void main(String[] args) {
        /* ========================================================================
         * 步骤1：调用导出的模块接口
         * 数据源：demo.lib 模块的公共类
         * 操作：1) 调用方法 2) 输出返回值
         * ======================================================================== */
        logger.info("开始调用模块");
        // 1.1 从依赖模块获取消息
        System.out.println(Greeting.message());
        logger.info("模块调用完成");
    }
}
```

在新建目录运行：

```powershell
javac --release 11 -encoding UTF-8 -d out --module-source-path src -m demo.app,demo.lib
java --module-path out -m demo.app/demo.app.Main
```

标准输出为 `你好，模块`，日志单独显示。编译后 `out` 是模块路径根目录；启动参数中斜杠前是模块名，后面是入口类的完整名称。

## 看懂依赖

`demo.lib` 导出 `demo.lib` 包；`demo.app` 通过 `requires demo.lib` 读取它，并因使用日志 API 声明 `requires java.logging`。应用调用公共类 `Greeting`。如果去掉依赖声明，或库不再导出该包，应用对该类的访问无法通过正常编译。

`exports` 控制普通代码对公开类型的访问；框架进行深度反射时，单纯导出不一定足够，可能需要按规则使用 `opens`。不要为了消除错误无差别开放所有内部包。

## 工作中怎么选

模块路径与传统类路径的解析和可见性规则不同。普通 Maven 项目先掌握依赖、包和运行时类路径；是否采用模块系统应遵循项目和依赖的兼容要求，不必为练习强行改造项目。`requires` 也不负责下载依赖，构建工具仍需提供对应模块。

## 动手与自查

1. 运行两条命令，检查输出和 `out` 下的模块目录。
2. 分别去掉 `requires demo.lib` 和 `exports demo.lib`，观察编译错误。
3. 为什么模块中的一个包没有导出时，另一个模块不能仅凭类是 `public` 就直接访问它？
