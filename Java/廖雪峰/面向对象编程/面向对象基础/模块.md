# Java 模块

> **重要程度：低**｜**手练：按需**
> **重点**：模块与包的关系；`requires`、`exports`；先掌握普通项目依赖。

模块系统自 Java 9 引入。模块可以通过 `module-info.java` 声明依赖和对外导出的包；`requires` 声明读取另一个模块，`exports` 控制包向其他模块公开。模块可包含多个包，模块与包不是同义词。

模块路径和传统类路径有不同的解析和可见性规则。新手维护普通 Maven 项目时，先弄清依赖、包和运行时类路径；是否启用模块系统应遵循项目约定，不必为了使用新特性强行改造项目。

反射访问也受模块边界影响。框架需要深度反射时，单纯 `exports` 不一定足够；应按模块规则和框架文档处理 `opens`，避免无差别开放内部包。

## 手练

创建两个最小模块：一个导出包含公共类的包，另一个声明依赖并调用；分别去掉 `requires` 和 `exports`，比较编译错误。
