# 内部类

> **重要程度：中**｜**手练：需要**
> **重点**：成员内部类与静态嵌套类、局部变量捕获、匿名类和 Lambda。

## 按声明位置区分

非静态成员内部类与外部类实例关联，可以访问该实例的成员。静态嵌套类不隐含外部实例，需要访问外部实例数据时应显式传入实例。局部类定义在方法等局部作用域中；匿名类在创建对象时同时定义实现。

## 完整例子

保存为 `InnerClassDemo.java`，使用 JDK 11 或更高版本：

```powershell
javac -encoding UTF-8 InnerClassDemo.java
java InnerClassDemo
```

```java
import java.util.logging.Logger;
public class InnerClassDemo {
    private static final Logger logger = Logger.getLogger(InnerClassDemo.class.getName());
    private final String name;
    InnerClassDemo(String name) { this.name = name; }
    class Member {
        String describe() { return "成员内部类:" + InnerClassDemo.this.name; }
    }
    static class Nested {
        String describe(InnerClassDemo owner) { return "静态嵌套类:" + owner.name; }
    }
    String localExample(String suffix) {
        class Local { String describe() { return name + suffix; } }
        return new Local().describe();
    }
    public static void main(String[] args) {
        /* ========================================================================
         * 步骤1：比较嵌套类的使用方式
         * 数据源：外部实例和局部参数
         * 操作：1) 创建成员与静态嵌套类 2) 调用局部类和匿名类
         * ======================================================================== */
        logger.info("开始内部类示例");
        // 1.1 成员内部类需要关联外部实例
        InnerClassDemo owner = new InnerClassDemo("Alice");
        Member member = owner.new Member();
        Nested nested = new Nested();
        System.out.println(member.describe());
        System.out.println(nested.describe(owner));
        // 1.2 局部类捕获未重新赋值的参数，匿名类实现接口
        System.out.println("局部类:" + owner.localExample("!"));
        Runnable action = new Runnable() {
            public void run() { System.out.println("匿名类:执行"); }
        };
        action.run();
        logger.info("内部类示例完成");
    }
}
```

标准输出，日志单独显示：

```text
成员内部类:Alice
静态嵌套类:Alice
局部类:Alice!
匿名类:执行
```

## 逐步理解

`owner.new Member()` 把成员内部类对象关联到 `owner`；`InnerClassDemo.this` 明确表示外部实例。`new Nested()` 不需要外部实例，例子把 `owner` 显式传给方法。静态嵌套类不能直接访问外部实例的非静态字段。

局部类的 `suffix` 参数没有重新赋值，属于实际上的 final，可以被捕获；若在方法中重新赋值，再引用它会编译失败。匿名类在创建时实现 `Runnable`，适合一次性实现。

## Lambda 和工作中的选择

函数式接口可以用 Lambda 表达，但它不是匿名类的简单文字替换：匿名类中的 `this` 指匿名类实例，Lambda 中的 `this` 指外围作用域的实例。两者在重载解析和对象身份等方面也可能不同，应按代码验证。

只服务于外部类的实现细节可以放在嵌套类中；不需要外部实例时，静态嵌套类通常更容易看清依赖。长期保存非静态内部类实例可能延长关联外部对象的生命周期，注意资源和内存。

## 动手与自查

1. 将 `Member` 改为静态嵌套类并保留对 `InnerClassDemo.this` 的访问，观察编译错误。
2. 在 `localExample` 中重新赋值 `suffix`，观察局部类捕获规则。
3. 把 `Runnable` 改成 Lambda；再分别思考其中 `this` 指向什么。
