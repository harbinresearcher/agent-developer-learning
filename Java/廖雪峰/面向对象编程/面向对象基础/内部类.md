# 内部类

> **重要程度：中**｜**手练：建议**
> **重点**：成员内部类、静态嵌套类、局部类和匿名类的区别。

## 按声明位置区分

非静态成员内部类与外部类实例关联，能访问该外部实例的成员；创建时通常需要一个外部类实例。静态嵌套类不隐含持有外部实例，不能直接访问外部实例的非静态成员。

局部类定义在方法等局部作用域中；匿名类在创建时同时定义具体实现，常用于只使用一次的接口或类实现。lambda 适用于函数式接口，但它不是匿名类的简单文本替换，两者的 `this` 等语义不同。

## 工作中

优先选择结构简单、职责明确的类。嵌套类适合只服务于外部类的实现细节；需要长期保存的内部类实例可能延长其关联外部对象的生命周期，应留意资源和内存。

## 手练

写一个外部类及其内部类，让内部类读取外部实例字段；再把它改为静态嵌套类，观察直接访问该字段时的编译错误。
