# 抽象类

> **重要程度：高**｜**手练：需要**
> **重点**：抽象类不能直接实例化；抽象方法由具体子类实现；与接口的选择。

## 定义与用途

抽象类用 `abstract class` 声明，不能直接 `new`。它可以定义字段、构造器、普通方法，也可以声明没有方法体的抽象方法。非抽象子类必须实现继承来的所有抽象方法，除非继续声明为抽象类。

适合父类既需要共享状态或实现，又需要让子类补全部分行为的情况。例如共同的文档处理流程可以放在抽象类中，把具体格式的解析留给子类。

## 注意边界

抽象类即使不能直接创建实例，也可能有构造器，用于初始化子类对象中的父类部分。抽象类不是“所有方法都必须抽象”。Java 类只能继承一个直接父类；接口更适合表达可由不同类实现的能力。

定义抽象的 `Shape`，声明计算面积的方法；写两个具体形状实现，分别测试面积。尝试直接创建抽象类对象，观察编译器提示。
