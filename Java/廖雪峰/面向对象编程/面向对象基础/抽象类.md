# 抽象类

> **重要程度：高**｜**手练：需要**
> **重点**：抽象方法、共享状态和子类实现。

## 先理解：共同部分已知，具体行为留给子类

圆和矩形都有名字、都能计算面积，但计算公式不同。抽象类可以保存公共状态并提供已有实现，同时声明需要子类补充的抽象方法。抽象类不能直接创建对象；它的具体子类可以实例化。

## 完整例子

保存为 `AbstractDemo.java`，编译并运行；日志写到标准错误。

```java
import java.util.logging.Logger;

public class AbstractDemo {
    private static final Logger logger = Logger.getLogger(AbstractDemo.class.getName());
    public static void main(String[] args) {
        /*
         * ========================================================================
         * 步骤1：计算图形面积
         * ========================================================================
         * 数据源：半径为 2 的圆
         * 操作：
         * 1) 创建具体图形对象
         * 2) 调用子类面积实现和父类公共方法
         */
        logger.info("开始计算图形面积");
        // 1.1 使用抽象父类类型引用具体对象
        Shape shape = new Circle("圆", 2.0);
        // 1.2 调用父类与子类提供的方法
        System.out.println(shape.label());
        System.out.printf(java.util.Locale.ROOT, "area=%.2f%n", shape.area());
        logger.info("图形面积计算完成");
    }
}

abstract class Shape {
    private final String name;
    Shape(String name) { this.name = name; }
    String label() { return "图形: " + name; }
    abstract double area();
}
class Circle extends Shape {
    private final double radius;
    Circle(String name, double radius) {
        super(name);
        if (radius <= 0 || !Double.isFinite(radius)) {
            throw new IllegalArgumentException("半径必须是有限正数");
        }
        this.radius = radius;
    }
    @Override
    double area() { return Math.PI * radius * radius; }
}
```

标准输出：

```text
图形: 圆
area=12.57
```

## 执行过程

`Shape` 是抽象类，有实例字段 `name`、构造器和普通方法 `label()`；`area()` 后面是分号，没有方法体，是抽象方法。`Circle` 继承 `Shape`，用 `super(name)` 初始化父类状态，并提供 `area()` 的实现。

`new Circle("圆", 2.0)` 创建实际对象，引用赋给父类型变量 `shape`。`shape.label()` 调用继承的公共行为，`shape.area()` 动态调用圆的实现，计算 π×2×2。`printf` 把结果显示为两位小数，显示为 12.57；它没有把存储的面积修改为 12.57。

## 规则和边界

- 有抽象方法的类必须声明为 `abstract`；抽象类也可以一个抽象方法都没有。
- 非抽象子类必须实现继承的抽象方法；若未全部实现，子类仍须声明为 `abstract`。
- 抽象类不能直接 `new Shape(...)`，但创建子类对象时会调用父类构造器。
- 抽象方法不能同时是 `private`、`static` 或 `final`：它需要由子类提供实现或重写。

## 工作中怎么用

共享稳定的状态与部分行为、并确有清晰的“是一种”关系时可考虑抽象类。Java 类只能直接继承一个类；如果主要是统一能力契约而不需要共享实例状态，可优先考虑接口。不要为了复用几行代码就引入继承；组合对象也能复用行为。

## 手练与答案

1. 去掉 `Circle.area()`：`Circle` 不再是完整的具体类，编译失败，除非它也声明为抽象类。
2. 将半径改为 -1：构造器抛 `IllegalArgumentException`，无法得到正常的圆对象。
