# 包

> **重要程度：高**｜**手练：需要**
> **重点**：`package`、`import`、完整类名、目录结构与同名类。

## 为什么需要包

包为类提供命名空间。`com.example.order.Order` 的完整类名包含包名和简单类名，不同包可以有同名类。源码通常按包名组织目录，例如包 `com.example.order` 对应目录 `com/example/order`。

源码的 `package` 声明位于文件开头的适当位置；`import` 让代码可以使用简单类名。`java.lang` 中的常见类通常无需显式导入。同一源文件需要使用两个同名类时，可对至少一个使用完整类名。

## 工作中

包还能影响默认访问权限：没有显式访问修饰符的成员通常只在同一个包中可见。包名和部署环境中的文件路径不是同一个概念，Java 项目一般由构建工具编译和管理类路径。

## 手练

在两个不同的包分别定义同名类，在第三个类里同时使用它们；再移除一个类的 `public`，观察其他包中的访问是否通过。
