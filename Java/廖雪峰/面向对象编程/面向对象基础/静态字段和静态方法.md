# 静态字段和静态方法

> **重要程度：高**｜**手练：需要**
> **重点**：类级成员、共享状态与实例成员。

## 先理解：属于类还是属于对象

实例字段各对象各有一份；`static` 字段属于类，所有该类对象共享。实例方法需要通过对象调用；静态方法属于类，一般用 `类名.方法名()` 调用，不需要先创建对象。

## 完整例子

保存为 `StaticDemo.java`，编译并运行；日志写到标准错误。

```java
import java.util.logging.Logger;

public class StaticDemo {
    private static final Logger logger = Logger.getLogger(StaticDemo.class.getName());
    public static void main(String[] args) {
        /*
         * ========================================================================
         * 步骤1：区分类级状态和对象状态
         * ========================================================================
         * 数据源：两个命名对象
         * 操作：
         * 1) 分别创建对象
         * 2) 查询各自名称与共享计数
         */
        logger.info("开始创建对象");
        // 1.1 创建两个独立对象
        Ticket first = new Ticket("A");
        Ticket second = new Ticket("B");
        // 1.2 访问各自字段和类级计数
        System.out.println(first.name());
        System.out.println(second.name());
        System.out.println("count=" + Ticket.createdCount());
        logger.info("对象创建完成");
    }
}

class Ticket {
    private static int created;
    private final String name;
    Ticket(String name) {
        this.name = name;
        created++;
    }
    String name() { return name; }
    static int createdCount() { return created; }
}
```

标准输出：

```text
A
B
count=2
```

## 执行过程

第一次创建 `Ticket`，第一个对象的 `name` 是 A，类字段 `created` 从 0 增至 1。第二次创建另一个对象，它的 `name` 是 B，而同一个 `created` 增至 2。`Ticket.createdCount()` 读取共享计数，因此输出 2。

`private static int created` 在本例类初始化时默认是 0；`private final String name` 是实例字段，每个对象分别初始化。静态方法没有隐含的当前对象 `this`，不能直接访问实例字段 `name`；如果确实有对象，可以通过那个对象访问其可见实例成员。

## 适合与不适合

工具函数、真正的常量、应用入口 `main` 经常使用静态成员。不可变常量常写成 `static final`；若引用指向可变对象，`final` 只禁止重新赋引用，并不让对象内部自动不可变。不要通过实例写 `first.createdCount()`，虽然某些情况下可编译，却容易误以为方法属于该对象。

示例计数只适合理解语法：`created++` 在并发下不是原子操作，结果可能丢失；静态数据也不会自动跨进程、跨重启保存。多线程计数需要并发工具，持久化需要数据库等存储。类加载器不同也可能各有各的类及静态状态。

## 手练与答案

1. 再创建一个 `Ticket("C")` 后，`createdCount()` 返回 3；各对象的名称不变。
2. 在 `createdCount()` 里直接 `return name`：编译失败，因为没有指定要读取哪个对象的实例字段。
