# 静态字段与静态方法

> **重要程度：高**｜**手练：需要**
> **重点**：类成员与实例成员、共享状态、静态方法的访问限制。

## 静态字段

实例字段每个对象各有一份；`static` 字段属于类，由同一类加载器加载的该类的实例共享。计数器、常量或无状态工具可能用到静态成员，但共享可变字段可能引发并发问题。

推荐使用 `类名.静态成员` 调用，让读代码的人看出它不属于单个对象。`static final` 常用于常量；如果引用指向可变对象，`final` 只限制引用重新赋值，不自动让对象不可变。

## 静态方法

静态方法可以不创建对象直接调用。它没有当前实例，因此不能直接使用 `this` 或直接读取实例字段；如果需要访问某个对象，必须持有该对象的引用。实例方法则可以访问当前实例字段。

入口 `main` 是静态方法，启动时不需要先创建主类对象。工具方法可以是静态的，但不应把所有业务都堆进静态方法，尤其是需要替换依赖和单元测试时。

## 手练

创建两个实例，各自修改实例字段，再修改类的静态计数器；记录每次变化。尝试在静态方法中直接使用 `this`，阅读编译错误。
