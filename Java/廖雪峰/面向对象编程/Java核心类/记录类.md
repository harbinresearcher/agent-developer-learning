# 记录类 record

> **重要程度：中**｜**手练：建议**
> **重点**：数据载体、自动生成成员、浅不可变性与版本。

`record` 是表达数据载体的语言特性，Java 16 起正式可用。记录组件声明后，编译器会生成对应访问方法，以及基于组件的 `equals`、`hashCode`、`toString` 等成员；还可以定义构造和校验逻辑。

记录组件对应的字段是 final，但这是浅层限制：如果组件引用一个可变列表，列表本身仍可能被修改。需要不可变快照时要显式做防御性复制，并考虑是否允许 `null`。

手练：用 record 表示坐标；再加入列表组件，尝试从外部修改列表，解释为什么 final 不等于深度不可变。本机如仍使用 Java 11，先切到支持 record 的项目 JDK。

来源：[教程：记录类](https://liaoxuefeng.com/books/java/oop/core/record/index.html)。
