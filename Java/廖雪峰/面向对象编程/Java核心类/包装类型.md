# 包装类型

> **重要程度：高**｜**手练：需要**
> **重点**：基本类型与包装类、装箱拆箱、空值和相等比较。

`int` 是基本类型，`Integer` 是对象类型；集合泛型如 `List<Integer>` 使用包装类型。Java 可以自动装箱和拆箱，但对 `null` 拆箱会抛 `NullPointerException`。

比较包装对象的数值时，不应依赖 `==` 恰好为真。某些值可能使用缓存，是否是同一对象不能代表数值是否相等；按需求使用 `equals`、`Objects.equals` 或在确认非空后比较基本值。

手练：把整数放进 `List<Integer>` 再取出；比较两个不同来源的包装对象；测试 `null` 拆箱的结果。
