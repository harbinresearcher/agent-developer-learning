# 包装类型

> **重要程度：高**｜**手练：需要**
> **重点**：装箱拆箱、null、数值比较与解析。

## 为什么有包装类型

`int` 是基本类型，保存整数值；`Integer` 是引用类型，可表示整数对象，也可能为 `null`。泛型类型参数不能直接写基本类型，所以需要 `List<Integer>` 而不是 `List<int>`。其他对应关系包括 `long/Long`、`double/Double`、`boolean/Boolean` 和 `char/Character`。

## 完整例子

保存为 `BoxingDemo.java`，编译并运行；日志写到标准错误。

```java
import java.util.Objects;
import java.util.logging.Logger;

public class BoxingDemo {
    private static final Logger logger = Logger.getLogger(BoxingDemo.class.getName());
    public static void main(String[] args) {
        /*
         * ========================================================================
         * 步骤1：转换和比较整数
         * ========================================================================
         * 数据源：整数与十进制字符串
         * 操作：
         * 1) 演示装箱、拆箱和字符串解析
         * 2) 比较两个包装对象的数值
         */
        logger.info("开始处理整数");
        // 1.1 自动装箱与拆箱
        Integer boxed = 42;
        int value = boxed;
        // 1.2 解析文本并比较数值
        int parsed = Integer.parseInt("42");
        Integer other = Integer.valueOf(parsed);
        System.out.println("value=" + value);
        System.out.println("sameValue=" + Objects.equals(boxed, other));
        System.out.println("sum=" + (boxed + parsed));
        logger.info("整数处理完成");
    }
}
```

标准输出：

```text
value=42
sameValue=true
sum=84
```

## 按顺序理解

`Integer boxed = 42` 自动把基本类型转换为包装对象，称为装箱；`int value = boxed` 自动取出其中的 `int`，称为拆箱。`Integer.parseInt("42")` 把合法的十进制文本转成 `int`；`Integer.valueOf(parsed)` 得到对应包装类型。`boxed + parsed` 要做数值运算，`boxed` 会拆箱，因此和是 84。

`Objects.equals(boxed, other)` 比较两个包装对象的值，且能处理任一引用为 `null`。两个 `Integer` 引用之间使用 `==` 比较引用身份，不应依赖缓存判断数值是否相等；若一边是 `int`，另一边可能先拆箱再按数值比较。理解操作数类型比背缓存范围更可靠。

## 常见错误

- 对值为 `null` 的 `Integer` 自动拆箱会抛 `NullPointerException`，包括赋给 `int`、参与算术和某些比较。可空字段先判断，或按业务定义默认值，不能随意把缺失当成 0。
- `Integer.parseInt("abc")`、超出 `int` 范围的数字会抛 `NumberFormatException`；外部输入需要处理错误。
- `Integer` 是不可变值对象；把包装对象作为可变计数器共享并不能让 `count++` 变成线程安全操作。并发计数请按场景使用原子类或锁。

## 工作中怎么用

在泛型容器、需要表达“值可能缺失”的接口使用包装类型；确定必须有值时可用基本类型。数据库或 JSON 中的 `null`、缺失与 0 可能有不同业务含义，转换前先确认约定。避免在大量热循环中无必要地反复装箱拆箱，性能应实际测量。

## 手练与答案

1. 把 `boxed` 改为 `null`：`int value = boxed` 处抛 `NullPointerException`，后面的输出不会发生。
2. 把 `"42"` 改为 `"x"`：解析处抛 `NumberFormatException`。
3. 对两个值相同的 `Integer` 用 `==`：结果取决于引用身份，不应作为数值相等的判断。
