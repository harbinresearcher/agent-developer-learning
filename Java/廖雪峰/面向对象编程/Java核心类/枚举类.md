# 枚举类

> **重要程度：高**｜**手练：需要**
> **重点**：枚举成员、状态建模、对外持久化与扩展。

`enum` 用有限且具名的一组常量表达状态，如订单的待支付、已支付和已取消。枚举可以定义字段、构造器和方法；固定集合让调用方比使用没有说明的整数更容易理解。

枚举可以用 `==` 比较同一枚举类型的成员。不要把 `ordinal()` 当作长期稳定的数据库或 API 标识：调整声明顺序会改变序号。需要对外保存时，应约定稳定编码，并处理未知值和后续新增状态。

手练：定义三种订单状态，验证相等比较；设计一个稳定的状态码，说明新增状态如何保持兼容。

来源：[教程：枚举类](https://liaoxuefeng.com/books/java/oop/core/enum/index.html)。
