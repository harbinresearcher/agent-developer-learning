# 常用工具类

> **重要程度：高**｜**手练：需要**
> **重点**：数组排序与比较、空值、整数运算和随机数用途。

## 工具类解决什么问题

Java 标准库提供可复用的静态方法。`Arrays` 操作数组，`Objects` 提供空值检查和相等比较，`Math` 提供常见数学运算。使用前查方法契约，尤其注意是否修改输入、如何处理空值及边界。

## 完整例子

保存为 `UtilsDemo.java`，使用 JDK 11 或更高版本：

```powershell
javac -encoding UTF-8 UtilsDemo.java
java UtilsDemo
```

```java
import java.util.Arrays;
import java.util.Objects;
import java.util.logging.Logger;
public class UtilsDemo {
    private static final Logger logger = Logger.getLogger(UtilsDemo.class.getName());
    public static void main(String[] args) {
        /* ========================================================================
         * 步骤1：比较常用工具方法
         * 数据源：数组、空值和整数
         * 操作：1) 复制排序并比较 2) 检查相等与除法
         * ======================================================================== */
        logger.info("开始工具类示例");
        // 1.1 排序副本，保留原始数组
        int[] original = {3, 1, 2};
        int[] sorted = Arrays.copyOf(original, original.length);
        Arrays.sort(sorted);
        System.out.println("原数组=" + Arrays.toString(original));
        System.out.println("排序后=" + Arrays.toString(sorted));
        System.out.println("内容相同=" + Arrays.equals(original, sorted));
        // 1.2 对比空安全比较和两种整数除法
        System.out.println("空值相等=" + Objects.equals(null, null));
        System.out.println("普通除法=" + (-5 / 2));
        System.out.println("向下取整=" + Math.floorDiv(-5, 2));
        logger.info("工具类示例完成");
    }
}
```

标准输出，日志单独显示：

```text
原数组=[3, 1, 2]
排序后=[1, 2, 3]
内容相同=false
空值相等=true
普通除法=-2
向下取整=-3
```

## 看懂结果

`Arrays.sort` 原地修改传入数组；例子先复制，因此原数组不变。`Arrays.equals` 按对应元素比较一维数组内容，数组的 `==` 比较引用。嵌套数组需要按结构选择合适的深层比较方法，不能假设普通 `equals` 总会递归比较。

`Objects.equals(a, b)` 可安全处理 null；两个 null 返回 true。`Objects.requireNonNull` 可在边界拒绝 null，但是否允许空值仍由业务决定。

整数 `/` 向零截断，所以 `-5 / 2` 为 -2；`Math.floorDiv` 向负无穷取整，得到 -3。除数为零等边界仍需处理；`Math.abs` 对最小整数也有溢出边界。

## 随机数与工作场景

`Random` 适合模拟和普通随机用途；密码重置令牌等安全敏感数据应使用密码学安全随机源，如 `SecureRandom`，并按协议确定长度。随机不等于唯一，唯一性要求还需结合碰撞处理或数据库约束。

金额通常使用合适的十进制表示并明确舍入，不应因为 `Math` 方法方便就忽略浮点精度。处理大数组时还需考虑复制成本和内存占用。

## 动手与自查

1. 直接排序原数组，比较排序前后；解释为什么本例先复制。
2. 比较两个内容相同但分别创建的数组，观察 `==` 和 `Arrays.equals`。
3. 分别计算 `-5 / 2` 与 `Math.floorDiv(-5, 2)`，解释结果差异。
