# 常用工具类

> **重要程度：中**｜**手练：建议**
> **重点**：按需求查 API，理解空值、数组和随机数的适用边界。

`Math` 提供常见数学函数；`Arrays` 提供数组排序、比较和格式化工具；`Objects` 提供空安全的相等比较等辅助方法。了解工具方法是否原地修改输入，以及遇到 `null` 或空数组时的契约。

`Random` 适用于模拟和一般随机用途，不应用于生成密码重置令牌等安全敏感数据。安全用途应使用合适的密码学安全随机源，如 `SecureRandom`，并按协议确定长度。

手练：分别对数组排序和比较内容；解释普通随机数与安全随机数的用途差异。
