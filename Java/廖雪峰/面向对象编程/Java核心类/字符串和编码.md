# 字符串和编码

> **重要程度：高**｜**手练：需要**
> **重点**：字符与字节、UTF-8 编码解码、乱码排查、字符串不可变。

## 先理解：文字如何变成字节

网络和文件最终处理字节；文字要按某种字符编码转成字节，读出时再按相同编码还原。UTF-8 是常见编码，英文和中文编码后的字节数可以不同。若写入和读取使用不同编码，文本可能无法正确还原。

## 完整例子

保存为 `EncodingDemo.java`，用 `javac -encoding UTF-8 EncodingDemo.java` 编译，再运行 `java EncodingDemo`。日志写到标准错误；中文能否正确显示还取决于终端编码。

```java
import java.nio.charset.StandardCharsets;
import java.util.Arrays;
import java.util.logging.Logger;
public class EncodingDemo {
    private static final Logger logger = Logger.getLogger(EncodingDemo.class.getName());
    public static void main(String[] args) {
        /*
         * ========================================================================
         * 步骤1：将文本编码再解码
         * ========================================================================
         * 数据源：一段包含中文的字符串
         * 操作：
         * 1) 使用 UTF-8 编码成字节
         * 2) 使用相同编码还原并验证
         */
        logger.info("开始编码文本");
        // 1.1 使用 UTF-8 将文本转换成字节
        String text = "A中";
        byte[] bytes = text.getBytes(StandardCharsets.UTF_8);
        // 1.2 用相同编码解码并比较内容
        String restored = new String(bytes, StandardCharsets.UTF_8);
        System.out.println("bytes=" + Arrays.toString(bytes));
        System.out.println("restored=" + restored);
        System.out.println("equal=" + text.equals(restored));
        logger.info("文本编码完成");
    }
}
```

标准输出：

```text
bytes=[65, -28, -72, -83]
restored=A中
equal=true
```

## 执行过程

`getBytes(StandardCharsets.UTF_8)` 按 UTF-8 编码：`A` 占一个字节，`中` 占三个字节。`Arrays.toString` 将 Java 有符号 `byte` 按 -128～127 的整数显示，负数不代表编码失败。`new String(bytes, UTF_8)` 用同一编码解码；`equals` 比较内容，所以结果为 true。

`String` 不可变。每次看似修改的操作通常返回新的字符串值；`==` 对两个字符串引用比较身份，文本内容用 `equals` 或 `Objects.equals`。Java 的 `char` 是 UTF-16 代码单元，不保证等同一个完整 Unicode 码点；某些字符需要两个代码单元，`length()` 不一定是用户感知到的字符数量。

## 工作中怎么用

文件读写、HTTP、消息协议明确约定字符编码，不依赖机器默认值。排查乱码时沿着“源文本 → 编码成字节 → 存储或传输 → 解码 → 终端显示”逐段核对，先确认哪一步损坏。二进制图片或压缩包不是文本，不能随意用字符串编码解码处理。

UTF-8 解码遇到无效字节时，普通便捷方法可能用替代字符；如果业务必须拒绝坏数据，使用配置为报告错误的 `CharsetDecoder` 并处理异常。

## 手练与答案

1. 将 `text` 改为 `"A"`：UTF-8 字节数组是 `[65]`，还原后相等。
2. 将解码编码换成与 UTF-8 不同的编码：中文不保证正确还原；具体输出取决于选用的编码及解码策略。
3. `text.length()` 在此为 2，但 UTF-8 编码后有 4 字节；字符序列长度与编码后的字节长度不是同一概念。
