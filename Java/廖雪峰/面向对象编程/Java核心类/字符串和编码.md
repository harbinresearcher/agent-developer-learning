# 字符串和编码

> **重要程度：高**｜**手练：需要**
> **重点**：String 不可变、内容比较、Unicode 和字节编码转换。

`String` 是不可变对象；调用替换等方法会返回结果，不会原地修改原字符串。用 `equals` 比较内容，`==` 比较两个引用是否指向同一个对象。需要允许 `null` 时可考虑 `Objects.equals(a, b)`。

字符与字节不是同一概念。Java 的字符串使用 UTF-16 代码单元表示；一个补充字符可能占两个 `char`。文本转字节和字节转文本应约定同一编码，例如 `StandardCharsets.UTF_8`，不要依赖未知的系统默认编码。

手练：比较两个内容相同的不同字符串对象；将中文文本编码为 UTF-8 后再解码，检查内容是否一致。
