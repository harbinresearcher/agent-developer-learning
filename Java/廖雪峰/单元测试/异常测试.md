# 异常测试

> **重要程度：高**｜**手练：需要**
> **重点**：assertThrows 和错误边界。

## 核心概念

异常测试验证指定输入会否抛出预期异常类型；JUnit 提供 assertThrows 等断言。

## 工作中注意

断言应包住真正触发异常的调用，必要时检查错误信息或业务错误码；不要用过宽的异常类型掩盖错误来源。

## 手练

为负数金额写异常测试，再故意让实现抛不同异常，确认测试能发现差异。
