# 编写JUnit测试

> **重要程度：高**｜**手练：需要**
> **重点**：测试结构、断言和运行。

## 核心概念

JUnit 测试围绕可观察行为组织：准备输入、调用目标、断言结果。实际注解与运行方式以项目 JUnit 版本和构建配置为准。

## 工作中注意

测试需要能够独立重复运行；测试通过说明已有断言通过，不能证明全部情况正确。

## 手练

为计算折扣的方法分别测试正常输入、边界值和非法输入。
