# 使用Fixture

> **重要程度：高**｜**手练：需要**
> **重点**：准备、清理与测试隔离。

## 核心概念

Fixture 是测试运行所需的初始环境，例如测试对象、临时目录和测试数据。JUnit 可在每个测试前后运行准备和清理逻辑。

## 工作中注意

不要让一个测试依赖另一个测试的执行顺序；数据库、文件及静态状态应在测试结束后恢复或隔离。

## 手练

创建临时文件并在测试后清理，连续运行两次确认结果一致。
