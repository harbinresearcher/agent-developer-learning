# 参数化测试

> **重要程度：高**｜**手练：需要**
> **重点**：多组输入、参数来源、命名与边界。

## 解决什么问题

同一业务规则需要验证多组输入时，参数化测试可以复用测试结构，同时让每组数据独立运行和报告。它减少重复，但不应把互不相关的业务规则硬塞到一个测试中。

## 完整例子

保存为 `ParameterTest.java`。该示例需要 JUnit Jupiter 参数化测试支持；下方 standalone jar 已包含所需组件。

```java
import org.junit.jupiter.params.ParameterizedTest;
import org.junit.jupiter.params.provider.CsvSource;
import java.util.logging.Logger;
import static org.junit.jupiter.api.Assertions.assertEquals;

class ParameterTest {
    private static final Logger logger = Logger.getLogger(ParameterTest.class.getName());
    @ParameterizedTest
    @CsvSource({"0, 0", "1, 1", "2, 4", "-2, 4"})
    void squaresNumbers(int input, int expected) {
        /*
         * ========================================================================
         * 步骤1：验证不同输入的平方
         * ========================================================================
         * 数据源：CsvSource 中的四组输入和预期结果
         * 操作：
         * 1) 计算当前输入的平方
         * 2) 检查当前组的预期值
         */
        logger.info("开始测试一组平方输入");
        // 1.1 检查当前参数组的返回值
        assertEquals(expected, square(input));
        logger.info("当前平方输入测试完成");
    }
    static int square(int value) { return value * value; }
}
```

## 运行方式

本例使用 JUnit Platform Console Standalone 1.14.4（包含 JUnit Jupiter），可在 Java 11 运行。将 [standalone jar](https://repo.maven.apache.org/maven2/org/junit/platform/junit-platform-console-standalone/1.14.4/junit-platform-console-standalone-1.14.4.jar) 放在源码所在目录，然后运行：

```text
javac -encoding UTF-8 -cp junit-platform-console-standalone-1.14.4.jar ParameterTest.java
java -jar junit-platform-console-standalone-1.14.4.jar execute --class-path . --select-class ParameterTest --details summary --disable-ansi-colors
```

本示例已用 Java 11 和上述 jar 验证。JUnit 5 系列可在 Java 11 上运行；JUnit 6 要求 Java 17 或更高，项目应按 JDK 和构建配置选兼容版本。日志写到标准错误，测试报告格式可能因版本而异。

默认运行结果：4 个测试成功、0 个跳过、0 个失败。

## 执行过程

`@CsvSource` 提供四行数据，每行按位置绑定到 `input` 和 `expected`。JUnit 对每一行分别执行测试，因此发现四次测试：0、1、2、-2 的平方分别是 0、1、4、4。任意一组的预期值改错，都能作为独立失败报告。

## 常用来源和边界

简单单参数可用 `@ValueSource`；多参数可用 `@CsvSource`；复杂对象或动态数据可用 `@MethodSource`。CSV 的引号、空值和类型转换有具体规则，需要按版本文档处理，不要假设所有字符串都按直觉解析。

示例只覆盖四个小整数；`int` 乘法可能溢出。对于真实金额、日期或非法输入，应按业务选择边界与预期，不要把数据行数量当成测试质量。

## 手练与答案

添加 `"3, 9"` 后应运行 5 组；把 `"-2, 4"` 改为 `"-2, -4"`，该组断言失败，其余组仍可分别报告。
