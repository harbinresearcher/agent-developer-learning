# 中断线程

> **重要程度：高**｜**手练：需要**
> **重点**：中断信号、阻塞与传播。

## 核心概念

interrupt 发出协作式中断请求，不是强制终止。某些阻塞操作响应中断并抛 InterruptedException，线程代码需要决定如何退出或传播。

## 工作中注意

捕获后不能随意吞掉中断；无法继续抛出时通常恢复中断标记，并按项目取消约定清理资源。

## 手练

启动可中断的等待任务，发出中断并等待结束，验证清理代码。
