# 线程的状态

> **重要程度：中**｜**手练：建议**
> **重点**：NEW、RUNNABLE、BLOCKED 和等待。

## 核心概念

Thread.State 提供 NEW、RUNNABLE、BLOCKED、WAITING、TIMED_WAITING、TERMINATED 等状态；RUNNABLE 不等于此刻一定占用 CPU。

## 工作中注意

状态是瞬时快照，看到某个状态不能单独说明根因；结合线程栈和锁持有情况排查。

## 手练

让线程等待锁或等待一定时间，观察其状态并说明快照局限。
