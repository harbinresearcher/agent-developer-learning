# 使用线程池

> **重要程度：高**｜**手练：需要**
> **重点**：任务提交、容量、拒绝与关闭。

## 核心概念

线程池复用线程来执行任务；ExecutorService 提供提交任务和管理生命周期的接口。

## 工作中注意

明确线程数、队列容量、拒绝策略和关闭流程；无限队列或忽略任务异常可能使系统积压或难以排错。

## 手练

用固定大小线程池处理任务，收集结果，再关闭并等待线程池结束。

来源：[教程：使用线程池](https://liaoxuefeng.com/books/java/threading/pool/index.html)。

## 关联知识与实践

`ExecutorService` 将任务提交给线程池，需明确容量、队列、拒绝策略和关闭时机。`Future` 表示异步结果；`CompletableFuture` 可组合多个阶段，但仍要处理异常、超时和线程池选择。`Atomic` 类提供特定原子操作；并发集合提供各自定义的线程安全行为，不等于所有多步业务操作都自动原子。

实现多个任务并发计数，先观察不加同步可能出现的问题，再用锁或原子类验证；实现线程池任务超时、中断和关闭，检查是否有任务被遗留。

来源：[教程：多线程](https://liaoxuefeng.com/books/java/threading/index.html)；[Oracle 虚拟线程](https://docs.oracle.com/en/java/javase/21/core/virtual-threads.html)。
