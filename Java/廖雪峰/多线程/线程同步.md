# 线程同步

> **重要程度：高**｜**手练：需要**
> **重点**：临界区、可见性和锁。

## 核心概念

同步用于协调共享状态访问。正确性要求所有相关线程遵循一致的保护规则；临界区范围要覆盖完整的不变量。

## 工作中注意

volatile 可提供可见性和特定有序性，但不能让自增等复合操作变成原子操作；不要用 sleep 代替同步。

## 手练

对共享计数进行并发更新，再用同步或原子类保护并验证最终值。

来源：[教程：线程同步](https://liaoxuefeng.com/books/java/threading/synchronize/index.html)。

## 关联知识与实践

多个线程读写共享可变数据时，复合操作可能发生竞态。`synchronized` 可保护临界区并提供可见性；要用同一把锁保护同一共享状态。`volatile` 提供可见性和部分有序性，不让 `count++` 这类复合操作自动原子化。多把锁需要统一获取顺序，避免死锁。
