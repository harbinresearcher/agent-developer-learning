# 使用虚拟线程

> **重要程度：中**｜**手练：建议**
> **重点**：Java 21、阻塞 IO 与资源限制。

## 核心概念

虚拟线程自 Java 21 起正式可用，适合大量大部分时间等待 IO 的任务；它仍需要底层平台线程运行。

## 工作中注意

虚拟线程改善并发任务规模，不会让 CPU 计算本身更快，也不能突破数据库连接等下游限制；检查运行时版本及依赖兼容性。

## 手练

在支持 Java 21 的环境运行多个等待 IO 的任务，对比平台线程方案，并测量下游并发上限。
