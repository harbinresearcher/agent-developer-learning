# 同步方法

> **重要程度：高**｜**手练：需要**
> **重点**：实例锁与类锁。

## 核心概念

实例同步方法通常锁住当前实例；静态同步方法锁住对应的 Class 对象。不同实例的实例锁互不相同。

## 工作中注意

如果共享数据由多个对象访问，锁住各自不同实例无法互斥；需明确共享资源与锁对象的对应关系。

## 手练

两个对象分别调用同步方法，观察是否共享锁；再改为使用共同锁并验证。
