# 创建新线程

> **重要程度：高**｜**手练：需要**
> **重点**：start、Runnable 和执行入口。

## 核心概念

可通过 Thread 承载 Runnable 等任务；调用 start 后由 JVM 调度新线程，直接调用 run 只是当前线程中的普通方法调用。

## 工作中注意

业务任务较多时优先考虑受控的执行器，避免无限创建平台线程；线程中的未捕获异常需要可观察。

## 手练

分别调用 start 和 run，输出当前线程名，比较执行位置。

来源：[教程：创建新线程](https://liaoxuefeng.com/books/java/threading/new-thread/index.html)。

## 关联知识与实践

调用 `start()` 启动新线程；直接调用 `run()` 只是普通方法调用。线程执行顺序由调度决定，不能依赖输出顺序。中断是一种协作式取消信号，不是强制杀死线程；捕获 `InterruptedException` 后应按调用约定传播或恢复中断状态。

来源：[教程：多线程](https://liaoxuefeng.com/books/java/threading/index.html)；[Oracle 虚拟线程](https://docs.oracle.com/en/java/javase/21/core/virtual-threads.html)。
