# 设计撮合引擎

> **重要程度：中**｜**手练：按需**
> **重点**：买卖盘、价格和时间优先。

## 核心概念

撮合引擎根据订单规则维护买卖盘，并对满足价格条件的订单产生成交结果。教程介绍价格优先、时间优先的简化模型。

## 工作中注意

匹配规则、价格精度和边界订单必须以实际业务规则为准；教程示例不构成生产交易系统验证。

## 手练

给定两笔买单和两笔卖单，按约定规则手算撮合顺序和剩余数量。

来源：[教程：设计撮合引擎](https://liaoxuefeng.com/books/java/springcloud/engine/match/index.html)。
