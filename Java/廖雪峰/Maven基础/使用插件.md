# 使用插件

> **重要程度：高**｜**手练：需要**
> **重点**：插件、目标、生命周期绑定、版本和编译目标。

## 解决什么问题

Maven 生命周期给构建分阶段；实际编译、运行测试、打包等由插件目标完成。插件自身也有坐标和版本。区分“阶段”和“目标”，才能理解为什么某个阶段会运行某个插件。

## 完整例子：明确编译插件版本

创建 `pom.xml`：

```xml
<project xmlns="http://maven.apache.org/POM/4.0.0" xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance" xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 https://maven.apache.org/xsd/maven-4.0.0.xsd">
    <modelVersion>4.0.0</modelVersion>
    <groupId>example.notes</groupId>
    <artifactId>calculator</artifactId>
    <version>1.0.0</version>
    <properties>
        <maven.compiler.release>11</maven.compiler.release>
        <project.build.sourceEncoding>UTF-8</project.build.sourceEncoding>
    </properties>
    <dependencies>
        <dependency>
            <groupId>org.junit.jupiter</groupId>
            <artifactId>junit-jupiter</artifactId>
            <version>5.14.4</version>
            <scope>test</scope>
        </dependency>
    </dependencies>
    <build><plugins>
        <plugin>
            <groupId>org.apache.maven.plugins</groupId>
            <artifactId>maven-compiler-plugin</artifactId>
            <version>3.14.1</version>
        </plugin>
        <plugin>
            <groupId>org.apache.maven.plugins</groupId>
            <artifactId>maven-surefire-plugin</artifactId>
            <version>3.5.4</version>
        </plugin>
    </plugins></build>
</project>
```

创建 `src/main/java/demo/Calculator.java`：

```java
package demo;
import java.util.logging.Logger;
public class Calculator {
    private static final Logger logger = Logger.getLogger(Calculator.class.getName());
    public int add(int first, int second) {
        /*
         * ========================================================================
         * 步骤1：计算整数和
         * ========================================================================
         * 数据源：调用方提供的两个整数
         * 操作：
         * 1) 计算整数和
         * 2) 返回计算结果
         */
        logger.info("开始计算整数和");
        // 1.1 使用精确加法检查溢出
        int result = Math.addExact(first, second);
        logger.info("整数和计算完成");
        return result;
    }
}
```

在 pom 所在目录运行：

```text
mvn org.apache.maven.plugins:maven-compiler-plugin:3.14.1:compile
```

成功后检查 `target/classes/demo/Calculator.class`。本例已用 Maven 3.9.16、JDK 17、Java 11 编译目标验证；首次运行需下载对应插件及其依赖。直接运行 compile 目标只执行该目标，不表示所有测试和后续生命周期阶段已通过。

## 按顺序理解

pom 的 `maven-compiler-plugin` 版本固定为 3.14.1，`maven.compiler.release` 为 11。Maven 使用其运行时配置的 JDK 编译，并请求符合 Java 11 的语言和公开 API 目标；它不会自动下载完整 Java 11 JDK，也不保证第三方依赖在 Java 11 运行时均兼容。

`groupId:artifactId:version:goal` 可明确指定要执行的插件目标。调用生命周期阶段时，Maven 根据项目 packaging、默认绑定和显式配置执行相应目标；某个阶段是否真的有检查取决于实际插件绑定，不能只看阶段名称。

## 工作中怎么用

统一管理插件版本，查看构建日志确定实际运行的目标；升级前核对 Maven、JDK 与插件兼容性。`pluginManagement` 可集中提供版本和配置，但通常仍需由生命周期绑定或实际插件声明触发执行；不要把放入 management 误当成已执行。

## 手练与答案

1. 将源码改用 Java 11 不存在的较新公开 API：用支持 `--release 11` 的编译器应报错；恢复后重跑。
2. 直接运行 compiler 的 compile 目标不会自动证明 JUnit 测试通过，应另外运行项目的 `mvn test` 或 `mvn verify`。

参考：[廖雪峰：使用插件](https://liaoxuefeng.com/books/java/maven/plugin/index.html)；[Apache Compiler Plugin](https://maven.apache.org/plugins/maven-compiler-plugin/)。
