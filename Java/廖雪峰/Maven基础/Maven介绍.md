# Maven介绍

> **重要程度：高**｜**手练：需要**
> **重点**：项目描述、约定目录和坐标。

## 核心概念

Maven 根据 pom.xml 描述项目，并按生命周期组织构建。groupId、artifactId、version 等坐标用于标识制品。

## 工作中注意

Maven 是构建和依赖管理工具，不是 JDK；构建使用的 JDK 仍需单独核对。

## 手练

检查一个项目的坐标、源码目录和测试目录，运行项目约定的构建命令。
