# 读取classpath资源

> **重要程度：中**｜**手练：建议**
> **重点**：类加载器资源与文件系统区别。

## 核心概念

类路径资源可以通过类或类加载器获取 URL 或输入流，适合读取随应用打包的模板、默认配置等。

## 工作中注意

资源打进 JAR 后不一定是普通文件路径；优先按流读取并处理资源不存在。不要假设打包资源可写。

## 手练

将一个测试文本放入资源目录，打包前后分别读取并比较内容。
