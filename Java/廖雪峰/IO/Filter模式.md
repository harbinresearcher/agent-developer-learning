# Filter模式

> **重要程度：中**｜**手练：建议**
> **重点**：装饰器、流包装与职责。

## 核心概念

过滤流通过包装现有流增加缓冲、数据转换等能力，调用链是外层对象逐层委托给内层。

## 工作中注意

包装顺序影响功能；用 try-with-resources 管理最外层资源，同时确认所用实现的关闭行为。不要重复包装没有实际价值的层。

## 手练

比较直接文件流和缓冲流读取过程，说明包装对象各自承担什么职责。
