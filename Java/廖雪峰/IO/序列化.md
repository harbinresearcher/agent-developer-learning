# 序列化

> **重要程度：中**｜**手练：按需**
> **重点**：Serializable、版本和安全。

## 核心概念

Java 原生序列化可以把支持的对象图写入流并还原；类定义和序列版本等会影响兼容性。

## 工作中注意

不要反序列化不可信来源的原生对象流；跨系统交换一般优先使用明确结构、可校验的数据格式，并限制输入大小。

## 手练

只在隔离测试环境序列化一个简单对象，检查版本变化后的兼容性；说明为什么不直接接受陌生人的对象流。
