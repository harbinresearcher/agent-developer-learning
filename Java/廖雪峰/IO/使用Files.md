# 使用Files

> **重要程度：高**｜**手练：需要**
> **重点**：Path、读写、遍历和资源。

## 核心概念

`Files` 与 `Path` 提供文件和目录操作，例如读取、写入、复制、移动及遍历。具体操作可能抛出 IOException。

## 工作中注意

一次性读取适合规模可控的文件；大文件应流式处理。目录遍历返回的流需要关闭；外部提供路径需验证是否越出允许范围。

## 手练

创建临时目录，写入两个文件并列出，再在结束时清理；检查异常路径下的资源释放。
