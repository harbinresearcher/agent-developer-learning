# File对象

> **重要程度：中**｜**手练：建议**
> **重点**：文件路径、存在性和 Path。

## 核心概念

`File` 表示路径的抽象表示，不保证对应文件一定存在；可查询文件或目录状态。现代 Java 新代码常使用 `Path` 和 `Files` 获得更明确的 API。

## 工作中注意

相对路径由进程工作目录决定；文件状态可能在检查后发生变化，不能只靠先检查再操作保证无竞态。

## 手练

创建测试目录并列出内容；比较相对路径在不同工作目录下指向的位置。
