# 集成Open API

> **重要程度：中**｜**手练：按需**
> **重点**：接口文档与实际契约。

## 核心概念

OpenAPI 描述 HTTP API 的路径、参数、响应等，可结合兼容工具生成交互式文档。

## 工作中注意

文档生成工具与 Boot 版本要兼容；文档暴露范围、鉴权与生产环境安全需控制。

## 手练

为测试接口生成文档，并对照真实响应检查字段和状态码。

来源：[教程：集成Open API](https://liaoxuefeng.com/books/java/springboot/integration/open-api/index.html)。
