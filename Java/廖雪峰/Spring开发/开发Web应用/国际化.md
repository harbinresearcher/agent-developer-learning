# 国际化

> **重要程度：中**｜**手练：需要**
> **重点**：Locale、消息资源、参数替换、语言选择与回退。

## 国际化解决什么问题

国际化把可翻译的文本从业务逻辑中提取出来，根据语言环境选择消息。Spring 的 `MessageSource` 按消息键与 `Locale` 查找模板；模板可以用 `{0}` 等位置插入参数。示例根据请求语言返回中文或英文 JSON。

## 完整例子

使用 JDK 17、Maven 和 Spring Boot 4.1.2。新建目录并保存 `pom.xml`：

```xml
<project xmlns="http://maven.apache.org/POM/4.0.0"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 https://maven.apache.org/xsd/maven-4.0.0.xsd">
    <modelVersion>4.0.0</modelVersion>
    <parent>
        <groupId>org.springframework.boot</groupId><artifactId>spring-boot-starter-parent</artifactId>
        <version>4.1.2</version><relativePath/>
    </parent>
    <groupId>learn.example</groupId><artifactId>i18n-demo</artifactId><version>1.0</version>
    <properties><java.version>17</java.version></properties>
    <dependencies>
        <dependency><groupId>org.springframework.boot</groupId><artifactId>spring-boot-starter-webmvc</artifactId></dependency>
    </dependencies>
    <build><plugins><plugin><groupId>org.springframework.boot</groupId><artifactId>spring-boot-maven-plugin</artifactId></plugin></plugins></build>
</project>
```

保存 `src/main/java/learn/i18n/I18nDemo.java`：

```java
package learn.i18n;
import java.util.Locale;
import java.util.Map;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;
import org.springframework.context.MessageSource;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;
@SpringBootApplication
@RestController
public class I18nDemo {
    private static final Logger logger = LoggerFactory.getLogger(I18nDemo.class);
    private final MessageSource messages;
    public I18nDemo(MessageSource messages) { this.messages = messages; }
    @GetMapping("/greet")
    public Map<String, String> greet(@RequestParam(name = "name", defaultValue = "guest") String name, Locale locale) {
        /* ========================================================================
         * 步骤1：生成本地化问候
         * 数据源：请求参数、语言环境和消息资源
         * 操作：1) 查找消息模板 2) 返回格式化结果
         * ======================================================================== */
        logger.info("开始生成问候");
        try {
            // 1.1 使用当前请求语言查找模板，不把输入拼入模板语法
            String message = messages.getMessage("greeting", new Object[] {name}, locale);
            return Map.of("message", message);
        } finally {
            logger.info("问候生成完成");
        }
    }
    public static void main(String[] args) {
        /* ========================================================================
         * 步骤1：启动国际化示例
         * 数据源：应用配置和消息资源文件
         * 操作：1) 启动容器 2) 提供本地接口
         * ======================================================================== */
        logger.info("开始启动国际化示例");
        // 1.1 启动内嵌服务器
        SpringApplication.run(I18nDemo.class, args);
        logger.info("国际化示例启动完成");
    }
}
```

保存 `src/main/resources/messages.properties`：

```properties
greeting=Hello, {0}!
```

保存 `src/main/resources/messages_en.properties`：

```properties
greeting=Hello, {0}!
```

保存 `src/main/resources/messages_zh.properties`：

```properties
greeting=你好，{0}！
```

确认 `java -version` 和 `mvn -v` 使用 JDK 17 或以上，在工程目录运行：

```powershell
mvn package
java -jar target/i18n-demo-1.0.jar --server.address=127.0.0.1 --server.port=8080
```

另开 PowerShell：

```powershell
curl.exe -H "Accept-Language: zh-CN" "http://127.0.0.1:8080/greet?name=Alice"
curl.exe -H "Accept-Language: en-US" "http://127.0.0.1:8080/greet?name=Alice"
```

第一条 JSON 的 `message` 为 `你好，Alice！`，第二条为 `Hello, Alice!`。服务窗口按 `Ctrl+C` 停止；端口被占用时同步修改启动参数与请求地址。

## 看懂语言选择

请求携带 `Accept-Language`，Spring MVC 根据当前配置解析 `Locale` 并传入控制器；`MessageSource` 用键 `greeting` 找资源并替换 `{0}`。示例同时提供基础、英文和中文资源，便于明确两个测试结果。

缺失特定语言时的回退受消息源配置和系统语言环境影响，不能假设一定先得到预期语言；应在项目中定义并测试默认语言。请求头可以被客户端修改，不应用它决定用户权限或可信身份。

## 工作中注意

统一管理消息键、占位参数和编码，测试缺失键及不同语言。日期、数字、货币的本地化还涉及时区、精度和格式，不能只翻译文案。用户输入显示到 HTML 时仍需按输出上下文转义；国际化本身不提供输入安全。

## 动手与自查

1. 分别发送中文和英文语言头，检查响应。
2. 增加另一语言资源并请求对应 Locale，观察回退。
3. 为什么客户端提供的语言头不能作为授权依据？
