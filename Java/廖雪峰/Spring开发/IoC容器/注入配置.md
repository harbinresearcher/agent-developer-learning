# 注入配置

> **重要程度：高**｜**手练：需要**
> **重点**：属性来源、默认值、类型转换和启动校验。

## 配置为什么要外置

服务地址、超时、环境开关在不同环境可能不同，不应散落在业务代码中。Spring 的 `Environment` 读取多个属性源；`${client.endpoint}` 取必需属性，`${client.timeout:5}` 在缺少该项时使用默认值 5。示例直接添加内存属性源以便复现，不会访问示例地址。


## 完整例子

使用 JDK 17、Maven 和 Spring Framework 7.0.10。Spring 6 及以上要求 Java 17 或更高版本；当前项目如使用其他版本，应遵循其依赖管理与兼容要求。新建空目录，将下列内容保存为 `pom.xml`：

```xml
<project xmlns="http://maven.apache.org/POM/4.0.0"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 https://maven.apache.org/xsd/maven-4.0.0.xsd">
    <modelVersion>4.0.0</modelVersion>
    <groupId>learn.example</groupId><artifactId>spring-ioc-demo</artifactId><version>1.0</version>
    <properties><maven.compiler.release>17</maven.compiler.release><project.build.sourceEncoding>UTF-8</project.build.sourceEncoding></properties>
    <dependencies>
        <dependency><groupId>org.springframework</groupId><artifactId>spring-context</artifactId><version>7.0.10</version></dependency>
    </dependencies>
    <build><plugins><plugin><groupId>org.apache.maven.plugins</groupId><artifactId>maven-compiler-plugin</artifactId><version>3.14.1</version></plugin></plugins></build>
</project>
```

代码保存为 `src/main/java/PropertyInjectionDemo.java`：

```java
import java.util.Map;
import java.util.logging.Logger;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.context.annotation.AnnotationConfigApplicationContext;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.core.env.MapPropertySource;
public class PropertyInjectionDemo {
    private static final Logger logger = Logger.getLogger(PropertyInjectionDemo.class.getName());
    static class ClientSettings {
        final String endpoint;
        final int timeoutSeconds;
        ClientSettings(String endpoint, int timeoutSeconds) {
            if (endpoint.isBlank() || timeoutSeconds <= 0) throw new IllegalArgumentException("配置无效");
            this.endpoint = endpoint; this.timeoutSeconds = timeoutSeconds;
        }
    }
    @Configuration
    static class Config {
        @Bean ClientSettings settings(@Value("${client.endpoint}") String endpoint,
                                      @Value("${client.timeout:5}") int timeout) {
            return new ClientSettings(endpoint, timeout);
        }
    }
    public static void main(String[] args) {
        /* ========================================================================
         * 步骤1：注入并检查配置
         * 数据源：演示用的属性源
         * 操作：1) 在刷新前加入属性 2) 创建并读取配置 Bean
         * ======================================================================== */
        logger.info("开始加载配置");
        try (AnnotationConfigApplicationContext context = new AnnotationConfigApplicationContext()) {
            // 1.1 将模拟环境配置放入容器属性源
            context.getEnvironment().getPropertySources().addFirst(
                new MapPropertySource("demo", Map.of("client.endpoint", "https://example.test")));
            context.register(Config.class);
            context.refresh();
            // 1.2 读取已校验的设置，不发起网络请求
            ClientSettings settings = context.getBean(ClientSettings.class);
            System.out.println("地址: " + settings.endpoint);
            System.out.println("超时秒数: " + settings.timeoutSeconds);
        }
        logger.info("配置加载完成");
    }
}
```

在项目根目录运行（PowerShell）：

先运行 `java -version` 和 `mvn -v`，确认两者都使用 JDK 17 或以上；不一致时先调整 `JAVA_HOME` 和 `PATH`。

```powershell
mvn package
mvn org.apache.maven.plugins:maven-dependency-plugin:3.7.0:build-classpath "-Dmdep.outputFile=classpath.txt"
$springDeps = (Get-Content -Raw -Encoding UTF8 classpath.txt).Trim()
java -cp "target/classes;$springDeps" PropertyInjectionDemo
```

标准输出如下，框架和示例日志可能单独显示：

```text
地址: https://example.test
超时秒数: 5
```

## 读取、转换和校验

容器解析占位符，把超时文本转换成 `int`，再调用构造器；本例还检查地址非空、超时大于零。缺失必需项或转换失败会使相应 Bean 创建失败；延迟创建的 Bean 可能到首次请求时才暴露错误。默认值解决缺省，不等于业务校验。

属性源有优先顺序，例子通过 `addFirst` 显式放在前面。生产项目必须查实际启动方式和框架的配置优先级，不要把这个演示顺序当成所有 Spring Boot 环境的完整规则。

## 工作中怎么用

敏感密码、密钥使用受控的密钥管理渠道，不提交源码、不写入日志。配置项较多时，Spring Boot 项目可按版本使用类型安全的配置属性和校验，不必散落大量 `@Value`。单位写入属性名或配置约定，避免秒和毫秒混淆。

## 动手与自查

1. 在 Map 中加入 `client.timeout`，验证显式值覆盖默认值。
2. 分别设为 `0` 和 `abc`，观察校验失败与类型转换失败的区别。
3. 删除必需的地址属性，说明异常在何时出现。
