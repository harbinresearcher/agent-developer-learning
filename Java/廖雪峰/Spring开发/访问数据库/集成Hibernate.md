# 集成Hibernate

> **重要程度：中**｜**手练：按需**
> **重点**：ORM、会话和映射。

## 核心概念

Hibernate 是 Java 常用 ORM 实现，可管理对象与关系数据之间的映射。

## 工作中注意

关注持久化上下文、惰性加载、查询数量和数据库事务；版本需与 Spring 及 Jakarta API 匹配。

## 手练

加载带关联对象的测试数据，检查实际查询数量并识别 N+1。
