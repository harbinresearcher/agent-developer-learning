# 集成第三方组件

> **重要程度：高**｜**手练：需要**
> **重点**：依赖、配置、资源生命周期、超时和失败处理。

## 集成组件时先确认什么

第三方组件可能是邮件客户端、消息代理、数据库驱动或管理接口。接入时先确认版本兼容和依赖，再确定连接地址、认证、超时、资源关闭与失败行为。Spring 提供依赖注入和各类抽象，但不会替应用决定重试是否安全。

下面以离线构造邮件为例，展示组件依赖和 API 的使用；例子不连接 SMTP，也不发送邮件。

## 完整例子

使用 JDK 17、Maven 和 Spring Boot 4.1.2。新建目录并保存 `pom.xml`：

```xml
<project xmlns="http://maven.apache.org/POM/4.0.0"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 https://maven.apache.org/xsd/maven-4.0.0.xsd">
    <modelVersion>4.0.0</modelVersion>
    <parent>
        <groupId>org.springframework.boot</groupId><artifactId>spring-boot-starter-parent</artifactId>
        <version>4.1.2</version><relativePath/>
    </parent>
    <groupId>learn.example</groupId><artifactId>spring-mail-demo</artifactId><version>1.0</version>
    <properties><java.version>17</java.version></properties>
    <dependencies>
        <dependency><groupId>org.springframework.boot</groupId><artifactId>spring-boot-starter</artifactId></dependency>
        <dependency><groupId>org.springframework.boot</groupId><artifactId>spring-boot-starter-mail</artifactId></dependency>
    </dependencies>
    <build><plugins><plugin><groupId>org.springframework.boot</groupId><artifactId>spring-boot-maven-plugin</artifactId></plugin></plugins></build>
</project>
```

保存 `src/main/java/learn/mail/MailDemo.java`：

```java
package learn.mail;
import jakarta.mail.Message;
import jakarta.mail.internet.MimeMessage;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.mail.javamail.JavaMailSenderImpl;
import org.springframework.mail.javamail.MimeMessageHelper;
public class MailDemo {
    private static final Logger logger = LoggerFactory.getLogger(MailDemo.class);
    public static void main(String[] args) throws Exception {
        /* ========================================================================
         * 步骤1：构造并检查邮件
         * 数据源：演示用地址、主题和正文
         * 操作：1) 创建 MIME 消息 2) 检查消息字段
         * ======================================================================== */
        logger.info("开始构造邮件");
        // 1.1 离线构造消息，不连接 SMTP 服务
        JavaMailSenderImpl sender = new JavaMailSenderImpl();
        MimeMessage message = sender.createMimeMessage();
        MimeMessageHelper helper = new MimeMessageHelper(message, false, "UTF-8");
        helper.setFrom("sender@example.test");
        helper.setTo("reader@example.test");
        helper.setSubject("测试通知");
        helper.setText("订单已创建", false);
        message.saveChanges();
        // 1.2 检查主题与收件人，不发送消息
        System.out.println("主题=" + message.getSubject());
        System.out.println("收件人=" + message.getRecipients(Message.RecipientType.TO)[0]);
        logger.info("邮件构造完成");
    }
}
```

确认 `java -version` 和 `mvn -v` 使用 JDK 17 或以上，在工程目录运行：

```powershell
mvn package
java -jar target/spring-mail-demo-1.0.jar
```

日志中应看到：

```text
主题=测试通知
收件人=reader@example.test
```

## 结合例子理解

`JavaMailSenderImpl` 创建 MIME 消息，`MimeMessageHelper` 设置演示地址、UTF-8 主题和正文；读取主题与收件人可验证构造结果。它没有调用发送方法，因此没有验证网络、凭据或邮件投递。

真实 SMTP 集成还需根据服务商文档配置 TLS、认证和连接、读写超时；凭据使用受控渠道。超时后的结果可能不确定，重试需考虑重复邮件和业务幂等。

## 工作中怎么用

邮件、消息和定时任务等都需要明确失败记录、重试和告警；连接池与客户端通常应由容器管理并在关闭时释放。涉及数据库与外部消息时，两个系统不会自动共享一个原子事务。
