# 编写泛型

> **重要程度：中**｜**手练：需要**
> **重点**：声明 `Box<T>`；让字段、参数和返回值使用同一个类型；区分泛型类与泛型方法。

## 先看需求

要做一个盒子：有时装姓名，有时装年龄。可以分别写 `StringBox` 和 `IntegerBox`，但保存和读取逻辑相同。泛型让一份类定义适用于不同类型，同时保留编译期检查。

`Box<T>` 中的 `T` 是**类型参数**，可以理解为“定义类时暂未指定的类型”。使用 `Box<String>` 时，调用方按字符串使用这个盒子；使用 `Box<Integer>` 时按整数包装类使用。

## 完整例子

保存为 `GenericBoxDemo.java`，在文件目录执行 `javac -encoding UTF-8 GenericBoxDemo.java`，再执行 `java GenericBoxDemo`。JDK 自带日志，不需额外依赖。

```java
import java.util.logging.Logger;

public class GenericBoxDemo {
    private static final Logger logger = Logger.getLogger(GenericBoxDemo.class.getName());

    public static void main(String[] args) {
        /*
         * ========================================================================
         * 步骤1：创建并读取不同类型的盒子
         * ========================================================================
         * 目标：观察泛型类的类型参数如何约束方法。
         * 数据源：姓名和年龄。
         * 操作：
         * 1) 分别创建字符串盒子和整数盒子。
         * 2) 按对应类型读取并输出内容。
         */
        logger.info("开始创建泛型盒子");
        // 1.1 创建两个不同类型的盒子
        Box<String> nameBox = new Box<>("小明");
        Box<Integer> ageBox = new Box<>(18);
        // 1.2 读取两个盒子的值
        String name = nameBox.get();
        Integer age = ageBox.get();
        System.out.println(name + ": " + age);
        logger.info("泛型盒子读取完成");
    }

    static class Box<T> {
        private final T value;

        Box(T value) {
            this.value = value;
        }

        T get() {
            return value;
        }
    }
}
```

标准输出：`小明: 18`。

### 按顺序看

1. `class Box<T>` 声明一个类型参数 `T`。
2. 字段 `T value`、构造器参数 `T value` 和 `get()` 返回类型 `T` 使用的是同一个类型参数。
3. 创建 `Box<String>` 后，构造器接收字符串，`get()` 的结果按 `String` 使用；创建 `Box<Integer>` 时同理。
4. `new Box<>(...)` 中的菱形让编译器从上下文推断类型参数。

如果把 `nameBox.get()` 赋给 `Integer`，或者向只接收 `String` 的 `Box<String>` 传整数，编译器会报错。`Integer` 是引用类型；不能把 `int` 直接写成泛型类型参数。

## 泛型类和泛型方法

泛型类在类名处声明参数，实例的方法可使用这个参数。泛型方法则在方法自己的返回类型之前声明类型参数，即使所在类不是泛型类也可以使用。两者声明的位置和作用范围不同，不要只看到 `<T>` 就以为它属于整个类。

需要限制可接受类型时，可声明上界，例如 `T extends Number`。这表示 `T` 必须是 `Number` 或其子类型；它让代码能够按 `Number` 使用值，不代表可以用 `new T()` 创建对象。

## 手练与自测

1. 把 `nameBox` 的类型改成 `Box<Integer>`，但保留字符串实参。编译会怎样？
2. 为什么 `Box<int>` 不合法，`Box<Integer>` 可以？
3. `Box<T>`、字段 `T value` 和方法 `T get()` 的三个 `T` 有什么关系？

**答案要点**：① 实参与 `Integer` 不匹配，编译失败。② Java 泛型参数使用引用类型。③ 三者是同一个类型参数，具体类型由使用该类时确定。
