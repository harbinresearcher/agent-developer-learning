# 编写泛型

> **重要程度：中**｜**手练：建议**
> **重点**：泛型类、泛型方法和类型边界。

## 核心概念

泛型类在类名后声明类型参数，例如 `Box<T>`；泛型方法也能声明自己的类型参数，用于表达输入和返回类型之间的关系。类型参数名只是标识符，`T`、`E` 常见但不是强制名称。

## 工作中注意

可以用 `T extends 某类型` 限制允许的类型及可调用方法。不要仅为一处简单代码添加多层泛型抽象；优先确保调用方能看懂类型关系。

## 手练

设计一个只能接收 Number 子类型的容器；解释它能调用 Number 的哪些方法，以及为何不能接收字符串。
