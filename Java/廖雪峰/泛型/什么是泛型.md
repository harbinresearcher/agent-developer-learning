# 什么是泛型

> **重要程度：高**｜**手练：需要**
> **重点**：类型参数、编译期检查和减少强制转换。

## 核心概念

没有泛型的容器按 Object 使用时，取值往往要强制转换，错误可能到运行时才暴露。`List<String>` 把元素类型写进类型系统，让编译器更早发现放入不匹配类型的代码。

## 工作中注意

泛型不会替外部数据做业务校验，也不能保证集合本身或元素一定非空。原始类型会削弱检查，维护旧代码时要留意未经检查的警告。

## 手练

尝试把整数加入 `List<String>`，阅读编译器报错；再说明泛型不能保证字符串内容符合业务要求。
