# 使用泛型

> **重要程度：高**｜**手练：需要**
> **重点**：声明、实例化、类型参数与基本类型包装。

## 核心概念

声明 `List<String>` 表示列表元素按字符串类型使用；构造时可以使用菱形语法 `new ArrayList<>()`，让编译器依据上下文推断类型参数。

## 工作中注意

泛型参数必须是引用类型，不能写 `List<int>`；整数应使用 `Integer`。包装对象可能为 null，自动拆箱时要考虑空指针。`List<Integer>` 不是 `List<Number>` 的子类型。

## 手练

创建整数列表并计算总和；加入 null 后观察拆箱错误，再决定应该拒绝还是显式处理空值。
