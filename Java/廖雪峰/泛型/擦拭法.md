# 擦拭法

> **重要程度：高**｜**手练：建议**
> **重点**：类型擦除、运行时边界和编译错误。

## 核心概念

Java 泛型通常通过类型擦除实现：编译时检查类型并在需要时插入转换，运行时对象一般不保留可直接区分每个泛型实参的完整信息。

## 工作中注意

因此不能用 `instanceof List<String>` 区分字符串列表，也不能直接 `new T()` 或 `new T[]`。泛型擦除后的方法签名可能冲突；不要依赖不安全的强制转换绕过编译器。

## 手练

解释为什么运行时无法单凭列表对象可靠区分 `List<String>` 与 `List<Integer>`；通过编译器验证一个非法的泛型实例创建。
