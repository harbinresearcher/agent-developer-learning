# 泛型和反射

> **重要程度：中**｜**手练：按需**
> **重点**：泛型擦除、Class 对象和声明元数据。

## 核心概念

普通实例的运行时 Class 通常不能区分不同泛型实参，例如不同元素类型的 ArrayList 实例具有同一个原始类。部分声明位置保留的泛型签名可以通过反射查询，但不等于所有对象运行时都保留实参。

## 工作中注意

需要运行时类型信息时，可由调用者显式传入 `Class<T>`，或按框架约定传入类型描述；不要把未经检查转换当成可靠验证。

## 手练

比较两个不同类型参数的列表实例的 Class，再查看一个显式声明泛型字段的反射类型，说明两者差异。
