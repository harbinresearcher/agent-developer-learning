# Java集合简介

> **重要程度：高**｜**手练：需要**
> **重点**：集合接口、实现类和选型。

## 核心概念

Collection 表示一组元素，常见子接口包括 List、Set、Queue；Map 是键值映射，不继承 Collection。接口描述能力，实现类决定具体行为。

## 工作中注意

先根据是否需要顺序、唯一性、键值查找及并发访问选择，再考虑数据规模和性能；不应只背实现类名称。

## 手练

把学生名单、唯一标签和用户编号到用户信息分别映射到合适的集合接口。
