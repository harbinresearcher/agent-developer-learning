# 使用List

> **重要程度：高**｜**手练：需要**
> **重点**：顺序、下标和实现类。

## 核心概念

List 是有序集合，通常允许重复元素；`get(i)` 按下标读取，越界会抛异常。ArrayList 常用于随机访问，具体选择需结合访问和修改方式。

## 工作中注意

列表的下标从零开始；删除元素会改变后续下标。`List.of` 创建的列表不可结构修改，并拒绝 null；不要混淆“不可修改视图”和对象深度不可变。

## 手练

创建学生列表，插入、查找并删除元素；验证下标越界和 `List.of` 修改行为。
