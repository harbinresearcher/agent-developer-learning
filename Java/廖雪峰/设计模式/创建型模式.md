# 创建型模式

> **重要程度：中**｜**手练：按需**
> **重点**：对象创建与适用场景。

## 核心概念

创建型模式讨论怎样创建对象，包括工厂方法、抽象工厂、Builder、原型和单例。

## 工作中注意

只有出现真实变化或复杂构造需求时再引入模式，避免无意义的层次。

## 手练

为复杂配置对象比较直接构造器与 Builder 的可读性。

来源：[教程：创建型模式](https://liaoxuefeng.com/books/java/design-patterns/creational/index.html)。

## 关联知识与实践

- 创建型：工厂方法把对象创建交给具体实现；抽象工厂创建一组相关对象；Builder 逐步构造复杂对象；原型按已有对象复制；单例控制实例数量，但需要考虑并发、测试和生命周期。
- 结构型：适配器转换接口，装饰器包装并增强行为，外观简化多个组件的调用；代理控制访问或附加行为。桥接、组合和享元按实际需求了解。
- 行为型：策略替换可变算法，责任链串联处理步骤，观察者在状态变化时通知订阅方，模板方法定义固定流程和可变步骤。命令、状态、迭代器、中介、备忘录、访问者和解释器可先认识问题背景。

来源：[教程：设计模式](https://liaoxuefeng.com/books/java/design-patterns/index.html)。
