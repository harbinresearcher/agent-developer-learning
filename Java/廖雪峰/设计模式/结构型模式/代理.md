# 代理

> **重要程度：高**｜**手练：需要**
> **重点**：接口、包装对象、调用顺序和异常边界。

## 代理做什么

代理对象实现与目标相同的接口，调用方先访问代理，代理决定是否、何时以及如何调用目标。它可在调用前后加入权限校验、审计、计时、缓存，或者把请求转发到远端。

这个例子是静态代理：`LoggingProxy` 在代码中明确实现接口并持有目标。`finally` 在正常返回和目标抛异常时都会记录耗时；目标的返回值和异常继续传给调用方。真正的日志要避免输出令牌、密码和敏感参数。


## 完整例子

保存为 `ProxyDemo.java`，使用 JDK 11 或更高版本：

```powershell
javac -encoding UTF-8 ProxyDemo.java
java ProxyDemo
```

```java
import java.util.logging.Logger;
public class ProxyDemo {
    private static final Logger logger = Logger.getLogger(ProxyDemo.class.getName());
    interface OrderService { String find(int id); }
    static final class RealOrderService implements OrderService {
        public String find(int id) {
            if (id <= 0) throw new IllegalArgumentException("订单编号无效");
            return "订单-" + id;
        }
    }
    static final class LoggingProxy implements OrderService {
        private final OrderService target;
        LoggingProxy(OrderService target) { this.target = target; }
        public String find(int id) {
            long start = System.nanoTime();
            try { return target.find(id); }
            finally { logger.info("订单查询耗时纳秒: " + (System.nanoTime() - start)); }
        }
    }
    public static void main(String[] args) {
        /* ========================================================================
         * 步骤1：通过代理查询订单
         * 数据源：内存中的模拟订单服务
         * 操作：1) 包装真实服务 2) 调用并验证返回值
         * ======================================================================== */
        logger.info("开始查询");
        // 1.1 通过相同接口组合代理与目标
        OrderService service = new LoggingProxy(new RealOrderService());
        // 1.2 代理负责计时，真实服务负责查询
        System.out.println(service.find(7));
        logger.info("查询完成");
    }
}
```

标准输出（日志单独输出）：

```text
订单-7
```

## 在工作中辨认代理

Java 动态代理可在运行时为接口生成代理；框架也可能使用其他代理机制。Spring AOP 的代理能否生效取决于调用是否经过代理：同一个对象内部直接调用自己的另一个方法通常不会重新经过代理。具体事务、切面和代理类型要结合实际配置与框架版本验证。

装饰器也常包装同接口对象；代理更侧重控制访问或调用方式，装饰器更侧重组合增强职责，两者的类结构可能非常相似。不要只靠是否存在包装类来断言模式。

## 手练与自查

1. 调用 `find(0)` 并捕获异常，确认目标异常没有被代理吞掉，计时日志仍出现。
2. 在代理中加入只允许正整数的前置校验，思考校验与目标职责如何划分。
3. 同类内部 `this.method()` 为什么可能绕过基于代理的切面？
