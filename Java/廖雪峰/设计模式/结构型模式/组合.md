# 组合

> **重要程度：中**｜**手练：需要**
> **重点**：树形结构、统一接口、叶节点与组合节点。

## 它解决什么问题

组合模式将单个对象和由多个对象组成的结构统一为同一接口，适合表示树。例子中 `FileNode` 是叶节点，`Folder` 是组合节点；两者都实现 `Node.size()`，调用方不必按类型分别统计。


## 完整例子

保存为 `CompositeDemo.java`，使用 JDK 11 或更高版本：

```powershell
javac -encoding UTF-8 CompositeDemo.java
java CompositeDemo
```

```java
import java.util.ArrayList;
import java.util.List;
import java.util.logging.Logger;
public class CompositeDemo {
    private static final Logger logger = Logger.getLogger(CompositeDemo.class.getName());
    interface Node { int size(); }
    static class FileNode implements Node {
        private final int bytes;
        FileNode(int bytes) { this.bytes = bytes; }
        public int size() { return bytes; }
    }
    static class Folder implements Node {
        private final List<Node> children = new ArrayList<>();
        void add(Node node) { children.add(node); }
        public int size() {
            int total = 0;
            for (Node child : children) total += child.size();
            return total;
        }
    }
    public static void main(String[] args) {
        /* ========================================================================
         * 步骤1：统计模拟目录大小
         * 数据源：内存中的目录树
         * 操作：1) 组装文件和子目录 2) 递归计算大小
         * ======================================================================== */
        logger.info("开始统计目录");
        // 1.1 组装一棵无环的树
        Folder root = new Folder();
        Folder sub = new Folder();
        sub.add(new FileNode(20));
        root.add(new FileNode(10));
        root.add(sub);
        // 1.2 从根节点调用统一接口
        System.out.println("总大小=" + root.size());
        logger.info("目录统计完成");
    }
}
```

标准输出，日志单独显示：

```text
总大小=30
```

## 递归过程

根目录先得到文件大小 10，再调用子目录的 `size()` 得到 20，最后相加为 30。例子只模拟结构，没有访问真实文件系统。真实目录可能存在符号链接、权限错误和循环，不能假定总是一棵无环树。

## 工作中怎么用

组织架构、菜单和文件树等可用组合模型。新增或移动节点时需考虑循环、层级过深、权限和统计溢出；本例使用 `int` 和递归仅为简化，真实大数据要选择合适数值范围和遍历方式。

## 动手与自查

1. 再加一个 5 字节文件，预测并验证结果。
2. 将目录加入它自己，说明为什么会产生问题；生产代码应如何拒绝循环？
3. 为什么客户端可以对文件和目录统一调用 `size()`？
