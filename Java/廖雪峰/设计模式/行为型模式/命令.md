# 命令

> **重要程度：中**｜**手练：需要**
> **重点**：封装请求、调用方与接收者、撤销和重试边界。

## 它解决什么问题

命令模式把一次操作封装成对象。例子中 `Button` 是调用方，`TurnOn` 保存接收者 `Light` 并执行开灯，`Command` 定义统一入口。按钮不需要知道开灯的具体实现，可以接收其他命令。


## 完整例子

保存为 `CommandDemo.java`，使用 JDK 11 或更高版本：

```powershell
javac -encoding UTF-8 CommandDemo.java
java CommandDemo
```

```java
import java.util.logging.Logger;
public class CommandDemo {
    private static final Logger logger = Logger.getLogger(CommandDemo.class.getName());
    interface Command { void execute(); }
    static class Light {
        private boolean on;
        void turnOn() { on = true; }
        boolean isOn() { return on; }
    }
    static class TurnOn implements Command {
        private final Light light;
        TurnOn(Light light) { this.light = light; }
        public void execute() { light.turnOn(); }
    }
    static class Button {
        private final Command command;
        Button(Command command) { this.command = command; }
        void press() { command.execute(); }
    }
    public static void main(String[] args) {
        /* ========================================================================
         * 步骤1：通过按钮执行开灯命令
         * 数据源：模拟灯、命令和按钮
         * 操作：1) 组合对象 2) 调用并检查状态
         * ======================================================================== */
        logger.info("开始执行命令");
        // 1.1 将接收者注入命令，再将命令交给调用者
        Light light = new Light();
        Button button = new Button(new TurnOn(light));
        // 1.2 按钮不直接依赖灯的具体操作
        button.press();
        System.out.println("灯已开=" + light.isOn());
        logger.info("命令执行完成");
    }
}
```

标准输出，日志单独显示：

```text
灯已开=true
```

## 与直接调用的区别

直接调用适合简单、一次性的操作；封装为命令后，更容易把请求传递、排队或记录，但这些能力必须另外实现。例子是同步调用，没有队列、持久化、重试或撤销。

## 工作中怎么用

撤销需要保存足够的原始状态，并定义不可逆操作的处理；重试需要业务幂等，不能因为请求包装成命令就认为重复执行安全。命令中的参数、权限和敏感数据也需要校验和保护。
