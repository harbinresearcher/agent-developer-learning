# 解释器

> **重要程度：中**｜**手练：需要**
> **重点**：受限语法、表达式树、解析与求值、非法输入。

## 它解决什么问题

当输入遵循一套较简单的规则时，可以把语法元素表示为对象，再按规则解释。例子支持的语法只有 `非负整数+非负整数`，例如 `3+4`。`Number` 表示数字，`Add` 表示加法；`parse` 负责从字符串构建对象，`evaluate` 负责计算。

## 完整例子

保存为 `InterpreterDemo.java`，使用 JDK 11 或更高版本：

```powershell
javac -encoding UTF-8 InterpreterDemo.java
java InterpreterDemo
```

```java
import java.util.logging.Logger;
public class InterpreterDemo {
    private static final Logger logger = Logger.getLogger(InterpreterDemo.class.getName());
    interface Expression { int evaluate(); }
    static class Number implements Expression {
        private final int value;
        Number(int value) { this.value = value; }
        public int evaluate() { return value; }
    }
    static class Add implements Expression {
        private final Expression left;
        private final Expression right;
        Add(Expression left, Expression right) { this.left = left; this.right = right; }
        public int evaluate() { return Math.addExact(left.evaluate(), right.evaluate()); }
    }
    static Expression parse(String input) {
        if (input == null || input.length() > 32 || !input.matches("[0-9]+\\+[0-9]+"))
            throw new IllegalArgumentException("只支持两个非负整数相加");
        String[] parts = input.split("\\+", -1);
        return new Add(new Number(Integer.parseInt(parts[0])), new Number(Integer.parseInt(parts[1])));
    }
    public static void main(String[] args) {
        /* ========================================================================
         * 步骤1：解析并计算表达式
         * 数据源：测试字符串
         * 操作：1) 构建表达式对象 2) 计算并检查非法输入
         * ======================================================================== */
        logger.info("开始解释表达式");
        // 1.1 按受限语法解析并求值
        Expression expression = parse("3+4");
        System.out.println("结果=" + expression.evaluate());
        // 1.2 非法语法被拒绝
        try { parse("3+"); }
        catch (IllegalArgumentException ex) { System.out.println("拒绝非法表达式"); }
        logger.info("表达式解释完成");
    }
}
```

标准输出，日志单独显示：

```text
结果=7
拒绝非法表达式
```

## 看懂解析和计算

`parse` 先验证长度和格式，再按加号拆成两段整数，并构造 `Add(Number(3), Number(4))`；`evaluate` 分别求左右值，再用 `Math.addExact` 相加。语法合法但数字超出 `int` 范围会抛 `NumberFormatException`；加法结果溢出会抛 `ArithmeticException`。这两种情况和格式错误应在调用边界按需求处理。

例子不支持负数、空格、括号或连续加法；不能把它当成通用数学解析器。限制输入长度有助于控制资源使用，但不是所有输入安全问题的完整解决方案。

## 工作中怎么选

简单且稳定的规则可用明确的解析逻辑或表达式对象；语法复杂时应优先考虑成熟解析器，并限制深度、执行时间和可访问能力。不要把不可信输入直接交给通用脚本引擎执行。

## 动手与自查

1. 输入 `12+30`、`3+` 和 `3 + 4`，分别预测结果。
2. 用接近整数上限的数测试解析范围和加法溢出。
3. 如果要支持括号和乘法，为什么简单地按加号拆分不再足够？
