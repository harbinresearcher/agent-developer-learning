# 迭代器

> **重要程度：高**｜**手练：需要**
> **重点**：遍历协议、游标、删除、增强 for 与并发修改。

## 解决什么问题

调用方需要逐个访问集合元素，但不应该依赖数组、链表或其他内部存储方式。迭代器提供统一的访问协议：`hasNext()` 判断是否还有元素，`next()` 移到下一项并返回它。Java 的 `Iterable` 提供 `iterator()`；很多集合的增强 for 循环也是基于迭代器。

## 完整例子

保存为 `IteratorPatternDemo.java`，使用 JDK 11 或更高版本：

```powershell
javac -encoding UTF-8 IteratorPatternDemo.java
java IteratorPatternDemo
```

```java
import java.util.ArrayList;
import java.util.Iterator;
import java.util.List;
import java.util.logging.Logger;
public class IteratorPatternDemo {
    private static final Logger logger = Logger.getLogger(IteratorPatternDemo.class.getName());
    public static void main(String[] args) {
        /* ========================================================================
         * 步骤1：遍历并删除过期任务
         * 数据源：内存中的任务列表
         * 操作：1) 获取迭代器 2) 删除指定元素并检查结果
         * ======================================================================== */
        logger.info("开始遍历任务");
        // 1.1 创建可修改列表及其迭代器
        List<String> tasks = new ArrayList<>(List.of("进行中", "过期", "已完成"));
        Iterator<String> iterator = tasks.iterator();
        // 1.2 移动游标并用迭代器删除当前元素
        while (iterator.hasNext()) {
            String task = iterator.next();
            if ("过期".equals(task)) iterator.remove();
        }
        System.out.println(tasks);
        logger.info("任务遍历完成");
    }
}
```

标准输出，日志单独显示：

```text
[进行中, 已完成]
```

`next()` 先返回当前要处理的任务；匹配“过期”后，`iterator.remove()` 删除刚刚返回的元素。每次成功调用 `next()` 后最多调用一次 `remove()`，否则可能抛出 `IllegalStateException`。并非所有迭代器都支持删除；不支持时会抛出 `UnsupportedOperationException`。

## 常见错误

- 没有下一项时调用 `next()` 会抛出 `NoSuchElementException`；先检查 `hasNext()`。
- 遍历普通 `ArrayList` 时，直接用列表的 `remove()` 修改结构可能触发 `ConcurrentModificationException`。它是尽力发现错误的机制，不是线程安全保证。
- `List.of()` 创建不可修改列表；例子用 `new ArrayList<>(...)` 创建可修改副本。
- 某些并发集合的迭代器行为与 `ArrayList` 不同，应查具体集合的契约；不要假设都支持删除或都提供同一种一致性。

## 工作中怎么用

只读遍历用增强 for 通常更直观；需要在遍历中删除当前元素时使用支持删除的迭代器，或在合适场景用 `removeIf`。集合很大或来自数据库时，还需考虑内存、分页和资源生命周期。

## 动手与自查

1. 删除“已完成”，预测并核对输出。
2. 改用 `List.of(...)` 直接遍历并删除，观察异常。
3. 为什么迭代器能把调用方与集合内部存储结构分开？
