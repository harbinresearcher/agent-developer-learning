# 访问者

> **重要程度：中**｜**手练：需要**
> **重点**：节点结构、访问者操作、双重分派和扩展代价。

## 它解决什么问题

对象结构的节点类型相对稳定，但需要增加多种操作时，可以把操作放在访问者中。例子中的表达式树有数字和加法两种节点，`Evaluate` 负责求值；节点只负责把自己交给访问者。

## 完整例子

保存为 `VisitorDemo.java`，使用 JDK 11 或更高版本：

```powershell
javac -encoding UTF-8 VisitorDemo.java
java VisitorDemo
```

```java
import java.util.logging.Logger;
public class VisitorDemo {
    private static final Logger logger = Logger.getLogger(VisitorDemo.class.getName());
    interface Node { int accept(Visitor visitor); }
    interface Visitor {
        int visit(NumberNode node);
        int visit(AddNode node);
    }
    static class NumberNode implements Node {
        final int value;
        NumberNode(int value) { this.value = value; }
        public int accept(Visitor visitor) { return visitor.visit(this); }
    }
    static class AddNode implements Node {
        final Node left;
        final Node right;
        AddNode(Node left, Node right) { this.left = left; this.right = right; }
        public int accept(Visitor visitor) { return visitor.visit(this); }
    }
    static class Evaluate implements Visitor {
        public int visit(NumberNode node) { return node.value; }
        public int visit(AddNode node) { return node.left.accept(this) + node.right.accept(this); }
    }
    public static void main(String[] args) {
        /* ========================================================================
         * 步骤1：计算表达式树
         * 数据源：数字节点与加法节点
         * 操作：1) 构造表达式 2) 用访问者计算
         * ======================================================================== */
        logger.info("开始计算表达式");
        // 1.1 构造 3 + 4
        Node expression = new AddNode(new NumberNode(3), new NumberNode(4));
        // 1.2 将操作交给求值访问者
        System.out.println("结果=" + expression.accept(new Evaluate()));
        logger.info("表达式计算完成");
    }
}
```

标准输出，日志单独显示：

```text
结果=7
```

## 看懂调用

`expression` 的声明类型是 `Node`，运行时对象是 `AddNode`。调用 `accept` 时先动态选择 `AddNode.accept`；该方法中的 `this` 是 `AddNode` 类型，编译器选择 `visit(AddNode)`。求值访问者再递归访问左右数字节点，得到 3 和 4 后相加。这个过程常称为双重分派：结合节点的动态方法调用与访问者的重载方法选择。

## 工作中怎么选

新增打印、校验等操作可新增访问者，但新增节点类型通常要扩展 `Visitor` 接口并修改已有访问者。节点种类频繁变化、操作很少时，直接在节点中定义方法可能更简单。

例子没有处理整数溢出、深层递归或无效树；真实表达式系统需要明确数值范围、错误处理和输入限制。访问者并不自动保证线程安全或输入安全。

## 动手与自查

1. 增加乘法节点，列出需要修改的接口和求值实现。
2. 增加打印访问者，将表达式输出为可读形式；可为返回字符串定义单独的访问者接口。
3. 为什么不能只对声明为 `Node` 的变量直接调用一组按具体节点重载的 `visit` 方法并期待 Java 自动选择运行时类型？
