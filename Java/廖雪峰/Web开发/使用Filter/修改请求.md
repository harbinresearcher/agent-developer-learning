# 修改请求

> **重要程度：高**｜**手练：需要**
> **重点**：请求体单次读取、有限缓存、包装对象和同步读取边界。

## 为什么需要包装请求

请求正文通常通过输入流读取。过滤器如果先读完原始请求流，再把原请求传给下游，下游可能只读到空内容。`HttpServletRequestWrapper` 可代理原请求，只重写需要改变的行为；过滤器把包装对象传给 `chain.doFilter`，下游看到的是包装后的请求。

示例限定 `/echo` 为同步、短小的 UTF-8 纯文本请求：过滤器最多读取 1025 字节，超过 1024 字节返回 413；否则缓存原始字节并把包装对象交给控制器。控制器仍能读取一次正文。本例不做签名验证，也不把正文写入日志。

## 完整例子

使用 JDK 17、Maven 与 Spring Boot 4.1.2。新建目录并保存 `pom.xml`：

```xml
<project xmlns="http://maven.apache.org/POM/4.0.0"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 https://maven.apache.org/xsd/maven-4.0.0.xsd">
    <modelVersion>4.0.0</modelVersion>
    <parent>
        <groupId>org.springframework.boot</groupId><artifactId>spring-boot-starter-parent</artifactId>
        <version>4.1.2</version><relativePath/>
    </parent>
    <groupId>learn.example</groupId><artifactId>wrapper-request</artifactId><version>1.0</version>
    <properties><java.version>17</java.version></properties>
    <dependencies>
        <dependency><groupId>org.springframework.boot</groupId><artifactId>spring-boot-starter-webmvc</artifactId></dependency>
    </dependencies>
    <build><plugins><plugin><groupId>org.springframework.boot</groupId><artifactId>spring-boot-maven-plugin</artifactId></plugin></plugins></build>
</project>
```

保存 `src/main/java/learn/wrapper/RequestBodyDemo.java`：

```java
package learn.wrapper;
import java.io.BufferedReader;
import java.io.ByteArrayInputStream;
import java.io.IOException;
import java.io.InputStreamReader;
import java.nio.charset.StandardCharsets;
import jakarta.servlet.Filter;
import jakarta.servlet.ReadListener;
import jakarta.servlet.ServletInputStream;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletRequestWrapper;
import jakarta.servlet.http.HttpServletResponse;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;
import org.springframework.boot.web.servlet.FilterRegistrationBean;
import org.springframework.context.annotation.Bean;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RestController;
@SpringBootApplication
@RestController
public class RequestBodyDemo {
    private static final Logger logger = LoggerFactory.getLogger(RequestBodyDemo.class);
    static class CachedRequest extends HttpServletRequestWrapper {
        private final byte[] body;
        private boolean opened;
        CachedRequest(HttpServletRequest request, byte[] body) { super(request); this.body = body; }
        private void claim() {
            if (opened) throw new IllegalStateException("请求体已打开");
            opened = true;
        }
        @Override public ServletInputStream getInputStream() {
            claim();
            ByteArrayInputStream in = new ByteArrayInputStream(body);
            return new ServletInputStream() {
                public boolean isFinished() { return in.available() == 0; }
                public boolean isReady() { return true; }
                public void setReadListener(ReadListener listener) { throw new UnsupportedOperationException("仅支持同步读取"); }
                public int read() { return in.read(); }
            };
        }
        @Override public BufferedReader getReader() {
            claim();
            return new BufferedReader(new InputStreamReader(new ByteArrayInputStream(body), StandardCharsets.UTF_8));
        }
        @Override public int getContentLength() { return body.length; }
        @Override public long getContentLengthLong() { return body.length; }
    }
    @Bean FilterRegistrationBean<Filter> requestFilter() {
        Filter filter = (request, response, chain) -> {
            /* ========================================================================
             * 步骤1：缓存有限大小的请求体
             * 数据源：/echo 的同步 HTTP 请求
             * 操作：1) 限制读取大小 2) 用包装对象交给后续处理
             * ======================================================================== */
            logger.info("开始处理请求体");
            try {
                // 1.1 最多读 1025 字节，以识别超过 1024 字节的请求
                byte[] body = request.getInputStream().readNBytes(1025);
                if (body.length > 1024) {
                    ((HttpServletResponse) response).sendError(413, "body too large");
                    return;
                }
                // 1.2 下游从独立的缓存流读取，不记录正文
                chain.doFilter(new CachedRequest((HttpServletRequest) request, body), response);
            } finally {
                logger.info("请求体处理结束");
            }
        };
        FilterRegistrationBean<Filter> registration = new FilterRegistrationBean<>(filter);
        registration.addUrlPatterns("/echo");
        return registration;
    }
    @PostMapping(value = "/echo", produces = "text/plain;charset=UTF-8")
    public String echo(HttpServletRequest request) throws IOException {
        return "收到:" + new String(request.getInputStream().readAllBytes(), StandardCharsets.UTF_8);
    }
    public static void main(String[] args) {
        /* ========================================================================
         * 步骤1：启动请求包装示例
         * 数据源：Boot 配置与过滤器注册信息
         * 操作：1) 启动容器 2) 提供本地测试接口
         * ======================================================================== */
        logger.info("开始启动请求包装示例");
        // 1.1 启动嵌入式 Web 服务
        SpringApplication.run(RequestBodyDemo.class, args);
        logger.info("请求包装示例启动完成");
    }
}
```

## 本机验证

先确认 `java -version` 和 `mvn -v` 都使用 JDK 17 或以上。工程目录中运行：

```powershell
mvn package
java -jar target/wrapper-request-1.0.jar --server.address=127.0.0.1 --server.port=8080
```

另开 PowerShell：

```powershell
curl.exe -i -X POST -H "Content-Type: text/plain; charset=UTF-8" --data-binary "hello" http://127.0.0.1:8080/echo
$body = 'a' * 1025
curl.exe -i -X POST -H "Content-Type: text/plain; charset=UTF-8" --data-binary $body http://127.0.0.1:8080/echo
```

第一条返回 200，正文为 `收到:hello`；第二条返回 413。也可用正确的 UTF-8 客户端发送中文。结束后在服务窗口按 `Ctrl+C`；端口占用时同步修改请求地址。

## 看懂包装边界

过滤器消费原始流后，`CachedRequest` 用缓存字节创建下游输入流或 Reader。`claim()` 限制下游在本例中只能选择并打开其中一种读取方式一次；这不表示可以无限次重复读取。示例重写长度方法以反映缓存字节数。

`setReadListener` 明确抛异常，表示这个教学实现不支持 Servlet 非阻塞读取；它不是可直接用于任意异步、multipart 或文件上传请求的通用包装器。仅限定 `/echo`，并约定 UTF-8 文本。生产系统应结合框架提供的组件、服务器和网关的请求大小限制，以及字符编码、内容类型、异步和异常处理做完整设计。

## 工作中怎么用

不要为记录日志无限缓存大请求，也不要记录口令、令牌或敏感正文。验证请求完整性时要明确威胁模型；普通 SHA-1 或 SHA-256 摘要本身不能证明发送者身份，认证签名需使用合适的密钥机制并考虑重放。

## 动手与自查

1. 去掉包装，过滤器先读取正文后再把原请求交给下游，观察控制器读取结果。
2. 用 1024 和 1025 字节分别测试边界；解释为什么先看 `Content-Length` 仍不能代替实际读取限制。
3. 如果下游需要异步非阻塞读取，为什么不能直接使用本例的 `setReadListener` 实现？
