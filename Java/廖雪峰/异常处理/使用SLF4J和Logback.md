# 使用SLF4J和Logback

> **重要程度：高**｜**手练：建议**
> **重点**：门面与实现、参数化日志、配置和敏感数据。

## 核心概念

SLF4J 提供日志门面，Logback 是一种可选实现。代码依赖门面并按项目配置选择合适的实现；版本和适配关系需要与现有依赖一致。

## 工作中注意

参数化日志可以避免手工拼接，并保留结构化上下文；记录异常时应保证异常对象被正确识别。不要假定只有写了 logger 就一定会输出，日志级别和 appender 决定结果。

## 手练

在测试项目中分别记录普通消息和带异常堆栈的错误；调整级别并确认密码或令牌没有进入日志。
