# 使用JDK Logging

> **重要程度：中**｜**手练：建议**
> **重点**：Logger、级别、处理器和异常记录。

## 核心概念

JDK 自带 `java.util.logging`，无需额外依赖。Logger 接收不同级别的日志记录，实际输出还受 Logger、处理器及配置影响；代码调用日志方法不代表一定能在控制台看到。

## 工作中注意

按信息重要程度选择级别，异常需要保留堆栈和定位上下文。不要把密码、访问令牌或个人信息写入日志；共享库不应擅自覆盖整个应用的日志配置。

运行 [[练习01 数组循环与平均值]]，观察日志和标准输出；修改日志级别并说明哪些记录仍可见。
