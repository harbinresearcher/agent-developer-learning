# 使用断言

> **重要程度：中**｜**手练：建议**
> **重点**：assert 开关和适用范围。

## 核心概念

`assert` 用来表达开发者认为应当成立的内部不变量，条件不成立时抛出 `AssertionError`。断言可由 JVM 参数启用；默认情况下通常不启用。

## 工作中注意

不能用断言校验用户输入、权限或必须执行的业务逻辑，因为未启用时断言表达式可能不执行。外部输入应该显式验证并报告合适的异常或错误。

## 手练

写一个内部不变量，分别在启用和未启用断言时运行；解释为什么不能用它阻止非法用户输入。
