# 捕获异常

> **重要程度：高**｜**手练：需要**
> **重点**：catch 顺序、finally 和资源关闭。

## 核心概念

`try` 内抛出异常时，运行时按顺序查找匹配的 `catch`；具体子类应放在父类前面，否则可能无法编译。`finally` 用于正常返回或异常传播时的清理，但进程被强制终止时不能保证执行。

## 工作中注意

实现 `AutoCloseable` 的资源可交给 `try-with-resources`。关闭时若也抛异常，Java 会保留主异常并记录被抑制的异常；排错要查看完整异常链。不要用空 catch 假装操作成功。

## 手练

读取测试文件，分别验证文件存在、文件不存在和读取过程中失败；确认资源在失败路径也关闭。

来源：[教程：捕获异常](https://liaoxuefeng.com/books/java/exception/catch-exception/index.html)。

## 可运行例子

保存为 `ParseDemo.java`，用 `javac -encoding UTF-8 ParseDemo.java` 编译，再运行 `java ParseDemo`。

```java
import java.util.logging.Logger;

public class ParseDemo {
    private static final Logger logger = Logger.getLogger(ParseDemo.class.getName());

    public static void main(String[] args) {
        /*
         * ========================================================================
         * 步骤1：解析输入并处理异常
         * ========================================================================
         * 目标：区分正常解析和格式错误。
         * 数据源：一组本地测试字符串。
         * 操作：
         * 1) 依次解析字符串。
         * 2) 对格式错误给出明确提示。
         */
        logger.info("开始解析测试数据");
        // 1.1 准备测试输入
        String[] values = {"12", "abc"};
        // 1.2 解析每个值并捕获具体异常
        for (String value : values) {
            try {
                System.out.println(Integer.parseInt(value));
            } catch (NumberFormatException ex) {
                System.out.println("无法解析整数: " + value);
            }
        }
        logger.info("测试数据解析完成");
    }
}
```

第一个输入输出 `12`；第二个输入进入 `catch`。例子选择继续处理后续数据；实际项目是否继续，应由业务需求决定。
