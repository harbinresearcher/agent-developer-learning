# 使用Log4j

> **重要程度：中**｜**手练：按需**
> **重点**：日志实现、版本核对和安全更新。

## 核心概念

Log4j 是日志实现体系，可通过配置设置输出目的地、级别和格式。阅读旧教程时要区分 Log4j 1 与 Log4j 2，配置格式、维护状态和兼容性不能混为一谈。

## 工作中注意

依赖版本按项目维护策略和官方安全公告核查；不要为了复现旧教程固定历史漏洞版本。配置文件和日志中都不要保存或输出敏感凭据。

## 手练

在隔离的测试项目中查看现有日志配置，解释日志级别和输出位置；查明实际依赖版本。
