# 调用方法

> **重要程度：中**｜**手练：建议**
> **重点**：签名查找、实例调用、目标异常与访问权限。

## 解决什么问题

框架有时在运行时根据配置或注解找到并调用方法。`Method` 描述一个方法；查找时需要名称及参数类型，调用时还要提供合适的目标对象与参数。普通业务代码在能使用接口时通常应优先直接调用。

## 完整例子

保存为 `MethodReflectionDemo.java`，编译运行；日志写到标准错误。

```java
import java.lang.reflect.InvocationTargetException;
import java.lang.reflect.Method;
import java.util.logging.Logger;
public class MethodReflectionDemo {
    private static final Logger logger = Logger.getLogger(MethodReflectionDemo.class.getName());
    public static void main(String[] args) throws ReflectiveOperationException {
        /*
         * ========================================================================
         * 步骤1：按名称调用对象方法
         * ========================================================================
         * 数据源：本示例服务和字符串参数
         * 操作：
         * 1) 按方法名及参数类型查找方法
         * 2) 调用方法并识别目标方法抛出的异常
         */
        logger.info("开始调用方法");
        // 1.1 获取公开方法并调用
        Method method = Service.class.getMethod("greet", String.class);
        Service service = new Service();
        System.out.println("result=" + method.invoke(service, "Ada"));
        // 1.2 演示目标方法抛异常时的包装
        try {
            method.invoke(service, "");
        } catch (InvocationTargetException ex) {
            System.out.println("cause=" + ex.getCause().getClass().getSimpleName());
        }
        logger.info("方法调用完成");
    }
    public static class Service {
        public String greet(String name) {
            if (name.isEmpty()) throw new IllegalArgumentException("姓名不能为空");
            return "Hello, " + name;
        }
    }
}
```

标准输出：

```text
result=Hello, Ada
cause=IllegalArgumentException
```

## 执行过程

`getMethod("greet", String.class)` 查找名为 greet、参数类型为 String 的公开方法。`method.invoke(service, "Ada")` 在指定对象上调用它，返回的对象是字符串 `Hello, Ada`。

第二次传入空字符串，目标方法内部抛出 `IllegalArgumentException`。反射调用将目标方法抛出的异常包装为 `InvocationTargetException`；本例捕获包装异常，再通过 `getCause()` 观察原始类型。反射调用自身也可能因访问权限、参数等原因失败，这些与目标方法抛错需要区分。

## 查找、调用和边界

`getMethod` 查公开方法，包含继承来的公开方法；`getDeclaredMethod` 查当前类声明的方法，包含非公开方法但不自动向父类查找。方法参数类型必须对应所查声明，例如 `int.class` 和 `Integer.class` 是不同类型，不能因为装箱方便就当作同一个查找签名。

实例方法调用需要合适的目标对象；静态方法的目标参数可为 null。`invoke` 的返回类型是 `Object`，基本类型返回值会包装，`void` 方法返回 null。可覆盖的实例方法在反射调用时仍可能按实际对象执行重写实现。模块和访问限制适用于反射，不应假设拿到 `Method` 就一定可以调用。

## 工作中怎么用

反射需要明确允许调用哪些类型和方法，特别是名称来自配置或外部输入时；不要让不可信输入任意选择代码执行。记录或转换失败时保留 cause，避免把目标方法的异常误认为框架本身找不到方法。

## 手练与答案

把查找参数类型改为 `Integer.class`：没有该签名，抛 `NoSuchMethodException`。传入 `"Bo"`：正常返回 `Hello, Bo`；传空字符串：外层捕获 `InvocationTargetException`，cause 是 `IllegalArgumentException`。
