# 调用方法

> **重要程度：中**｜**手练：按需**
> **重点**：Method 查询、参数类型与调用异常。

## 核心概念

通过 Class 查询 Method 时，需要按方法名和参数类型定位；对实例方法调用时提供目标对象和参数。反射调用可能包装目标方法抛出的异常。

## 工作中注意

`getMethod` 与 `getDeclaredMethod` 的查找范围不同；捕获反射异常时检查 cause，不要丢失真正的业务异常。

## 手练

反射调用一个带参数的方法；让目标方法抛异常，检查反射包装异常的原因。
