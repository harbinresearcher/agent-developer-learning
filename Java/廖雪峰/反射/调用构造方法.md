# 调用构造方法

> **重要程度：中**｜**手练：建议**
> **重点**：查找构造器、创建对象、访问和异常。

## 解决什么问题

一些框架在运行时拿到类型后才决定创建哪类对象。`Constructor<T>` 描述构造器，可以按参数类型查找，再用 `newInstance` 传入参数创建对象。如果类型和构造方式在编译时已知，普通 `new` 通常更直接。

## 完整例子

保存为 `ConstructorReflectionDemo.java`，编译运行；日志写到标准错误。

```java
import java.lang.reflect.Constructor;
import java.util.logging.Logger;
public class ConstructorReflectionDemo {
    private static final Logger logger = Logger.getLogger(ConstructorReflectionDemo.class.getName());
    public static void main(String[] args) throws ReflectiveOperationException {
        /*
         * ========================================================================
         * 步骤1：按参数类型创建对象
         * ========================================================================
         * 数据源：公开的 User 构造器和姓名
         * 操作：
         * 1) 查找 String 参数的构造器
         * 2) 创建实例并读取结果
         */
        logger.info("开始创建对象");
        // 1.1 按构造器参数签名查找
        Constructor<User> constructor = User.class.getConstructor(String.class);
        // 1.2 传参创建对象并读取结果
        User user = constructor.newInstance("Ada");
        System.out.println("name=" + user.getName());
        logger.info("对象创建完成");
    }
    public static class User {
        private final String name;
        public User(String name) { this.name = name; }
        public String getName() { return name; }
    }
}
```

标准输出：

```text
name=Ada
```

## 执行过程

`User.class.getConstructor(String.class)` 查找 User 的公开、单个 String 参数构造器。`Constructor<User>` 的类型参数使 `newInstance("Ada")` 返回 User；随后调用公开方法读取姓名。查找按声明的参数类型而不是参数值推断：若把 `String.class` 写成 `Object.class`，示例类没有该签名，会抛 `NoSuchMethodException`。

## 访问与异常

`getConstructor` 查公开构造器；`getDeclaredConstructor` 可查当前类声明的非公开构造器，但能找到不等于有权调用。模块和访问规则可能限制访问。`newInstance` 可能因访问、参数或无法实例化而失败；构造器内部抛出的异常会包装在 `InvocationTargetException` 中，可通过 cause 查看真实原因。

`Class.newInstance()` 是旧 API，已弃用；使用明确的 `getDeclaredConstructor(...).newInstance(...)` 等方式，按需求处理异常与访问。不要假设所有框架都要求无参构造器，也不要仅为反射方便就移除必要的业务校验。

## 工作中怎么用

只从可信配置或白名单选择需要实例化的类；任意类的构造可能触发副作用。依赖注入框架的构造规则、生命周期和异常处理以框架文档为准。优先选择工厂或接口，使创建过程可测、可替换。

## 手练与答案

把 `getConstructor(String.class)` 改为 `getConstructor()`：本例没有公开无参构造器，查找抛 `NoSuchMethodException`。传入 `"Bo"` 创建对象后读取姓名，结果为 `name=Bo`。
