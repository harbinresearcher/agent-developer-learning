# 调用构造方法

> **重要程度：中**｜**手练：按需**
> **重点**：Constructor、参数匹配和创建对象。

## 核心概念

可通过 Class 获取公开或当前类声明的构造器，再按参数调用 `Constructor.newInstance` 创建对象。构造器的可见性和参数类型决定能否找到并调用。

## 工作中注意

不要使用已经弃用的 `Class.newInstance()` 作为默认写法；检查访问权限和构造器内部抛出的异常。

## 手练

反射获取一个带参数的构造器并创建对象；尝试用错误参数类型查询，观察异常。
