# 动态代理

> **重要程度：中**｜**手练：建议**
> **重点**：接口代理、InvocationHandler 和异常。

## 核心概念

JDK 动态代理为接口创建代理对象，方法调用交给 InvocationHandler；处理器可以在调用目标方法前后加入行为。

## 工作中注意

代理不能自动解决所有切面问题；目标方法的异常、equals/hashCode/toString 和重复代理都要按需求处理。Spring 代理类型由配置和目标类型影响。

## 手练

为接口创建一个计时代理，比较通过代理调用和直接调用的行为，检查异常是否正确传播。
