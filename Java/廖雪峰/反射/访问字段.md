# 访问字段

> **重要程度：中**｜**手练：按需**
> **重点**：public 字段、声明字段和访问限制。

## 核心概念

`getField` 查询可访问的 public 字段，包括继承的 public 字段；`getDeclaredField` 查询当前类声明的字段，不自动包含父类声明字段。

## 工作中注意

访问私有字段可能受到访问控制和模块边界限制。不要依赖反射绕过对象封装来实现普通业务逻辑。

## 手练

定义一个公共字段和一个私有字段，分别查询；比较两种查询方法的结果和权限。
