# 访问字段

> **重要程度：中**｜**手练：建议**
> **重点**：getField 与 getDeclaredField、访问限制与类型。

## 解决什么问题

需要在运行时读取对象结构的框架可能通过反射发现字段。`Field` 是字段元数据，必须结合对象与访问权限才能读取实例字段值。普通业务代码通常更适合使用公开方法，而不是直接访问内部字段。

## 完整例子

保存为 `FieldDemo.java`，编译运行；日志写到标准错误。本例使用 Java 9 起提供的 `trySetAccessible`，并在同一个示例中访问自己声明的类。

```java
import java.lang.reflect.Field;
import java.util.logging.Logger;
public class FieldDemo {
    private static final Logger logger = Logger.getLogger(FieldDemo.class.getName());
    public static void main(String[] args) throws ReflectiveOperationException {
        /*
         * ========================================================================
         * 步骤1：读取声明字段的信息
         * ========================================================================
         * 数据源：本示例定义的 Profile 对象
         * 操作：
         * 1) 查找声明的私有字段并检查访问能力
         * 2) 读取字段类型和对象中的值
         */
        logger.info("开始查看字段");
        // 1.1 获取本类声明的字段
        Profile profile = new Profile("Ada");
        Field field = Profile.class.getDeclaredField("name");
        // 1.2 在当前示例的访问条件下读取字段
        if (!field.trySetAccessible()) {
            throw new IllegalStateException("无法访问字段");
        }
        System.out.println("type=" + field.getType().getSimpleName());
        System.out.println("value=" + field.get(profile));
        logger.info("字段查看完成");
    }
    static class Profile {
        private final String name;
        Profile(String name) { this.name = name; }
    }
}
```

标准输出：

```text
type=String
value=Ada
```

## 执行过程

`Profile.class.getDeclaredField("name")` 按名称查找 `Profile` 自己声明的字段，得到 `Field` 元数据；它包括 private 字段，但查找成功不等于调用方一定有权限读取。`trySetAccessible()` 尝试允许该反射对象抑制访问检查；成功后 `field.get(profile)` 从指定实例读取值。

`field.getType()` 返回字段的原始类型 `String.class`。获取泛型声明信息可使用 `getGenericType()`，但实例运行时类型参数受擦除规则限制，见 [[泛型和反射]]。

## 查找范围和权限

`getField` 查询公开字段，包括可访问的继承字段；`getDeclaredField` 查询当前类声明的字段，不自动查父类，也可以找到非公开字段。名称不存在会抛 `NoSuchFieldException`。静态字段与实例字段读取方式及目标对象要求不同，应查具体 API；写入还可能受到 final、类型和访问限制。

模块系统、包开放情况及运行配置可能阻止抑制访问检查；`trySetAccessible()` 可能返回 false，`setAccessible(true)` 也可能失败。不要假设所有 JDK 内部字段都能强行访问，也不要无条件添加开放模块参数绕开封装。

## 工作中怎么用

只反射访问有明确契约和允许范围的类型；把字段名变化、类型不匹配与访问失败当作可诊断的配置或兼容问题。反射写字段可能绕过业务校验，除框架等明确需要的场景外，应优先调用对象的公开行为。

## 手练与答案

将字段名改为不存在的 `"age"`：查找时抛 `NoSuchFieldException`。将 `getDeclaredField` 换成 `getField`：本例 name 是 private，不能通过该公开字段查找方式找到。
