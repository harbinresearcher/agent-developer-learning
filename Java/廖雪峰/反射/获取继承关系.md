# 获取继承关系

> **重要程度：低**｜**手练：按需**
> **重点**：父类、接口与类型判断。

## 核心概念

`getSuperclass()` 查询直接父类，`getInterfaces()` 查询直接实现的接口；Class 还提供类型兼容性判断。

## 工作中注意

直接接口和传递继承的接口不是同一个集合，遍历完整层级时需要按需求递归处理。对基本类型、接口和 Object 等边界查看 API 契约。

## 手练

定义父类、子类和接口，用反射检查直接继承关系和类型兼容性。
