# 获取继承关系

> **重要程度：中**｜**手练：建议**
> **重点**：父类、接口、isAssignableFrom 方向。

## 解决什么问题

反射代码有时要判断某个类型是否实现接口或继承父类，才能决定是否接受它。`Class` 提供直接父类、直接接口和类型可赋值关系等信息。

## 完整例子

保存为 `TypeRelationDemo.java`，编译运行；日志写到标准错误。

```java
import java.util.Arrays;
import java.util.logging.Logger;
public class TypeRelationDemo {
    private static final Logger logger = Logger.getLogger(TypeRelationDemo.class.getName());
    public static void main(String[] args) {
        /*
         * ========================================================================
         * 步骤1：检查类型关系
         * ========================================================================
         * 数据源：示例中的 Animal、Dog 与 Pet 类型
         * 操作：
         * 1) 查询直接父类和直接接口
         * 2) 判断赋值方向
         */
        logger.info("开始检查类型关系");
        // 1.1 查看 Dog 的直接父类和接口
        System.out.println("parent=" + Dog.class.getSuperclass().getSimpleName());
        System.out.println("interfaces=" + Arrays.toString(Dog.class.getInterfaces()));
        // 1.2 检查一个类型是否可赋给另一个类型
        System.out.println("animalFromDog=" + Animal.class.isAssignableFrom(Dog.class));
        System.out.println("dogFromAnimal=" + Dog.class.isAssignableFrom(Animal.class));
        logger.info("类型关系检查完成");
    }
    static class Animal { }
    interface Pet { }
    static class Dog extends Animal implements Pet { }
}
```

标准输出：

```text
parent=Animal
interfaces=[interface TypeRelationDemo$Pet]
animalFromDog=true
dogFromAnimal=false
```

## 执行过程

`Dog` 继承 `Animal` 并实现 `Pet`。`getSuperclass()` 返回直接父类 Animal；`getInterfaces()` 返回该类直接声明实现的接口。数组输出中的 `$` 是嵌套类型名称的一部分，不是目录分隔符。

`Animal.class.isAssignableFrom(Dog.class)` 为 true：可以把 Dog 对象引用赋给 Animal 类型变量。反过来为 false，因为普通 Animal 不保证是 Dog。判断方向可以按“左边变量能否接收右边类型”记忆；同一类型与自身的可赋值判断也为 true。

## 范围与边界

`getSuperclass()` 只给直接父类；要遍历祖先需继续查询，并处理 `Object`、接口、基本类型等可能返回 null 的情况。`getInterfaces()` 只给直接接口，不自动列出父类及接口祖先的所有间接接口；若业务需要完整关系，要按规则递归并去重。

`SomeType.class.isInstance(value)` 用于检查一个具体对象是否可赋给该类型；对 null 返回 false。泛型类型参数受擦除限制，不能仅凭 Class 判断某个 List 的元素都是什么类型。

## 工作中怎么用

动态注册组件前可校验它是否实现预期接口，再通过可信工厂创建。类型兼容不等于业务行为正确，也不保证有可访问构造器；还需检查配置和生命周期。

## 手练与答案

`Pet.class.isAssignableFrom(Dog.class)` 为 true；`Dog.class.isAssignableFrom(Pet.class)` 为 false。`Object.class.getSuperclass()` 返回 null。
