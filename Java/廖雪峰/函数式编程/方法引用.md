# 方法引用

> **重要程度：高**｜**手练：需要**
> **重点**：静态、实例、构造器方法引用与类型匹配。

## 解决什么问题

如果 Lambda 只是把参数交给一个已有方法，方法引用可简化写法。它仍要与目标函数式接口的参数和返回类型匹配；`::` 本身不会立即调用方法。

## 完整例子

保存为 `MethodReferenceDemo.java`，编译运行；日志写到标准错误。

```java
import java.util.*;
import java.util.function.*;
import java.util.stream.*;
import java.util.logging.Logger;
public class MethodReferenceDemo {
    private static final Logger logger = Logger.getLogger(MethodReferenceDemo.class.getName());
    public static void main(String[] args) {
        /*
         * ========================================================================
         * 步骤1：引用已有方法转换文本
         * ========================================================================
         * 数据源：程序中准备的固定示例数据
         * 操作：
         * 1) 创建函数或数据流
         * 2) 处理输入并输出结果
         */
        logger.info("开始处理示例");
        // 1.1 准备数字文本并去除空格
        List<String> values = Arrays.asList(" 10 ", "20");
        // 1.2 使用实例和静态方法引用转换
        List<Integer> numbers = values.stream()
                .map(String::trim)
                .map(Integer::parseInt)
                .collect(Collectors.toList());
        System.out.println("numbers=" + numbers);
        logger.info("示例处理完成");
    }
}
```

标准输出：

```text
numbers=[10, 20]
```

## 执行过程

流中每个字符串依次调用 `String::trim`，等价于本例中的 `s -> s.trim()`；再调用 `Integer::parseInt`，等价于 `s -> Integer.parseInt(s)`。终止操作 collect 触发流水线并收集为整数列表 `[10, 20]`。

## 常见形式

`类型::静态方法` 如 `Integer::parseInt`；`对象::实例方法` 把调用绑定到指定对象；`类型::实例方法` 如本例 `String::trim`，流元素成为方法接收者；`类型::new` 可引用构造器。能否使用由目标接口签名、重载解析和访问权限决定。

方法引用不会自动处理 null、异常或业务校验。`trim()` 遇到 null 会抛异常，`parseInt` 遇到非法数字会抛 `NumberFormatException`；外部输入先明确失败策略。只有当方法引用比 Lambda 更易读时才使用。

## 手练与答案

输入改为 `" x "`：trim 后 parseInt 抛 `NumberFormatException`。将 `String::trim` 改为 `s -> s.trim()`：本例行为不变。
