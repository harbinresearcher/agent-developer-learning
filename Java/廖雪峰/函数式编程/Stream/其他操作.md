# 其他操作

> **重要程度：中**｜**手练：建议**
> **重点**：排序、去重、limit 和短路。

## 核心概念

Stream 还提供 sorted、distinct、limit、anyMatch 等操作，分别处理排序、去重、截取和条件判断。

## 工作中注意

操作顺序影响结果与性能；无限流要使用可以结束的处理方式。并行执行的实际收益需要测量。

## 手练

对测试数字先去重再排序并取前三个，交换操作顺序比较结果。
