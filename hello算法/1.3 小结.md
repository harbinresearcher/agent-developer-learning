**第 1 章总复习：初识算法**

```
┌────────────┬────────────┬──────────────────────────┐
│ 生活场景   │ 算法       │ 识别条件                 │
├────────────┼────────────┼──────────────────────────┤
│ 查字典     │ 二分查找   │ 数据有序；每次排除一半   │
│ 整理扑克   │ 插入排序   │ 有序区逐步扩大；数据较小 │
│ 货币找零   │ 贪心算法   │ 每步选当前最优           │
└────────────┴────────────┴──────────────────────────┘
```

```
[解决问题] ── 数据输入 ── 数据结构 ── 算法步骤 ── 输出结果
                               │
                               └── 决定访问、增删、内存开销
```

**必须背下来的定义**

- 算法：在有限时间内解决特定问题的一组确定步骤。
- 数据结构：组织、存储和操作数据的方式。
- 二者关系：数据结构决定数据怎样放、怎样取；算法决定怎样处理数据。

**别把“会调用库函数”当成“懂算法”**

排序函数能直接用，但仍要判断它是否适合当前数据。

```
通用排序：O(n log n)
固定长度整数：可考虑基数排序 O(nk)
```

其中 `k` 是整数位数。数据量小时差别可能不明显；数据量大时，选错算法会直接变成时间和成本问题。

学算法的目标不是手写所有排序，而是形成判断：

```
数据有什么特征？
最频繁的操作是什么？
标准方案的时间和内存成本是多少？
有没有利用数据特征的更优方案？
```

知识储备越多，看到的问题结构越清楚，方案也越接近最优。
