**笔记：算法无处不在**

```
┌──────────┬────────────┬──────────────────┬────────────────────┐
│ 生活动作 │ 算法名称   │ 核心条件         │ 每一步做什么       │
├──────────┼────────────┼──────────────────┼────────────────────┤
│ 查字典   │ 二分查找   │ 数据已排序       │ 每次排除一半范围   │
│ 整理扑克 │ 插入排序   │ 已有一段有序区   │ 插入一张到正确位置 │
│ 货币找零 │ 贪心算法   │ 可按局部最优选   │ 每次优先选最大面额 │
└──────────┴────────────┴──────────────────┴────────────────────┘
```

算法不等于复杂数学。它本质上是一套明确、可重复的步骤：给定输入，按规则处理，得到结果。生活里许多习惯已经是算法，只是没有写成代码。

```
[生活问题] ──┬── 查找有序信息 ── 二分查找
             ├── 逐步扩大有序区 ── 插入排序
             └── 每步拿当前最佳 ── 贪心算法
```

1. 二分查找：查字典

字典按拼音排序。查首字母 `r` 时，先翻中间；若中间是 `m`，因为 `r > m`，直接排除前半部分；再在后半部分重复。

- 关键不是“翻中间”，而是“数据必须有序”。
- 每轮把查找范围缩小一半。
- 适合：有序数组、按时间排序的记录、字典、排行榜。
- 不适合：无序数据。无序时不能靠比较中间值排除一半。

判断口诀：**有序 + 查某个值或边界 → 先想二分。**

2. 插入排序：整理扑克

把手牌分成两部分：

- 左边：已经排好序；
- 右边：还没处理。

每次从右边抽一张牌，插入左边正确位置。处理完一张，有序区就扩大一张。

例如已有 `[3, 7, 9]`，拿到 `5`：

```
[3, 7, 9] + 5
        ↓
[3, 5, 7, 9]
```

- 算法的核心状态：**有序区不断扩大，无序区不断缩小**。
- 小数据量时简单有效。
- 数据量大时，反复移动元素会慢。

判断口诀：**前面已有序，后面逐个插入 → 插入排序。**

3. 贪心算法：货币找零

找 `31` 元时，先拿不超过剩余金额的最大面额：

```
剩余 31 → 拿 20 → 剩余 11
剩余 11 → 拿 10 → 剩余 1
剩余  1 → 拿  1 → 剩余 0
```

得到 `20 + 10 + 1`。

- 贪心的规则：每一步都选“当前看来最好”的选择。
- 它不回头比较以前的选择。
- 这页例子中得到可行方案。
- 注意：贪心不保证所有题都得到全局最优解，是否正确取决于题目的结构和可选面额。

判断口诀：**每步先拿眼前最优，并且不回溯 → 考虑贪心。**

**本页真正要记住的内容**

- 同一个问题可换两种视角：生活中的“做事步骤”，程序里的“算法”。
- 算法能否用，先看前提：二分要有序；插入排序要维护有序区；贪心要证明局部最优不会坑后面。
- 学算法不只是背名称，要能说清：输入是什么、状态如何变化、每轮排除了什么或新增了什么、何时结束。
