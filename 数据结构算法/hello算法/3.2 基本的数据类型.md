**3.2 基本数据类型**

基本数据类型回答“一个数据是什么”；数据结构回答“多个数据怎么组织”。例如 `list[int]` 和 `list[str]` 的结构同为列表，元素类型不同。[原文](https://www.hello-algo.com/chapter_data_structure/basic_data_types/)

```
┌──────────┬────────────────┬────────────────────┐
│ 类型     │ 表示什么       │ 常见用途           │
├──────────┼────────────────┼────────────────────┤
│ 整数     │ byte/int/long  │ 计数、下标、编号   │
│ 浮点数   │ float/double   │ 小数、测量值       │
│ 字符     │ char           │ 单个文字或符号     │
│ 布尔     │ bool           │ 条件判断：真或假   │
└──────────┴────────────────┴────────────────────┘
```

```
[程序中的数据] ──┬── 基本数据类型：内容是什么
                 │   ├── int：整数
                 │   ├── float：小数
                 │   ├── char：字符
                 │   └── bool：真/假
                 └── 数据结构：多个数据怎么摆放
                     ├── 数组
                     ├── 链表
                     ├── 栈、队列
                     └── 树、图、哈希表
```

**1. bit、byte、取值范围**

- `bit`：一位二进制，只能是 `0` 或 `1`。
- `1 byte = 8 bit`。
- 一个类型占的 bit 越多，可表示的不同状态越多。

例如 Java 的 `int` 占 4 字节，即 32 bit，共有 `2^32` 种二进制组合。若表示有符号整数，范围是：

```
b 位有符号整数：
-2^(b-1) 到 2^(b-1) - 1
```

所以 Java `int` 的范围是 `-2^31` 到 `2^31 - 1`。不必死背数值，要会按位数判断范围。[原文](https://www.hello-algo.com/chapter_data_structure/basic_data_types/)

**2. 四类类型怎么用**

- 整数：循环次数、数组下标、节点数量。算法题最常用。
- 浮点数：表示小数。它是近似值，金额等需要精确计算的场合不能随便用浮点数。
- 字符：单个字母、汉字、标点等。
- 布尔：只有 `True / False`，常用于条件、标记是否访问过。

布尔逻辑上只需 1 bit，但内存中通常按 1 byte 存，因为 CPU 一般按字节寻址。

**3. Java、Python 不一样**

```
┌──────────┬─────────────────────────────────────┐
│ 语言     │ 要点                                │
├──────────┼─────────────────────────────────────┤
│ Java     │ int 固定 4 字节，范围固定           │
│ Python   │ int 可随数值增长，占用更多内存      │
│ Python   │ float 通常是 64 位双精度            │
│ Python   │ 没有 char，单字符也是 str           │
│ C / C++  │ 类型大小取决于平台和编译器          │
└──────────┴─────────────────────────────────────┘
```

写算法时，Python 的 `int` 不容易溢出；Java、C/C++ 的固定整数类型则要警惕溢出。

**4. 最容易混淆的点**

- `int` 是元素的内容类型；数组是组织多个元素的结构。
- 数组能存整数、浮点数、字符或布尔值；结构没变，元素类型变了。
- Python 列表可混放不同类型，但写算法时通常应保持同类元素，例如 `list[int]`，逻辑更清晰。
- “基本类型由 CPU 直接处理”不等于复杂数据不能处理；复杂数据最终也是由基本类型和内存组织出来的。

一句话：**先选元素类型，再选组织结构；类型决定每个元素是什么，结构决定它们如何排列与访问。**
